# 专题二：忽必烈为何迅速成为大汗候选人
## 1259年8月至1260年夏：从南征统帅到开平汗廷的资源重组

> **研究目标**
>
> 本专题不写忽必烈完整传记，也不预先证明他比阿里不哥“更合法”。它只研究一个较窄的问题：蒙哥死亡时，忽必烈仍是远离和林、奉命攻宋的一位宗王；他为什么能在不足一年内，把军队、漠南行政财赋、潜邸家政、汉军世侯和宗王支持接合成一个足以争夺大汗之位的联盟？
>
> **核心判断**
>
> 1260年夏的忽必烈政权，既不是已经成熟、能够脱离本人自动运转的“元朝国家”，也不只是临时聚拢在帐幕周围的私人追随者。更准确的说法是：
>
> **它是一副嵌在个人联盟之中的薄层国家骨架。**
>
> 鄂州北返军提供了时间与武力；漠南旧有经营提供了节点、人员和财政记忆；潜邸集团把这些资源翻译成命令、官职和合法性语言；汉军世侯提供地方兵力与社会控制；东道及部分西道宗王提供最低限度的成吉思汗家族承认。中书省、宣抚司、印信、急递、宿卫和粮马调拨，又使联盟开始获得制度外壳。
>
> 但是，这些连接仍高度依赖忽必烈本人：他是各集团共同承认的宗王，是军队的直接统帅，是官职和利益的授予者，也是蒙古合法性、汉地行政和属国外交之间最重要的中介。若在1261年突然拿掉忽必烈，体系不会立刻化为乌有，却会迅速退化成若干需要重新议价的军事—家族—地域集团。

## 文档说明

### 一、时间范围

- **起点：**1259年8月蒙哥死亡，忽必烈军仍在汝南—淮北一线南下。
- **中段：**忽必烈进至鄂州，获知死讯，在继续作战与立即北返之间犹豫，随后分批撤军。
- **终点：**1260年春开平集会、忽必烈即位，以及至1260年夏最初一轮中枢、宣抚、军事和后勤部署。

1251—1258年忽必烈经营漠南、建立潜邸班底和遭蒙哥限制的经历只作为前史；1260年夏以后的全面内战只作为检验联盟强度的反向证据。

### 二、证据等级

| 等级 | 含义 |
|---|---|
| **A级：史料可直接确认** | 有明确纪年、地点、任命、命令或行动记录；仍须考虑《元史》等材料的胜利者立场 |
| **B级：多条材料支持的重建** | 原始材料不完整，但人物行程、官职与后续行动能够互相印证 |
| **C级：分析性推断** | 用来解释动机、联盟结构或反事实风险，不能冒充史料原话 |
| **缺口** | 现有材料不足，必须保留不确定性 |

### 三、最重要的史料警戒线

1. 《元史·世祖纪》以胜利者王朝的建立为叙事终点，会把1260年的临时措施写成后来元朝制度的自然开端。
2. 廉希宪、刘秉忠、郝经等人的列传倾向于突出传主的先见与功劳；“某一人一句话决定大局”的写法必须拆解。
3. 汉军世侯列传常在李璮之乱以后重新整理忠逆，早期合作关系可能被后见之明改写。
4. 《高丽史》保存了更早记录，却在十五世纪编成；“唐太宗不能服而今世子自来”一类名言，政治寓意大于逐字可信度。
5. “忽里勒台”“中书省”“宣抚司”等同名制度在1260年并不必然具有后来成熟元朝的规模和效力。
6. 本文所说的“国家骨架”“个人联盟”是分析概念，不是十三世纪当事人的自称。

# 一、摘要：忽必烈为什么能在数月内成为现实候选人

## 1. 他有资格，但资格本身不能自动转化为汗位

忽必烈是拖雷与唆鲁禾帖尼之子，是蒙哥的同母弟。在拖雷正妻诸子的资序中，蒙哥死后忽必烈年长于旭烈兀、阿里不哥；旭烈兀又远在西亚。这给了忽必烈明显的家系与资序优势。

但蒙古帝国并没有“兄终弟及且长者自动继位”的刚性法律。宗王会议、军事实力、斡耳朵和中央兀鲁思的控制、其他家系的承认仍然重要。资序使忽必烈**有资格争位**，不能使他**自动成为大汗**。

**结论等级：A/B。**

## 2. 鄂州军使他不是一个只能靠使者和诏书争位的宗王

忽必烈南征集团是一支由蒙古军、汉军、潜邸人员、前锋和粮运系统组成的完整战役集团。它原本由蒙哥临时授予忽必烈统率，并非忽必烈的全部私军；但在蒙哥死亡后，军队仍直接听命于忽必烈本人。

这支军队给了他三种资本：

- 保护本人和家属、控制北返路线的现实武力；
- 对汉军世侯和东道诸王进行谈判时的可信承诺；
- 在阿里不哥尚未完成漠北、漠南动员前抢占燕京、开平和交通节点的时间窗口。

**结论等级：A/B。**

## 3. 他不是从零进入华北，而是拥有十年经营留下的人事和制度节点

1251年蒙哥曾令忽必烈总理“漠南汉地军国庶事”。此后忽必烈在邢州、河南、京兆、金莲川—开平等地进行过不同程度的军政经营，形成了：

- 官员和幕僚网络；
- 粮仓、屯田、盐粮转运等经验；
- 与河北、河南、关中地方集团的长期关系；
- 一个可以容纳斡耳朵、幕府和宗王交往的开平基地。

这些不是一块排他的主权领土。蒙哥仍可另派牙老瓦赤、布智儿等管理燕京财赋，又曾令阿蓝答儿、刘太平调查忽必烈系统。这说明忽必烈拥有的是**可被调用的旧网络和治理履历**，不是对漠南的无条件所有权。

**结论等级：A。**

## 4. 潜邸集团的核心作用是“资源转换”，而不仅是劝他采用汉法

刘秉忠、张文谦、郝经、廉希宪、赵璧、董文炳、商挺以及蒙古、色目家臣承担的功能并不相同：

- 有人设计官署和名号；
- 有人分析战争、继承和北返时机；
- 有人书写诏令、管理文书和财政；
- 有人联络宗王；
- 有人进入地方处理兵变和征发；
- 有人掌握前线部队、宿卫或燕京行政。

他们的共同作用，是把忽必烈的私人声望、宗王身份和军事统帅权，转化为可以被不同群体理解的命令、官职、利益与合法性语言。

**结论等级：A/B。**

## 5. 汉军世侯支持的是“能保护并承认其地位的强宗王”，不是一个已经完成中央集权的国家

张柔、史天泽、董文炳、李璮等集团的处境不同，不能统称为“汉人拥戴忽必烈”。

他们支持忽必烈，可能因为：

- 早期合作和私人恩信；
- 需要有人保护其家族辖区与军户；
- 希望把临时军权转化为正式官职；
- 反感蒙哥后期调查、征发和多头命令；
- 判断忽必烈的北返军和漠南网络更能维持华北秩序。

但他们并未在1260年同时交出全部兵权。张柔集团被分割使用，随后又被抽取三千五百人守京并以子入质；史天泽在忽必烈即位后才被“首召”；李璮甚至一面受封、一面保留山东独立基础。所谓支持，本质上是不同程度的**军事契约和政治投资**。

**结论等级：A。**

## 6. 东道诸王的支持让开平即位“足以成立”，但不足以令全帝国无争议承认

《元史》列举合丹、阿只吉等西道宗王，以及塔察儿、也先哥、忽剌忽儿、爪都等东道宗王推戴忽必烈。它们带来的不只是骑兵，也包括成吉思汗家族内部的承认。

然而，开平是忽必烈经营的基地，不是一个由帝国所有主要家系共同赴会的中立中心。阿里不哥、旭烈兀及更西方兀鲁思的主要代表并未共同参与。按照忽里勒台作为协商性、合议性制度的原则，缺乏广泛到场意味着合法性仍有明显缺口。

所以开平会议的效果是：

> 它足以把忽必烈从“有资格的宗王”变成“拥有汗廷、官署和支持者的大汗候选人”，却不足以消灭阿里不哥另行即位的空间。

**结论等级：A/B。**

## 7. 高丽世子事件不是军事转折，却是一次高价值的外交展示

高丽世子王倎原本是赴蒙哥汗廷交涉，途中得知蒙哥死亡，又因北路受阻而转向忽必烈。忽必烈阵营随后让他回国继位，将一场偶然相遇转化为“无需动兵而得一国”的政治成果。

它不能决定蒙古宗王站队，却证明忽必烈已经能够：

- 接受属国来朝；
- 决定一位外国王位继承人的命运；
- 以宽缓政策换取臣服；
- 把外交成功写进自己的天命叙事。

**结论等级：A/B。**

## 8. 到1260年夏，忽必烈已经制造了一副国家骨架，但本人仍是不可替代的连接器

1260年春夏相继出现：

- 中书省；
- 燕京宣慰体系；
- 十路宣抚司；
- 印信和文书回收；
- 急递铺与军令传递；
- 京师宿卫；
- 开平和燕京方向的粮、马、军服和兵力调拨；
- 关陇、四川、河南等地的军政任命。

这些措施不只是私人帐幕政治，说明一个跨地区政权正在形成。

然而，宗王、军队、世侯、官僚和属国并未形成稳定的共同继承程序。各方接受官职和命令，往往因为授予者是忽必烈本人。由此得出的最终判断不是“只有联盟”或“已经是国家”，而是：

> **国家化已经开始；联盟性仍然占主导；个人中介性仍然极强。**

# 三、蒙哥死前，忽必烈究竟已经拥有些什么

## 1. “总领漠南汉地军国庶事”：广泛授权，但不是排他主权

蒙哥即位后，曾令忽必烈管理漠南汉地军国事务。这一授权解释了忽必烈为什么能在华北接触地方官、汉军世侯、僧道和儒士，也解释了后来很多人愿意把他视为漠南秩序的自然中心。

但必须注意三层限制。

### 第一层：授权来自蒙哥，理论上可被收回

忽必烈并非以独立君主身份治理漠南，而是以大汗之弟和受命宗王身份办事。蒙哥死亡使授权来源消失；它没有自动变成忽必烈的世袭主权。

### 第二层：大汗中央仍在漠南保有平行官员

《元史》记载，牙老瓦赤、布智儿等曾在燕京管理财赋。这说明即使忽必烈掌握广泛军政事务，大汗中央仍能绕过或监督其网络。

### 第三层：蒙哥后期对忽必烈系统进行政治—司法调查

1257年前后，阿蓝答儿、刘太平等调查京兆、河南官员。周思成等现代研究指出，所谓“钩考”不能只理解为普通汉式查账，更接近蒙古政治司法中的 **yārghū**：它带有调查、追责乃至重新划定权力边界的性质。

因此，蒙哥死前的忽必烈不是“漠南国王”，而是一位曾获广泛授权、拥有治理履历、却又受到中央限制的宗王。

## 2. 邢州、河南和京兆：三个不同性质的经营节点

### 邢州：地方治理试验

忽必烈以幕僚整顿邢州，处理官吏、赋役和流民问题。这为他积累了“能改善汉地秩序”的声誉，也形成一批熟悉地方行政的追随者。

它的价值主要是：

- 政治声誉；
- 官员训练；
- 与地方士人和豪强建立关系；
- 展示不同于掠夺式征发的治理方案。

邢州不是一块独立国土，更不是1259年可以随时抽取大量军粮的直属领地。

### 河南：军政和后勤枢纽

忽必烈曾设置河南经略体系，使用史天泽、杨惟中、赵璧等人，并经营屯田、粮运和南方战场准备。

河南的意义在于：

- 接近南宋前线；
- 能把汉军世侯、州县行政和军需结合；
- 为1259年的南征提供熟悉道路与人员；
- 北返时仍可作为联系华北和淮北的中间地带。

但史天泽等人拥有自己的家族与军队基础，不能视作忽必烈官僚系统中的普通执行者。

### 京兆：份地、盐粮和入川通道

京兆及关中经营与忽必烈的份地利益、盐粮转运和四川战争准备有关。其系统能够联系：

- 盐池收入；
- 粮食采购；
- 嘉陵江方向运输；
- 关陇将领和地方官；
- 四川北部道路。

然而，京兆也是蒙哥与忽必烈权力冲突最明显的地区之一。阿蓝答儿调查、后来关陇军队的分裂，都证明这里并没有在1259年无条件归属于忽必烈。

## 3. 金莲川—开平：从夏营地到政治基地

开平在1256年前后营建，位于忽必烈长期活动的金莲川地区。它兼具：

- 斡耳朵和家政中心；
- 幕僚集会场所；
- 与东蒙古、燕京和和林道路相连的地理位置；
- 接待宗王、属国使者和地方官员的政治功能；
- 储存文书、家属和部分物资的后方功能。

开平最大的优势不是城墙或人口，而是它已经被不同集团认识为“忽必烈的中心”。察必能够从这里侦知阿里不哥派系逼近并向鄂州送出急报，说明开平在1259年已具备独立于前线行营的信息和家政网络。

但它也有明显弱点：

- 距和林不远，容易遭北方军队威胁；
- 本地粮食承载能力有限，需要从燕京、东平等处输入；
- 它是候选人的私人基地，无法天然替代帝国传统中心和林。

## 4. 忽必烈的“既有资源”清单

| 资源 | 蒙哥死前是否存在 | 1259年能否立即使用 | 局限 |
|---|---:|---:|---|
| 拖雷家系与年长资序 | 是 | 是 | 不能替代宗王会议和军事实力 |
| 个人斡耳朵、家臣、宿卫 | 是 | 是 | 规模不足以单独争夺帝国 |
| 开平基地 | 是 | 大体可以 | 粮食依赖外运，且受漠北威胁 |
| 潜邸幕僚 | 是 | 是 | 职能不一，未必形成统一官僚机构 |
| 漠南治理声誉 | 是 | 可用于招徕 | 不能自动兑换为税收和军队 |
| 邢州、河南、京兆旧网络 | 是 | 部分可以 | 受大汗官员、地方强人和战区变化制约 |
| 汉军世侯关系 | 是 | 需逐家重新确认 | 家族兵权仍然独立 |
| 东道诸王关系 | 部分存在 | 需重新动员 | 不是天然统一阵营 |
| 南征军统帅权 | 是，来自蒙哥任命 | 在前线最可立即使用 | 蒙哥死后合法来源中断，部队成分复杂 |
| 燕京行政财政 | 有关系和旧部 | 不能自动控制 | 脱里赤等能进入燕京征兵，说明控制权需重新夺取 |

**阶段性判断：**

忽必烈拥有的不是一座现成国家，而是一套比其他候选人更容易迅速重新接通的“接口”：军队接口、地方官接口、财赋接口、宗王接口和合法性接口。

# 四、鄂州军：从攻宋战役集团到争位机动力量

## 1. 蒙哥死时，忽必烈尚未到鄂州

1259年七月，忽必烈最后可明确定位于汝南；阴历八月才渡淮，继而经黄陂向长江北岸推进。蒙哥死亡与忽必烈抵达鄂州之间存在消息和行军时差。

这意味着忽必烈最初不是从鄂州“听到消息立即北返”，而是在以下几项行动之间继续向南：

- 继续执行蒙哥南征命令；
- 等待可靠死讯；
- 与前锋和后续军队会合；
- 判断北方形势；
- 维持军队的共同战役目标。

## 2. 鄂州军不是单一来源的私军

至少可以分为六层。

| 层次 | 主要成员或功能 | 与忽必烈的关系 |
|---|---|---|
| **直属行营与宿卫** | 个人家臣、蒙古近侍、帐下指挥人员 | 私人依附最强 |
| **蒙古前锋与战役部队** | 拔都儿等将领所率军队 | 受蒙哥命令交由忽必烈节制 |
| **汉军将领及分队** | 董文炳、张柔部分军队等 | 有长期合作，也保留家族基础 |
| **潜邸文职幕僚** | 郝经、杨惟中等 | 提供战略、文书、宣抚与行政 |
| **粮运与州县系统** | 汝南、蔡州及淮北军需人员 | 依赖地方行政和征发网络 |
| **后续会合或留守部队** | 张柔后到；拔都儿、白鹿矶等留守 | 说明军队并未同时、整齐地北返 |

所以，“忽必烈拥有鄂州军”应理解为：

> 他掌握一个以本人为最高战役统帅、由多种隶属关系组成的临时联合军，而不是拥有一支完全私有、所有部队都只认其个人的常备军。

## 3. 为什么获知蒙哥死讯后没有立即撤军

《元史》把忽必烈继续渡江解释为“不可以无功而返”。这一说法带有明显的世祖英雄叙事色彩，但仍反映一个真实难题：若未经战斗便仓促北逃，忽必烈可能失去军中威望，也会被竞争者解释为违抗蒙哥遗命、畏敌争位。

可以把他的犹豫拆为四种动机。

### A. 军事声望

一位争夺大汗的宗王必须显示自己仍在完成大汗交付的战争。哪怕鄂州未被攻克，实际渡江、交战和保持进攻姿态，也能避免“闻丧逃归”的形象。

### B. 军队凝聚

南征军来自不同集团。继续执行公开的战役任务，可以在政治目标尚未明确时维持共同命令；若突然宣布北返争位，部分将领可能要求新的宗王授权。

### C. 信息确认

蒙哥死亡的消息传播、末哥使者到达、北方征兵风声和开平警报并非同时出现。忽必烈需要判断死亡是否确实、阿里不哥是否已经行动、家属是否安全。

### D. 退出条件

一支大军跨过淮河和长江后，不能只靠统帅一句话瞬间消失。必须安排：

- 与宋军脱离；
- 船只和渡口；
- 辎重与俘获人口；
- 后卫；
- 尚未抵达或分散作战的部队；
- 留守白鹿矶等据点的军队。

因此，继续攻鄂州不必解释为他“完全不知道争位的重要性”，更可能是军事声望、组织惯性与退出条件共同造成的短暂延迟。

## 4. 郝经《班师议》：潜邸幕僚如何重新定义战争

郝经的建议极有价值，因为它不是一般性的“儒臣劝仁政”，而是一份政权转换方案。

其中的核心判断包括：

- 北方政治中心空虚；
- 阿里不哥已通过脱里赤等人在燕京附近建立征兵和行政活动；
- 忽必烈拥有声望和一支重兵；
- 应迅速通过驿递返回燕京；
- 应控制印信、文书和北方官署；
- 应召集宗王，以奔丧和会议形式处理继承；
- 应留下适当人员处理南方战线和家属安全。

即使郝经列传可能强化了传主的先见，这篇文字仍说明忽必烈身边已有人能够把“攻宋战役”转换成“继承危机的政治—交通—文书行动”。

潜邸集团的真正价值正体现在这里：他们不只是提供理念，而是识别**哪条道路、哪套印信、哪批官员和哪种会议形式**能把一支军队变成一个汗廷。

## 5. 鄂州撤军是分批完成的

几个细节特别关键。

### 第一，忽必烈先留下拔都儿等部

《元史》记载忽必烈北返时并未把所有军队同时带走，说明前线需要后卫和谈判掩护。

### 第二，张柔在白鹿矶承担长期驻守

张柔随忽必烈抵达鄂州，忽必烈北返后又令其率蒙汉军在白鹿矶构筑据点。后来才下令撤回。

### 第三，史天泽在即位后被派往鄂州撤回余军

史天泽原先随蒙哥在四川作战，并非忽必烈鄂州集团的天然成员。忽必烈即位后“首召”史天泽，又令其处理江上余军撤回，说明南方军队直到1260年仍需要高级将领逐步整合。

### 第四，董文炳等人按自己的战斗路线北返

董文炳先在鄂州外围和长江作战，随后于闰十一月前后北返。他的部队与忽必烈关系较深，却仍有自身指挥链。

## 6. 这是一次主动撤退还是仓促溃退

现有材料不能支持“毫无损失的完美撤军”，也不能支持“鄂州军已经崩溃”。

较稳妥的判断是：

- 蒙哥死亡是结束南征的根本原因；
- 宋军并未摧毁忽必烈的主要指挥体系；
- 忽必烈仍能安排分批撤离、后卫和据点；
- 北返后迅速压制燕京征兵并参加开平集会，说明核心军队和统帅机构保持了相当组织性；
- 疾病、长期行军、渡江作战和分兵必然造成损耗，但无法量化。

因此可称为：

> **一支未实现战役目标、但仍保持政治与军事组织的远征军主动转向。**

## 7. 鄂州军在1260年的用途

它至少被重新用于五种任务：

1. 保护忽必烈从鄂州返回燕京、开平；
2. 压制脱里赤等人在漠南征集的兵力；
3. 为开平即位提供武力背景；
4. 组成燕京、开平和关隘守备的一部分；
5. 在阿里不哥战争初期成为可迅速调动的核心野战力量。

但不能把1260年所有调往燕京、开平的兵都算作原鄂州军。东平军、陕西军、宗王本部和新征宿卫也被逐步加入。

# 五、漠南行政与财赋：不是自动继承，而是快速“重新接线”

## 1. 燕京在1259年末仍是争夺区

如果忽必烈在蒙哥死前已经拥有一个排他的漠南国家，脱里赤便很难进入燕京附近征兵、处理文书和发布命令。

恰恰相反，材料显示：

- 阿里不哥一方能够借蒙哥旧有的中央名义活动；
- 燕京官员、军户和地方势力仍在等待合法命令；
- 忽必烈必须亲自北返、解散对方所征兵力；
- 燕京的重新控制依赖军队、宣慰任命和文书整顿。

因此，“燕京离不开忽必烈”不能理解为1259年所有人天然服从他。更准确的说法是：

> 忽必烈拥有在燕京迅速恢复控制的旧关系和政治信誉，但必须用北返军和新任命把这些关系重新激活。

## 2. 从治理履历到可征用资源，中间还隔着四道门槛

| 状态 | 含义 | 1259—1260年的例子 |
|---|---|---|
| **曾经经营** | 忽必烈或其旧侣过去在当地任职 | 邢州、河南、京兆 |
| **名义辖区** | 文书上归某机构或宗王负责 | 漠南汉地军国事务 |
| **当时可征税** | 官员、账册、仓储和地方势力愿意执行 | 燕京、河南、山东各不相同 |
| **能够立即调兵** | 有军籍、印信、粮饷和直接指挥者 | 多数仍掌握在世侯或地方将领手中 |

忽必烈的优势主要在于前两项积累较多，第三、第四项必须在1260年重新建立。

## 3. 1260年春夏的新机构做了什么

### 中书省：建立一个跨部门命令中心

1260年四月设置中书省，王文统、张文谦等进入核心职位。此时的中书省规模和成熟度远不能与后来相比，但它至少承担：

- 汇集诏令；
- 任命官员；
- 处理财赋和赦令；
- 把潜邸旧侣变成有正式职名的中枢成员；
- 向地方宣抚司发出统一命令。

它首先是战争中枢和政权认证机构，而非已经覆盖全国的成熟宰相府。

### 燕京宣慰体系：把军事接管转化为地方行政

禡禡、赵璧、董文炳等被用于燕京宣慰。这里的组合很有代表性：

- 有蒙古或宫廷人物；
- 有熟悉汉地行政的旧侣；
- 有能够带兵的汉军将领。

这种混合配置说明忽必烈不信任任何单一集团独占燕京，而是用交叉监督的方式重新接管。

### 十路宣抚司：在地方建立“接头点”

1260年五月以后设置十路宣抚司，覆盖燕京、顺天、河南、山东、陕西等重要区域。它们的作用是：

- 宣布新汗廷合法性；
- 重新确认地方官和军户；
- 停止或改造旧征发；
- 收集税粮、兵马和情报；
- 处理地方对阿里不哥命令的响应；
- 把潜邸人员派到关键地域。

宣抚司更像战时接管机构，而不是稳定的常规地方政府。

### 印信、文书与急递：让命令变得可验证

忽必烈收缴、整理旧官印和文书，建立急递，是争位战争中非常实际的一步。

没有这套机制，各地会面对多个同样声称代表成吉思汗家族的使者。控制印信和驿站意味着能够回答：

- 哪份命令是真的；
- 谁有权征兵和征粮；
- 哪个官职仍有效；
- 谁是叛乱者；
- 消息能以多快速度到达开平、燕京、陕西和前线。

### 宿卫和京师守军：保护机构本身

从张柔等世侯军中抽取兵力守京、征调其他地区部队，说明新中枢无法只靠文书存在。宿卫既保护忽必烈，也保护印信、官署、家属和会议。

## 4. 粮、马、军服和人口调拨：国家能力的第一轮压力测试

1260年夏，忽必烈向开平和北方驿站输送粮食，调东平等地军队北上，征马并准备冬衣。这些行动说明：

- 漠南农业区开始被组织为草原战争的后方；
- 开平本地不能独立供养大量军队；
- 中书和宣抚机构已能发出跨地区征调；
- 但实际执行仍依赖地方军户、世侯和官员。

忽必烈相较阿里不哥的长期优势并非“汉地天然属于他”，而是他更早建立了将汉地粮食、银钞、军户和道路转化为北方战争资源的机构。

## 5. 漠南体系的阶段判断

到1260年夏，可以区分三层。

### 已有一定制度惯性的部分

- 开平与燕京的文书和家政中心；
- 中书省的命令汇集功能；
- 若干宣抚司；
- 急递和印信系统；
- 部分宿卫和粮运路线。

### 仍高度依赖忽必烈个人的部分

- 宗王是否承认中书发出的命令；
- 汉军世侯是否交兵、出粮；
- 地方官是否把旧关系转化为对新汗的效忠；
- 各地军队是否接受跨辖区调遣；
- 新官职的权威是否高于家族和宗王关系。

### 尚未真正控制的部分

- 和林及中央兀鲁思；
- 阿里不哥掌握的漠北动员区；
- 西北部分蒙哥旧军；
- 旭烈兀及其他西方兀鲁思；
- 大量边缘地区和属国的最终承认。

# 六、潜邸集团：谁在连接哪些资源

## 1. 不能把潜邸旧侣写成一个“汉儒党”

忽必烈潜邸中既有儒士、僧人、军人和地方行政人才，也有蒙古、色目家臣和宗王联络者。他们对政治路线的理解并不相同。

真正应记录的是“人物—功能—资源”。

## 2. 核心人物功能表

| 人物 | 1259年前的关系和资源 | 1259—1260年的关键功能 | 新政权中的位置 | 对忽必烈依赖度 | 1261年断裂风险 |
|---|---|---|---|---|---|
| **察必** | 正妻斡耳朵、开平家政、子女与近侍网络 | 发现阿里不哥派系逼近，向鄂州秘密示警；维持后方 | 非正式但极关键的家政与信息中心 | 极高 | 能维持家族核心，却难单独号令宗王和世侯 |
| **刘秉忠** | 长期潜邸顾问，熟悉蒙古旧制与汉地官制 | 提供官署、名号、制度和王朝语言 | 中枢设计者 | 极高 | 可维持制度方案，缺乏直接军权和宗王合法性 |
| **郝经** | 幕僚、文书和政治论说能力 | 以《班师议》重新定义战略目标，提出北返、控制燕京与会议程序 | 决策顾问 | 极高 | 能提出方案，不能强制军队执行 |
| **张文谦** | 刘秉忠关系网、邢州等治理经验 | 文书、财政、行政协调；1260年进入中书 | 中书左丞等核心职位 | 高 | 中书可继续办公，但权威需要新的最高授予者 |
| **廉希宪** | 潜邸旧侣，能与蒙古宗王和汉地官员沟通 | 催促即位、联络塔察儿等宗王、处置高丽世子、赴陕蜀稳定西线 | 陕蜀宣抚等 | 高 | 远在关陇时难直接控制燕京继承；可能成为地方稳定器 |
| **赵璧** | 河南等地行政与联络经验 | 燕京宣慰、地方接管 | 燕京核心行政人员 | 高 | 能守官署，缺乏独立最高合法性 |
| **董文炳** | 长期随忽必烈作战，兼具家族军和行政经验 | 鄂州作战、北返、燕京宣慰、后续宿卫 | 军政桥梁 | 中高 | 可能支持家族继承，但仍要顾及本部军和地方 |
| **商挺** | 潜邸与地方行政经验 | 参与关陇、陕蜀接管 | 西线军政官员 | 高 | 易被西北军势裹挟，需依赖宗王和将领 |
| **杨惟中** | 早期漠南、河南宣抚经验 | 前线宣抚、地方联络 | 行政与宗教事务骨干 | 高 | 可维持地方网络，难主导汗位 |
| **史天泽** | 华北世侯、蒙哥四川军高级将领 | 即位后被召入，撤江上余军，提供军政方案 | 河南等地军政重臣 | 中 | 忠于新秩序但有家族与军队基础，可能重新议价 |
| **张柔** | 保定张氏家族军 | 鄂州作战、白鹿矶留守；部分兵力被抽为宿卫 | 军事支持者 | 中 | 质子和抽兵增加约束，但本部仍可能自主 |
| **王文统** | 与李璮网络密切，财政才能突出 | 进入中书负责财赋 | 平章政事 | 低至中 | 对李璮关系使中枢存在渗透风险 |

## 3. 潜邸集团的四项不可替代功能

### 信息整合

察必的开平警报、郝经对北方形势的判断、廉希宪对关陇风险的认识，使忽必烈能同时看到：

- 前线战况；
- 和林继承；
- 燕京征兵；
- 开平安全；
- 关陇蒙哥旧军；
- 属国来使。

阿里不哥掌握和林，但忽必烈的优势在于拥有一批能将不同地区信息翻译为行动方案的人。

### 政治翻译

同一项行动需要对不同群体使用不同理由：

- 对蒙古宗王：家系、资序、宗王推戴；
- 对军队：完成战役、奖赏、秩序和粮饷；
- 对汉地官员：除苛征、设官、安民；
- 对世侯：确认官职、保护辖区、交换兵力；
- 对高丽：承认王位、以臣服换取宽缓。

潜邸集团使忽必烈能够同时说这几种政治语言。

### 官职化

潜邸关系本来是私人追随。1260年以后，旧侣被放入：

- 中书省；
- 宣慰司；
- 陕蜀、河南、燕京等地方机构；
- 宿卫和军队；
- 文书、财政和外交岗位。

官职化使私人网络开始获得可复制的组织形式。

### 危机派遣

廉希宪赴关陇、史天泽撤江军、董文炳宣慰燕京，说明忽必烈不是把所有能人留在身边，而是将其派到政权可能断裂的接点。

## 4. 潜邸集团的局限

- 多数人没有独立的成吉思汗家族合法性；
- 文职官员无法替代宗王和世侯的军权；
- 旧侣之间存在路线和利益差异；
- 新官署威望仍来自忽必烈授职；
- 一旦忽必烈死亡，“谁有权继续任命和罢免”会立即成为问题。

因此，潜邸集团能制造国家骨架，却不能自行决定谁继承忽必烈。

# 七、汉军世侯：支持、议价与未完成的中央化

## 1. 为什么他们倾向忽必烈

不能只用“忽必烈亲汉”解释。更实际的原因有五个。

### A. 既有合作关系降低不确定性

忽必烈曾在河南、邢州、京兆和南征中使用史、张、董等集团。长期合作使双方知道彼此能提供什么。

### B. 忽必烈能把地方军权合法化

蒙古征服后的汉军世侯既有实力，也担心被中央清理。支持一个强宗王，可以换取：

- 官职；
- 金银符牌；
- 辖区承认；
- 军户和家族地位；
- 在新中枢中的发言权。

### C. 他们需要统一的命令和财政秩序

蒙哥死亡后若多头征兵、征粮，世侯辖区会遭不同宗王重复索取。忽必烈以中书和宣抚司提供一种相对集中的秩序。

### D. 鄂州北返军改变了风险判断

支持一位没有军队的宗王风险极高。忽必烈带着完整度较高的南征集团北返，使观望者相信他有能力保护盟友。

### E. 阿里不哥的优势不容易转化为汉地利益保障

阿里不哥接近和林传统中心，却缺少在华北长期经营的官员和财政网络。世侯未必反对阿里不哥的蒙古合法性，但很难确认他能否保护其辖区和军权。

## 2. 张柔集团：最典型的“分割合作”

1259年张氏军队已被拆分：

- 张果、王仲仁等随蒙哥入四川；
- 王安国等随塔察儿进攻荆山；
- 张柔本人及其余部随忽必烈至鄂州。

这说明张氏首先是一支能够被大汗和宗王分遣的家族军事集团，并非忽必烈的整建制私军。

忽必烈北返后：

- 张柔在白鹿矶留守；
- 后来奉命撤军；
- 1260年汗位战争中，忽必烈一度召其宿卫；
- 又从其军中抽出三千五百人守京；
- 以其子入质。

这套措施的含义很明确：

> 忽必烈既需要张柔，又不完全信任张氏独立兵权；他通过抽兵、宿卫和质子，把合作变成可约束的联盟。

## 3. 史天泽集团：从蒙哥四川军转入忽必烈体系

史天泽在1259年随蒙哥于钓鱼山、嘉陵江方向作战。他不是跟着忽必烈从鄂州北返的核心旧部。

忽必烈即位后“首召”史天泽，向其询问治国之策，并令其撤回鄂州等地余军。这一步的重要性在于：

- 史天泽带来华北世侯中的威望；
- 他与蒙哥四川军和汉军将领有联系；
- 他的加入显示忽必烈开始吸收并非原属自己战役集团的军事资源；
- 他能把新汗廷命令传给江上和河南军队。

史天泽后来主张文武分职、世侯家族交出军政合一权，恰好从反面说明1260年的中央化尚未完成。

## 4. 董文炳集团：整合程度较高的军政桥梁

董文炳与忽必烈合作较早，随军经历较多。1259年他作为前锋在鄂州外围作战，北返后又进入燕京宣慰和宿卫体系。

与张柔、李璮相比，董文炳具有三个特点：

- 对忽必烈个人依附更深；
- 能在野战军与地方行政之间转换；
- 家族军权虽存在，但较早被嵌入新中枢。

因此，他更接近“新政权军官”，而不是单纯与新汗谈判的地方盟主。

## 5. 李璮集团：支持联盟的危险边界

李璮控制益都及山东东部重要军政资源，长期以海防和宋军威胁为由保留部队，回避中央抽调。1260年忽必烈仍授予他江淮大都督等重职、符牌和财物。

这说明忽必烈当时的策略不是立即消灭所有世侯，而是：

- 用更高官职换取名义服从；
- 让地方集团承担边境战争；
- 通过中枢和人质逐步约束；
- 在汗位战争期间避免同时与所有地方强人开战。

李璮后来反叛不能简单证明他1260年“从未支持”忽必烈；它更适合作为反向证据：

> 1260年的成功联盟允许一部分地方集团在接受最高官职的同时，继续保有独立军队、财政和通信渠道。

## 6. 王文统：为何中书省本身也带有联盟风险

王文统有财政和行政才能，又与李璮关系密切。忽必烈让他进入中书，说明新政权急需能够立即运转财赋的人，即使其政治关系并不安全。

这反映一种典型的创业期困境：

- 忽必烈必须吸收既有地方网络，才能迅速获得税粮；
- 吸收越快，中枢越可能被地方集团渗透；
- 不吸收，则无法与阿里不哥进行长期资源战争。

## 7. 世侯支持程度表

| 集团 | 1259年主要位置 | 对忽必烈支持方式 | 是否交出全部军权 | 中央约束手段 | 1261年风险 |
|---|---|---|---:|---|---|
| 张柔集团 | 鄂州、荆山、四川多处分散 | 随征、留守、提供宿卫兵 | 否 | 抽兵、质子、官职 | 若最高授予者死亡，可能优先保全家族与本镇 |
| 史天泽集团 | 四川及华北关系网 | 即位后加入、撤军、提供军政方案 | 否，后续才推动分权 | 高位任命、制度改革 | 可能支持秩序继承，但要求强有力共主 |
| 董氏集团 | 鄂州前锋、后入燕京 | 作战、宣慰、宿卫 | 较高程度嵌入，但非完全 | 私人恩信、官职、近卫职位 | 较可能支持忽必烈家族核心 |
| 李璮集团 | 益都、海州、涟水方向 | 名义效忠、边境作战、接受高官 | 明显没有 | 符牌、赏赐、官职，约束有限 | 高风险，可能利用权力真空扩张 |
| 关陇汪氏等 | 陕西、巩昌、四川北部 | 受不同宗王和将领调动 | 否 | 宣抚、宗王命令、军职 | 容易在阿里不哥与燕京间重新选边 |

# 八、东道诸王与开平集会：最低限度的蒙古合法性

## 1. 为什么东道诸王重要

东道诸王拥有的不是抽象“血统加分”，而是三种现实资源：

- 成吉思汗诸弟家系的宗王资格；
- 东蒙古、辽东及邻近地区的份地、人口和本部军；
- 与华北道路、汉军世侯和开平之间的地缘联系。

他们的支持使忽必烈不再只是一个依靠汉军和儒臣的宗王，而成为一个得到若干成吉思汗家族分支公开推戴的候选人。

## 2. 东道诸王并非天然统一

应区分：

1. 宗王本人到场；
2. 派遣代表；
3. 口头支持；
4. 带本部军参会；
5. 在后续战争中持续出兵。

《元史》列出的开平推戴者证明若干宗王参与，却不足以说明所有东道诸王早在1259年8月已形成稳定阵营。

他们支持忽必烈的可能原因包括：

- 忽必烈的开平基地与其份地地理接近；
- 阿里不哥长期居和林，可能强化中央兀鲁思对宗王份地的压力；
- 忽必烈拥有汉地粮食和军需，更能支持其本部军；
- 塔察儿等人与忽必烈、汉军世侯已有南征合作；
- 忽必烈的资序和军事实力使支持具有较高成功概率。

这些原因需要逐家考证，不能把“东道诸王”当成一个有统一意志的政党。

## 3. 开平会议究竟有多合法

忽里勒台在蒙古政治中不是现代意义的投票大会，而是一种需要主要利害关系宗王到场、协商和共同确认的制度。其效力取决于：

- 谁发起；
- 谁到场；
- 是否有能力安全赴会；
- 主要家系是否缺席；
- 决定能否得到军队和斡耳朵执行。

开平会议具有三项真实效力。

### A. 它提供了公开的宗王推戴

忽必烈不是单方面宣布，而是让东、西道若干宗王成为推戴者。

### B. 它把开平从私人基地变成竞争性汗廷

即位以后，开平开始接收诏令、官员、宿卫、粮食和属国使者。

### C. 它使反对者必须另行组织会议

阿里不哥随后在和林一带即位。双汗并立本身证明开平会议足以产生政治事实，也证明其不足以产生帝国共识。

## 4. 开平会议的程序缺口

- 地点属于忽必烈私人经营区；
- 阿里不哥及和林中央留守集团没有共同参与；
- 旭烈兀远在西亚；
- 术赤、察合台等西方兀鲁思没有形成共同、无争议的到场承认；
- 蒙哥诸子和蒙哥旧有行营资源的整体立场并未因此自动解决；
- 会议处于军队和政治竞争压力之下。

因此，评价开平会议时应避免两个极端：

- 不能说它“完全非法、毫无作用”；
- 也不能说它已经是全帝国一致的正式忽里勒台。

最准确的表述是：

> **一场参与范围有限、但政治效力真实的宗王拥立会议。**

## 5. 东道诸王对忽必烈提供了什么

| 资源 | 实际作用 | 局限 |
|---|---|---|
| 家族合法性 | 证明若干成吉思汗家系承认忽必烈 | 不能代表全部宗王 |
| 骑兵与份地军 | 增加开平、燕京及漠东防御能力 | 出兵规模、持续时间需逐王确认 |
| 地理通道 | 连接辽东、东蒙古、燕京和开平 | 各家系仍有自己的利益 |
| 会议资格 | 使即位不是纯粹自立 | 缺少帝国全体主要家系 |
| 对汉军的政治背书 | 减轻“汉军拥立蒙古宗王”的嫌疑 | 无法消除阿里不哥的和林优势 |

# 九、高丽世子王倎事件：外交收益与天命叙事

## 1. 事件的基本过程

高丽世子王倎原本奉命前往蒙古最高汗廷交涉。行至西北交通线上时得知蒙哥死亡，北上和林的道路又受到阿里不哥一方阻隔，于是转而南下或东南行，与正在北返的忽必烈相遇。

不同材料对相遇地点、路线细节和话语存在差异，但几个核心事实较稳定：

- 王倎原本不是专程“选择忽必烈”而来；
- 蒙哥死亡和北路受阻改变了行程；
- 忽必烈接纳了他；
- 廉希宪、赵良弼等主张让其回国继位；
- 此举成为忽必烈对高丽政策的重要转折；
- 元方后来把事件塑造成“四海来归”的征兆。

## 2. 高丽方面原本准备向谁交涉

王倎的目标本来是蒙哥大汗，而非一个尚未即位的忽必烈。这一点非常重要。

它意味着事件最初是偶然的：高丽试图通过派世子入朝保存王室和争取缓和，恰逢最高汗死亡。忽必烈的政治能力体现在，他没有把偶然来使仅当作一个外交插曲，而是将其转化为：

- 对外承认权；
- 王位授予权；
- 宽政声誉；
- 即位合法性素材。

## 3. 立即军事价值有限

王倎没有为忽必烈带来一支足以影响汗位战争的军队。高丽当时内部仍有武人政权、岛屿抗争和对蒙关系等复杂问题。

因此不能说“高丽归附帮助忽必烈击败阿里不哥”。

## 4. 实际外交和战略价值不低

### A. 无须新增大规模征服成本

让王倎回国继位，比继续依靠军事征服和驻军更节省资源。忽必烈可以把更多兵力用于北方内战。

### B. 获得东北方向的政治缓冲

一个愿意与忽必烈汗廷建立关系的高丽王室，有助于稳定辽东东侧和海东交通。

### C. 展示“新汗能够封王”

在大汗继承尚未统一时，忽必烈已经能够决定一个属国王位继承人的待遇。这是实际主权行为。

### D. 为宽缓政策提供样板

忽必烈阵营可以宣称：归附者会得到保护，旧王室可被承认，不必重复残酷征服。这种信号不仅面向高丽，也面向汉地地方集团。

## 5. “唐太宗不能服”的名言应如何使用

《高丽史》等材料保存了忽必烈将王倎来归与唐太宗征高丽相比较的著名叙述。它非常符合后来元朝对世祖天命的塑造：

- 古代强帝未能完成的事，忽必烈无需出兵即得；
- 外国世子在争位之际主动来朝；
- 天命通过偶然事件显现。

这句话可以用来研究元朝如何记忆该事件，不宜未经保留地当作1259年现场逐字记录。

## 6. 高丽事件的阶段结论

| 层面 | 作用 |
|---|---|
| 军事 | 很有限，没有直接提供决定性兵力 |
| 外交 | 较高，建立王室层级的臣属关系 |
| 东北战略 | 中等，有助于稳定辽东外缘 |
| 政权能力展示 | 较高，显示忽必烈能接见、封授和遣返外国王储 |
| 合法性宣传 | 很高，可塑造成天命与四海来归 |
| 对蒙古宗王的直接说服力 | 有限，不能替代宗王会议与军队 |

# 十、忽必烈用什么语言宣布自己有权统治

忽必烈阵营没有只使用一种合法性语言，而是针对不同受众组合多套说法。

## 1. 面向蒙古宗王：家系、资序与推戴

核心要素包括：

- 成吉思汗—拖雷家系；
- 蒙哥同母弟身份；
- 兄弟中的年长与贤能叙事；
- 东、西道诸王推戴；
- 在帝国危机中恢复统一和秩序；
- 否定阿里不哥一方未经共同认可的征兵和处置。

这里的重点不是汉地年号，而是证明忽必烈仍在蒙古政治传统内部争位。

## 2. 面向军队：功业、奖赏与连续命令

忽必烈没有在获知死讯后立刻抛弃南征，有助于维持“完成大汗使命”的形象。北返后则通过：

- 继续任用战役将领；
- 赏赐和授职；
- 抽调宿卫；
- 供应粮、马和冬衣；
- 镇压未经许可的征兵；

证明自己的汗廷能让军队获得可执行命令和军需。

## 3. 面向汉地官僚和百姓：除苛政、立官署、恢复秩序

《即位诏》《中统建元诏》等文本把蒙哥死后的混乱与苛征、官吏失序联系起来，强调：

- 安民；
- 纠正滥征；
- 设置中书和地方总司；
- 统一官制；
- 赦免和恢复生产；
- 使用年号与王朝文书。

这不是简单的“忽必烈变成汉族皇帝”，而是借汉地政治语言解释：为什么一位蒙古宗王有权重新组织漠南财政和官署。

## 4. 面向汉军世侯：确认利益并逐步收权

忽必烈同时使用两手：

- 授予高官、符牌、赏赐，承认家族军功；
- 抽取兵力、设置宿卫、要求质子、建立中书和宣抚司。

他没有在1260年一次性摧毁世侯，而是以汗位战争需要为理由，将家族军权逐步嵌入新政权。

## 5. 面向属国：宽缓、封授和“来归”

高丽世子事件提供了最清晰案例。忽必烈以承认王位换取服从，将军事征服语言改写为“无需劳师而来归”。

## 6. 面向竞争者：谁能恢复秩序，谁才像大汗

忽必烈的宣传并不只说自己血统更高，而是暗示：

- 阿里不哥一方在漠南擅自征兵；
- 多头命令破坏州县；
- 只有开平汗廷能够给军队粮饷、给官员印信、给地方明确上级、给属国确定待遇。

这是一种“治理能力即合法性”的主张。

## 7. 合法性语言对照表

| 受众 | 主要语言 | 交换内容 |
|---|---|---|
| 蒙古宗王 | 拖雷家系、资序、宗王推戴、恢复帝国秩序 | 承认与份地安全 |
| 蒙古及汉军 | 完成战役、奖赏、粮饷、有效军令 | 军事服从 |
| 汉军世侯 | 官职、符牌、辖区承认、渐进收权 | 兵力、地方控制、税粮 |
| 汉地官僚 | 中书、宣抚、安民、停止滥征 | 文书执行与财政治理 |
| 百姓与州县 | 赦免、减扰、恢复生产 | 纳税与秩序接受 |
| 高丽等属国 | 宽缓、封王、承认旧王室 | 朝贡和政治臣属 |
| 其他兀鲁思 | 成吉思汗家系与宗王会议 | 外交承认，但1260年尚未获得 |

## 2. 接合的顺序

忽必烈的成功不是五种资源同时自动归附，而是一个有顺序的过程：

1. **先保持南征军完整；**
2. **通过开平家政网获得北方警报；**
3. **北返控制燕京并压制阿里不哥派系征兵；**
4. **联络宗王，在开平制造最低限度的拥立；**
5. **把潜邸旧侣放入中书和宣抚机构；**
6. **召入史天泽等原属蒙哥战区的将领；**
7. **以官职、质子和抽兵重新绑定世侯；**
8. **把燕京、东平、陕西等地粮马输入开平；**
9. **用高丽事件、诏书和年号扩大合法性叙事。**

这说明鄂州北返的最大意义不是“带回多少万人”，而是给其他四种资源提供一个能够围绕其组织的武力中心。

## 3. 为什么忽必烈比阿里不哥更快利用漠南资源

阿里不哥拥有和林、中央兀鲁思和传统政治中心的优势，但在漠南面临四个困难：

- 缺少忽必烈那样长期经营的地方官和世侯关系；
- 征兵和命令需要通过蒙哥旧官或临时代理人；
- 对汉地财政、仓储和文书系统的直接理解较弱；
- 难以同时向汉军、州县官和地方士人提供稳定利益。

忽必烈则有：

- 现成北返军；
- 开平基地；
- 察必与家政网；
- 邢州、河南、京兆旧侣；
- 一批能立刻出任中书、宣抚和军事岗位的人；
- 与张、史、董、李等集团既竞争又合作的经验。

因此，忽必烈的优势不是汉地资源“天然更多”，而是**转换效率更高**。

# 十二、开平即位以后：到底留下了一个国家，还是个人联盟

## 1. 支持“已经出现国家”的证据

到1260年夏，忽必烈政权具备一些不能简化为私人追随的特征：

- 有公开即位和年号；
- 有中书省与地方宣抚体系；
- 有印信和正式文书；
- 有急递和跨地区通信；
- 有京师与开平守军；
- 能调拨不同地区的粮、马、冬衣和兵力；
- 能任免地方官；
- 能处理属国王位；
- 能召回不在原直属军中的史天泽等将领；
- 能把张柔等家族的一部分军队抽入中央宿卫。

这些都是国家能力的萌芽。

## 2. 支持“仍是个人联盟”的证据

与此同时：

- 开平会议参与范围有限；
- 阿里不哥另有和林汗廷；
- 旭烈兀和西方兀鲁思未形成统一承认；
- 世侯仍掌握家族军、辖区和财政；
- 中书吸收王文统等地方网络人物，内部忠诚复杂；
- 宣抚司多由潜邸旧侣临时派出；
- 军队对忽必烈的服从往往来自战役统帅关系；
- 真金尚未获得后来皇太子的制度化继承地位；
- 新中枢没有经过一次“最高统治者突然死亡”的继承检验。

## 3. 最合适的模型：薄层国家骨架嵌在个人联盟中

可以把1260年体系画成三层。

```text
第一层：忽必烈个人
宗王资格｜军队统帅｜官职授予者｜不同政治语言的共同中介
                         │
第二层：联盟连接器
察必斡耳朵｜潜邸旧侣｜东道诸王｜汉军世侯｜蒙哥旧将
                         │
第三层：初生机构
中书省｜宣抚司｜燕京官署｜印信文书｜急递｜宿卫｜粮马调运
```

第三层已经存在，说明不能只称私人联盟；但第一层一旦消失，第二层是否继续承认第三层，没有固定答案。

## 4. 哪些连接已有制度惯性

| 连接 | 制度惯性 | 原因 |
|---|---|---|
| 中书内部文书和日常行政 | 中等 | 官员和流程已开始形成，可短期继续办公 |
| 燕京宣慰与地方接管 | 中等 | 有具体人员、印信和守军 |
| 急递与粮运 | 中等 | 路线和站户可继续运行，但命令合法性可能受争夺 |
| 开平家政与斡耳朵 | 较高 | 察必、子女和家臣可维持家族核心 |
| 宿卫 | 中等 | 有直接编组，但效忠对象可能争议 |
| 高丽政策 | 中等 | 已有王室关系，可由继承者继续 |
| 十路宣抚司 | 低至中 | 新设不久，依赖派遣者与地方合作 |

## 5. 哪些连接几乎仍以忽必烈为唯一枢纽

| 连接 | 依赖程度 | 风险 |
|---|---:|---|
| 东道诸王对开平汗廷的承认 | 极高 | 支持忽必烈不等于支持其子或某位汉臣摄政 |
| 鄂州北返军的最高统帅权 | 极高 | 将领可能按宗王、家族和战场关系分裂 |
| 汉军世侯对中枢的服从 | 高 | 官职和承诺需新最高权威重新确认 |
| 中书对军队的命令权 | 高 | 文官机构尚不能独立调动宗王本部和世侯军 |
| 开平与和林之间的合法性竞争 | 极高 | 忽必烈死亡会让阿里不哥宣称对手汗廷已经失去主体 |
| 真金继承 | 极高 | 尚无成熟皇太子制，需宗王、军队和斡耳朵重新同意 |

## 6. 为什么不能把1260年的中书省等同于后来元朝国家

同名官署容易造成后见之明。1260年的中书省有三个明显特征：

- **人员高度私人化：**主要依赖潜邸旧侣和临时吸纳的地方人才；
- **权限高度战时化：**最紧迫任务是征调、安抚、任命和对抗阿里不哥，而非成熟常规治理；
- **执行高度地方化：**真正收税、征兵、守城的仍是地方官、世侯和宗王本部。

因此，它已经是一种中枢，却尚不是能够独立吞并所有旧权力中心的官僚国家。

# 十三、1261年死亡压力测试：本专题能够提前给出的判断

> 这里不完整推演昔木土之后三十天，只检验1260年形成的连接在忽必烈突然死亡时是否能自行延续。

## 1. 不会立即消失的部分

- 察必掌握的开平家政和子女；
- 中书省的文书、官印和部分财赋流程；
- 燕京宣慰人员及守军；
- 已配置的急递和粮运路线；
- 董文炳等依附较深的军政人员；
- 一部分已经抽入中央宿卫的汉军；
- 高丽王室与开平汗廷建立的关系。

所以忽必烈死亡不等于次日燕京政权自然解散。

## 2. 会在数日内暴露的核心问题

- 谁能使用忽必烈的印信发布最高命令；
- 察必能否以斡耳朵名义摄理；
- 真金是否在前线、开平或燕京，能否安全出现；
- 东道诸王是否承认父子继承；
- 前线军队由谁统帅；
- 中书省能否越过宗王直接命令世侯；
- 阿里不哥多久获知消息，并以何种名义号召重新归一；
- 廉希宪、史天泽、张柔等人身处不同地域，是否来得及共同表态。

## 3. 最可能出现的不是立刻全面倒戈，而是“合法性冻结”

各方在没有确认继承者前，可能采取：

- 暂停远距离调兵；
- 扣留粮饷；
- 守住本镇；
- 等待正式印信；
- 向不同宗王派使；
- 要求重新开会；
- 以保护皇子或大汗遗命为名控制关键人物。

这会使国家骨架继续存在，却失去跨集团的有效命令。

## 4. 各集团的第一选择倾向

| 集团 | 忽必烈突然死亡后的优先目标 | 对真金的可能态度 |
|---|---|---|
| 察必与开平斡耳朵 | 隐瞒或控制消息、保护子女、掌握印信 | 最可能推动真金，但需宗王和军队承认 |
| 刘秉忠、张文谦等中书人员 | 保持官署运转、起草遗命或拥立文书 | 倾向延续忽必烈路线，但缺乏武力 |
| 董文炳等近系军将 | 保护开平、燕京和皇子 | 较可能支持，但要看前线形势 |
| 史天泽集团 | 避免华北再乱、寻找可被广泛承认的共主 | 可能支持真金，也可能要求宗王会议 |
| 张柔集团 | 保全本部、质子和辖区，观察强弱 | 不会自动反对真金，但会重新议价 |
| 李璮集团 | 扩大自主权，避免被抽兵 | 高风险观望或利用权力真空 |
| 东道诸王 | 重新评估家系、军力和利益 | 支持忽必烈不等于接受未成熟父子继承 |
| 阿里不哥 | 宣称竞争汗廷因首领死亡而失效 | 必然反对直接父子继承，争取前盟友 |
| 关陇蒙哥旧军 | 等待廉希宪、宗王和阿里不哥多方命令 | 立场最易分裂 |

## 5. 时间尺度上的风险

| 时段 | 最可能维持的东西 | 最可能断裂的东西 |
|---|---|---|
| **死亡后0—3日** | 前线行营、近卫和家政网可控制消息；既有军令仍有惯性 | 新的最高命令无法合法签发 |
| **第4—10日** | 中书、燕京宣慰和驿站仍可处理日常事务 | 宗王、世侯会要求确认遗命、印信和继承者 |
| **第11—20日** | 若察必、真金和核心将领迅速合流，开平—燕京核心可守 | 外地军粮、关陇和宗王本部可能暂停执行命令 |
| **第21—30日** | 官署仍可能存在，局部守军仍可忠于忽必烈家族 | 阿里不哥开始以“恢复唯一汗权”为名重组联盟；世侯与宗王公开议价 |

这只是结构性压力测试，不等于已经确定的架空事件顺序。具体时间仍取决于昔木土战场位置、忽必烈死亡是否保密、真金所在地和阿里不哥获讯速度。

## 6. 压力测试结论

若忽必烈在1261年死亡：

- **一个月内，开平—燕京政权仍可能保持核心官署和若干军队；**
- **但它无法仅凭既有制度自动让真金继承；**
- **宗王支持、世侯兵权和前线军队都需要重新确认；**
- **阿里不哥会立即获得“竞争汗廷首领已死”的巨大政治机会；**
- **中书省可以维持行政，却不能替代忽必烈完成蒙古宗王之间的最高仲裁。**

因此，本专题对后续架空推演最重要的贡献是：

> 忽必烈在1260年确实创造了一个不会因他死亡而瞬间归零的政权核心；但这个核心还不足以独立完成汗位继承。拿掉忽必烈，体系会从“正在国家化的联盟”迅速退回“拥有官署和军队的多集团谈判场”。

# 十四、最终回答：忽必烈为何能迅速成为大汗候选人

忽必烈的迅速崛起不能归因于任何单一因素。

不是因为他“天然继承漠南”，因为蒙哥仍有平行官员，并曾调查、限制他的系统；燕京在1259年末也需要重新夺取。

不是因为“汉人拥戴”，因为史天泽、张柔、董文炳、李璮等集团来源、位置和利益不同，支持程度也不同。

不是因为开平会议已经完全合法，因为阿里不哥仍能在和林另行即位，西方主要兀鲁思没有共同参与。

也不是因为高丽世子带来决定性外援，因为该事件的军事实力贡献有限。

真正的原因是，忽必烈在1259年末拥有一种其他候选人暂时缺乏的**资源组合能力**：

1. 他有拖雷家系和年长宗王资格；
2. 他手中有一支仍保持组织的南征军；
3. 他在漠南经营多年，拥有可重新激活的官员、道路和财赋节点；
4. 开平斡耳朵和察必为他保留了家族、情报和政治中心；
5. 潜邸旧侣能把军队、文书、财政、外交和宗王会议组织在一起；
6. 汉军世侯愿意在保护地方利益的前提下与他结盟；
7. 东道及部分西道宗王的推戴提供最低限度的蒙古合法性；
8. 他迅速设置中书、宣抚、急递和宿卫，把联盟转化为可下达命令的机构；
9. 汉地粮食和军户又使这一机构比和林体系更有长期战争潜力。

所以，忽必烈不是从鄂州撤军后突然“建立元朝”。他做的是：

> **把蒙哥死亡后彼此分散的军事、行政、家族和宗王网络，抢在阿里不哥完全渗入漠南之前，围绕自己重新接通。**

这种成功真实而迅速，却没有消除结构性脆弱：

- 军队仍按将领和家族分层；
- 宗王支持仍是对忽必烈个人的支持；
- 中书和宣抚机构刚刚建立；
- 真金继承尚未制度化；
- 阿里不哥仍掌握和林和中央兀鲁思；
- 西方兀鲁思仍保持高度自主。

最终可以将1260年夏的忽必烈政权定义为：

> **以南征军为硬核、以开平斡耳朵为私人中心、以漠南行政财赋为后方、以汉军世侯和东道诸王为外圈、由潜邸旧侣编织起来的竞争性汗廷。**

它已经比一般宗王联盟更接近国家，却还没有成熟到能够轻易承受创建者在1261年突然死亡。

## 文档结语

专题一的军事快照显示，蒙哥死亡时没有任何人天然掌握帝国全部军队。专题二进一步说明，忽必烈之所以能迅速成为候选人，不是因为这道裂缝自动把漠南送给了他，而是因为他比其他人更快地完成了以下转换：

- 把奉命攻宋的军队转换为争位军；
- 把私人潜邸转换为中枢官署；
- 把旧有治理关系转换为宣抚和财赋网络；
- 把地方世侯转换为受约束但未完全中央化的盟友；
- 把部分宗王支持转换为开平即位；
- 把偶然外交事件转换为天命和臣属叙事。

这套转换在1260年足以创造一个能够与和林对抗的汗廷，却尚不足以保证创建者死后无缝继承。

因此，在后续“昔木土之后忽必烈重伤死亡”的架空推演中，最自然的爆点不是燕京官署一夜崩溃，而是：

> **官署仍在、军队仍在、粮道仍在、诏书也能继续发出；但所有人忽然发现，再没有一个被各方共同接受的人，能够证明这些东西为什么必须继续服从同一个中心。**
