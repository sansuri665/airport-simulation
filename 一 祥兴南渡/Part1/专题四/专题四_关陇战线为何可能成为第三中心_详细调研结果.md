# 专题四：关陇战线为何可能成为第三中心
## 1257—1261：京兆、六盘山、河西、巩昌与四川之间的军政拼接

> **研究目标**  
> 本专题承接前三个专题，但不把关陇只当作忽必烈—阿里不哥战争的“西线支战场”。它要回答的是：
>
> **1257—1261年间，关陇的军权、钱粮、道路和合法命令究竟掌握在谁手里；1260年阿蓝答儿、浑都海失败以后，关陇是否真的成为忽必烈可以直接调度的稳定后方；若忽必烈在1261年昔木土脑儿之战后重伤死亡，秦蜀行省为什么可能先形成一个名义奉真金、实际保境自决的第三军政中心。**

---

# 核心判断

1259—1261年的关陇不是一块已经被某一方完整控制的地域，而是七套力量叠加形成的军事走廊：

1. **忽必烈的京兆分地与潜邸旧网络**：廉希宪、商挺、赵良弼等人留下的官员、账册、仓储和地方关系；
2. **蒙哥大汗中央留下的司法—财政权力**：阿蓝答儿、刘太平等曾以中央名义调查河南、陕西官署；
3. **蒙哥亲征四川形成的六盘山—四川旧军链**：浑都海、哈剌不花及各路入川军、辎重和奥鲁；
4. **西道宗王本部**：合丹、合必赤、只必帖木儿等宗王拥有自己的军队、份地和政治判断；
5. **巩昌汪氏家族军事集团**：汪良臣、汪惟正及其控制的陇右、青居、四川接口军；
6. **纽璘及四川蒙古军**：拥有相对独立的野战军、奥鲁、降附人口和前线任务；
7. **京兆、平阳、太原及州县财政—驿路体系**：屯田、盐课、府库、交钞、兵籍和黄河渡口把华北资源接入关陇。

1260年的胜利并没有把这七层压缩成一支“忽必烈直属西军”。它真正完成的是：

- 杀死阿里不哥最重要的两个西线代理人；
- 阻止六盘山旧军与和林来军合并后向京兆东进；
- 以廉希宪为政治组织者，把宗王、行省官署、汪氏巩昌军、八春节制系统与纽璘奥鲁临时拼成一个共同阵线；
- 在京兆设置秦蜀行中书省，为这些本来互不隶属的力量提供共同的文书、钱粮和紧急决策外壳。

因此，本文把1261年的秦蜀体系定义为：

> **一个由薄层行省官署包裹的战时保境联合体。**

它已经具备部分国家能力：

- 能使用印信和文书；
- 能动用京兆府库、赏银和军服；
- 能确认或临时授予军职；
- 能协调宗王、本地家族军和四川统帅；
- 能处理军粮、屯田、盐课、驿站和边境急务；
- 能在中央路远、消息延迟时便宜行事。

但它没有形成稳定的最高政治权：

- 廉希宪不能把宗王本部变为自己的直属军；
- 汪氏、纽璘和四川诸帅仍保有独立兵权与地方利益；
- 行省缺乏成吉思汗家族的最高合法性；
- 山西、河西与四川前线的供给都可能中断；
- 真金尚未拥有成熟的皇太子继承制度；
- 南宋会持续利用任何北调与粮道空隙。

所以，忽必烈死亡以后，关陇最可能出现的第一形态不是立刻称帝、立刻投降阿里不哥，也不是无条件听命燕京，而是：

> **在真金名义下维持秦蜀原有官署和军队，由廉希宪—商挺、宗王、汪氏和纽璘共同决定紧急军务；对燕京承认名义上的共同阵营，却拒绝在继承权未定、山西转输未恢复以前交出西线调兵权。**

这就是“第三中心”的含义：它不是已经独立的国家，而是一个能够在三至六个月内自行维持、扣留兵粮、同燕京和和林分别议价，并决定蒙古西线战争能否继续的区域军政中心。

# 文档说明

## 一、时间范围

- **前史：1253—1257年。**忽必烈取得京兆相关分地并建立宣抚、屯田和军需网络；蒙哥随后派阿蓝答儿、刘太平调查河南、陕西官署。
- **军事形成期：1258—1259年。**蒙哥在六盘山集结并亲征四川，关中、巩昌、河西、四川和山西形成重叠的兵粮与指挥链。
- **主体：1259年8月至1261年昔木土脑儿战役前后。**蒙哥死亡、阿蓝答儿和浑都海响应阿里不哥、1260年西线战役、秦蜀行省建立，以及1261年四川前线和地方财政的运行状态。
- **反事实延伸：忽必烈死亡后的30日、90日与180日。**
- **必要后视：1262—1264年。**只用来检验秦蜀行省后来能够处理哪些事务，不将后来的制度成熟度倒推到1261年。

## 二、地理范围

本文所说的“关陇战线”不是现代行政区，而是以下节点组成的系统：

| 区域 | 核心节点 | 主要功能 |
|---|---|---|
| 关中中枢 | 京兆、凤翔、河中 | 官署、府库、屯田、盐粮、兵籍和政治协调 |
| 陕北屏障 | 延安、绥德、陕北黄河渡口 | 阻断河套—山西—关中的北来路线 |
| 山西接口 | 平阳、太原、西京、河东渡口 | 华北兵员、马匹、军械、银钞与驿递入口 |
| 陇右军事带 | 巩昌、六盘山、临洮、秦州 | 蒙哥旧军、汪氏军、入川道路和西北牧地 |
| 河西走廊 | 灵州、凉州、甘州、山丹、焉支山、肃州 | 和林—唐兀—关陇代理人、辎重和军队移动路线 |
| 秦蜀接口 | 兴元、利州、剑门 | 关中向四川输粮、调军和传递命令的山地走廊 |
| 四川前线 | 成都、潼川、青居、合州、重庆、泸州 | 蒙哥旧军、宋蒙边境、水陆粮道与降将网络 |

## 三、六种“控制”必须分开

| 控制类型 | 本文实际判断什么 | 不能据此自动推出什么 |
|---|---|---|
| 法统与命令 | 谁能发诏、授职、使用印信、召宗王或继承旧命令 | 有名义便能让所有军队执行 |
| 军队 | 主将、兵源、奥鲁、驻地、军械与实际参战 | 官称万户等于实到万人 |
| 财政 | 府库、税赋、盐课、交钞、借贷、屯田与实收 | 设行省便有稳定年度财政 |
| 道路与粮运 | 渡口、驿马、车畜、牧草、市场和季节 | 地图上有道路便能通过大军 |
| 地方政治 | 宗王投下、家族军、达鲁花赤、州县官和质子关系 | 一次奉命等于永久归附 |
| 信息 | 使者、牌符、截使、消息到达日期和伪命风险 | 文书发出便同时传到各地 |

## 四、证据等级

| 等级 | 含义 |
|---|---|
| **A级：直接可证** | 原始史料有明确人物、行动、任命、地点、钱粮或军队记录 |
| **B级：交叉重建** | 两条以上材料可互证，但日期、地名或隶属仍有缺口 |
| **C级：条件性推论** | 用于解释战略和反事实，明确标出前提 |
| **缺口** | 现有材料不足，不用估算填平 |

## 五、主要史料警戒线

1. 《元史》把阿蓝答儿、浑都海写成“反”“乱”，把结果写成“西土悉平”，服务于世祖正统叙事。
2. 廉希宪、商挺、汪良臣等传记都有突出传主先见与战功的倾向。
3. 同一战役在本纪和列传中出现姑臧、西凉、甘州东、山丹、耀碑谷、合纳忽失温等不同地名，不能强行压成一个地点。
4. 秦蜀行省正式设立不等于所有军籍、府库、道路和州县在同一天完成移交。
5. 1262—1264年的财政、急递和四川军政分工只能说明后来能够发展到什么程度，不能直接证明1261年已经完全具备。
6. “第三中心”是分析概念，指区域议价与自主行动能力，不等于关陇已经建立独立王朝。

# 一、摘要：十一项中心结论

## 1. 1257年的阿蓝答儿钩考首先是权力追究，不只是查账

阿蓝答儿、刘太平进入河南、陕西，不应简单理解为现代意义上的财政审计。周思成的制度研究指出，这次行动更接近蒙古札鲁忽赤主持的 **yārghū** 司法程序：由大汗中央对忽必烈藩府所任官员进行贪污、税赋和渎职调查。

它具有四种效果：

- 中央人员取得接触京兆账册、官员和钱谷的合法程序；
- 忽必烈旧有宣抚与经略机构遭撤罢或削弱；
- 廉希宪、商挺等潜邸旧人受到追责与排斥；
- 阿蓝答儿获得一种“代表蒙哥中央重新划定关陇权力”的履历。

所以1260年阿蓝答儿能够向西线发命，并非一位外来将领突然闯入，而是1257年中央调查权在大汗死亡后被其重新解释和扩张。

**结论等级：A/B。**

## 2. 蒙哥死亡时，关陇至少存在七条彼此交叉的命令链

京兆旧宣抚、蒙哥中央、六盘山旧军、西道宗王、汪氏、纽璘四川军和州县财政各有直接上级。蒙哥同时是大汗、四川战役统帅和最终资源分配者，他的死亡使这些命令链失去共同仲裁者。

因此，关陇危机不是“阿里不哥军入侵忽必烈领土”，而是原本同属蒙哥体系的不同人员重新解释自己有权听谁。

**结论等级：A。**

## 3. 浑都海的核心不是和林来军，而是六盘山—四川旧军关系

浑都海原本与蒙哥亲征体系、六盘山府库和四川将领有关系。阿里不哥派使召他后，他拒绝耶律铸等人的劝说，控制辎重和随行家属，并沿灵州—西凉—甘州方向移动。

这说明浑都海掌握的至少包括：

- 一部分六盘山旧军；
- 战役府库、辎重或其控制权；
- 与哈剌不花等四川旧将的上下级或旧部关系；
- 对军属和随军人口的强制能力。

**结论等级：A/B。**

## 4. 阿蓝答儿是中央命令和远方代理的连接者

阿蓝答儿从和林方向率军至焉支山，与浑都海会合，并尝试联络陇、蜀诸将、招诱纽璘。这说明他承担的是：

- 把阿里不哥汗廷命令带到河西；
- 将六盘山旧军与蒙古本土来军合并；
- 重新确认蒙哥旧臣的合法地位；
- 把西部地方行动包装为大汗继承战争的一部分。

他与浑都海的资源来源不同，不能合称为一支天然统一的“西路军”。

**结论等级：A。**

## 5. 廉希宪稳定关陇的核心是组织能力，不是直属兵力

廉希宪的实际工具包括：

- 忽必烈授予或追认的宣命、虎符、银印和便宜权；
- 对京兆官署、府库和旧人网络的熟悉；
- 赵良弼等人的情报；
- 先发制人处置刘太平、霍鲁海；
- 自出虎符、银印和一万五千两白银组织汪氏等军；
- 释放纽璘奥鲁官员、把可能倒戈者转化为数千精骑；
- 说服合丹等宗王和八春、汪良臣共同出兵；
- 阻止朝廷因初战不利而放弃两川。

他是政治组织者、资源调拨者和联盟中介，不是每支部队的直接野战统帅。

**结论等级：A。**

## 6. 1260年的西线胜利是多集团联合作战

不同材料分别把胜利归于合丹、合必赤、八春、汪良臣、按竺迩、李忽兰吉等人。异文并不只是史书记错，也可能反映：

- 多路部队分别行进；
- 数月对峙和多次接战；
- 宗王拥有名义总领地位；
- 汪氏、按竺迩等地方军承担具体战斗；
- 廉希宪和商挺负责组织、钱粮和命令。

所谓“廉希宪平叛”应改写成：

> 廉希宪主持建立共同阵线，宗王提供成吉思汗家族的军事合法性，八春承担节制，汪氏及其他西北军队完成主要野战。

**结论等级：A/B。**

## 7. “西土悉平”只意味着主力威胁解除

阿蓝答儿、浑都海被杀后：

- 残部北走，推哈剌不花为帅；
- 一部分被收编、释放或返回原驻地；
- 六盘山旧军和四川军仍由各自主将掌握；
- 河西道路、唐兀人口与旧使者网络仍存在；
- 西部宗王仍保有本部和份地。

1260年的胜利摧毁了阿里不哥最重要的西线代理人首脑，却没有消除重新联络这些资源的可能。

**结论等级：A。**

## 8. 秦蜀行省是宣抚体系的临战升级，而非成熟地方国家

1260年八月设秦蜀行中书省，廉希宪任中书右丞、行省事。现代行省研究指出，这一机构的前身正是八春、廉希宪、商挺等主持的陕西—四川宣抚体系；此时行省仍以临时处理军政为主，辖区和节制关系尚不稳定。

它的建立说明忽必烈承认：西线不能只靠远方中书逐事请示，必须给予本地官署更高的命令和资源整合权。

**结论等级：A。**

## 9. 山西是关陇的关键接口，却不是一根可随意开关的中央管道

1260年平阳与京兆共同签发七千守隘军，分守延安等北部通道；河东、太原和平阳又有术赤系、察合台系投下和地方军政网络。

因此，山西若“中立”，必须区分：

- 停止官府转输但允许市场交易；
- 宗王中立且允许使者和商队通行；
- 宗王主动为阿里不哥提供驿马、粮食与渡口。

只有第三种状态才会迅速把关陇北部门户变成军事危机。第一种状态更可能造成三至六个月的慢性财政、马匹和军械短缺。

**结论等级：A/C。**

## 10. 南宋四川方面不会只是旁观者，但也难成为可靠盟军

1261年刘整以泸州方向军政资源降蒙，宋方俞兴随即组织反击；此后泸州、青居、合州、重庆等地仍持续争夺。

若忽必烈死亡，宋方最可能首先：

- 侦察蒙古军是否北调；
- 争夺堡寨、渡口和水路；
- 招诱降附人口或地方将领；
- 局部恢复贸易或交换俘虏；
- 在有利时接受短期停战，却不承担保护秦蜀行省的义务。

**结论等级：A/C。**

## 11. 关陇成为第三中心的最可能形式是“奉真金而保境”

秦蜀体系的官员大多依赖忽必烈授职，汉军和地方官也更担心阿里不哥恢复旧中央后重新调查和征发。因此，它最可能在政治上继续使用真金名义。

但若燕京发生军府政变、不能确认原官职、停止山西输送或要求大规模抽调西军，关陇会优先保全：

- 京兆府库；
- 六盘山和陕北门户；
- 巩昌与青居军；
- 四川粮道；
- 行省印信和军籍。

于是出现一个“名义同阵营、实际不受燕京直接指挥”的第三中心。

**结论等级：C。**

# 三、关陇的战略结构：为什么它不是普通后方

## 1. 它同时连接五个政治空间

```text
                    和林—蒙古本土
                          │
               河西 / 唐兀 / 河套通道
                          │
        ┌────凉州—甘州—山丹────┐
        │                         │
   六盘山—巩昌—临洮          陕北—黄河渡口
        │                         │
        └────────京兆─────────平阳—太原—燕京
                          │
                兴元—利州—剑门
                          │
              成都—潼川—青居—重庆
                          │
                    南宋四川防区
```

任何一方控制关陇，都不只是获得长安，而是获得：

- 蒙古高原向四川的西南通道；
- 河西与关中的人员和粮道；
- 山西向西部输送兵马的接口；
- 四川蒙古军的北方后方；
- 对南宋四川战场的资源配置权。

## 2. 京兆的优势不等于自给自足

京兆具有官署、府库、市场、屯田与政治声望，但仍依赖：

- 山西和华北输入的银、马、军械和部分兵员；
- 河西、陇右的牧马和地方军；
- 兴元、利州道路与四川军协同；
- 宗王提供蒙古军事合法性；
- 州县和豪强实际执行征发。

所以京兆可以成为协调中心，却难单独吞并其他节点。

## 3. 六盘山的价值在于“控制旧战役体系”

六盘山不仅是地理关口，也是：

- 蒙哥亲征的初始集结地；
- 四川远征辎重和府库节点；
- 蒙古军、探马赤、汉军和随军人口的汇合处；
- 通往河西、关中和四川北部的分叉点。

浑都海据六盘，危险不在于一支军队距长安有多近，而在于他可能代表蒙哥旧军继续解释谁有权使用府库、军籍和辎重。

## 4. 巩昌汪氏是“地理粘合剂”

汪氏势力横跨：

- 巩昌地方社会；
- 陇右兵源；
- 利州、青居等四川节点；
- 蒙古宗王和大汗任命；
- 家族军和质子关系。

他们可以把京兆命令传向四川，也可以在中央失联时保全本镇。正因如此，汪氏既是秦蜀联合体的支柱，也是未来自主化的潜在基础。

## 5. 四川前线使关陇无法纯粹北顾

即使阿里不哥威胁上升，秦蜀体系仍不能放空：

- 成都；
- 青居；
- 合州；
- 重庆；
- 泸州；
- 兴元—利州粮道。

南宋的存在迫使关陇始终保留一部分军队和财政在南线。这会减弱其对阿里不哥的主动进攻能力，却增强其“不能接受远方随意调兵”的自主诉求。

# 四、1257年的阿蓝答儿钩考：究竟改变了什么

## 1. 传统“查账”解释为什么不够

如果只把阿蓝答儿事件写成财政审计，很难解释：

- 为什么廉希宪等人把它视为严重政治危机；
- 为什么宣抚、经略机构随之撤罢或削弱；
- 为什么阿蓝答儿在蒙哥死后仍能以中央旧臣身份介入西部军政；
- 为什么1257年的冲突会在1260年变成武装站队。

周思成的研究把它放回蒙古断事官和 **yārghū** 司法体系，更能解释其政治性质。

## 2. 四层调查对象

| 层次 | 可能调查内容 | 对权力结构的影响 |
|---|---|---|
| 钱谷 | 税赋、军需、盐粮和官物出纳 | 中央取得账册和追责权 |
| 官员违法 | 贪污、渎职、擅权 | 潜邸任命者的官职合法性受挑战 |
| 藩府权限 | 忽必烈是否越过大汗任官、征发和经营财赋 | 重新划定漠南宗王权力边界 |
| 政治忠诚 | 官员究竟首先听忽必烈还是蒙哥中央 | 为后来的站队留下人员分裂 |

## 3. 廉希宪为何与阿蓝答儿早有冲突

《廉希宪传》记，调查到京兆后，廉希宪主动承担责任，使同僚获免。这一叙事可能带有名臣塑造，却至少证明：

- 廉希宪是忽必烈京兆体系的重要责任人；
- 调查直接触及他和同僚的任职；
- 双方对“谁有权治理京兆”已有明确冲突；
- 1260年廉希宪不会把阿蓝答儿视为普通军事对手，而会视为蒙哥旧中央权力的复归。

## 4. 商挺所反映的机构中断

商挺传记把1257年钩考与宣抚机构撤销、本人东归联系起来。它说明调查结果不仅是罚款或处分，而是：

- 中止忽必烈旧有官署；
- 使账册和人事关系分散；
- 把京兆重新置于大汗中央和地方军头的多头管理中。

## 5. 蒙哥死亡后，阿蓝答儿能继承什么

较有依据的部分：

- 中央札鲁忽或调查官的政治身份；
- 对京兆、河南官员和财赋结构的知识；
- 与刘太平、霍鲁海等蒙哥旧属的关系；
- 以蒙哥旧命令为自己行动辩护的能力；
- 从和林取得新命令后联络旧人员的渠道。

不能确认的部分：

- 他是否持有蒙哥原印信；
- 是否获得所有调查机构人员；
- 是否能直接支配京兆府库；
- 是否在1259年即已明确支持阿里不哥；
- 所率军队中多少是旧调查机构兵力、多少是1260年新征军。

## 6. 1257年事件的最终作用

> **它把关陇从“忽必烈经营区”重新变成了一个权力来源相互重叠的地区。**

如果没有这次调查，1260年的阿蓝答儿更像外部入侵者；有了这次前史，他可以向部分官员和军队宣称：

- 自己原本就是大汗中央派来的执行者；
- 忽必烈开平即位尚未获得普遍承认；
- 继续服从蒙哥旧中央比服从廉希宪更具连续性。

这正是西线危险程度高于普通地方叛乱的原因。

## 2. 多头命令不是偶然混乱，而是蒙古帝国的正常结构被大汗死亡放大

蒙古帝国原本就允许：

- 宗王拥有份地和本部；
- 大汗越过地方宗王直接任命人员；
- 战役统帅临时节制不同来源军队；
- 家族军保留自己的奥鲁和首领；
- 地方官署同时服务税收与军需。

蒙哥在世时，这些层级能由大汗最终裁决；蒙哥死亡后，同一制度结构立即变成竞争者可以利用的多重合法性。

# 六、阿蓝答儿与浑都海：两种不同的西线力量

## 1. 浑都海的资源结构

### A. 六盘山旧军和府库

汪良臣传称阿蓝答儿、浑都海“劫六盘府库”。“劫”是胜利者史学的道德定性，但这条记录至少证明：六盘山不是一处空营，那里存在能够被主将掌握的仓储、军械、辎重或战役性财政资源。

六盘山在蒙哥亲征前承担过大军集结、辎重停放和道路分派功能。蒙哥死后，留守人员、回撤军、军属与府库的归属并没有一套预先规定的自动继承程序。谁能够控制这里，谁便能尝试把“蒙哥远征军的后方遗产”转化为新汗位战争的军资。

### B. 蒙哥四川旧军关系

商挺、耶律希亮等材料把哈剌不花写成四川旧将，又显示浑都海同其存在上下级、旧部或战役协作关系。阿蓝答儿、浑都海失败后，残军还能推哈剌不花为帅，说明这支力量的组织记忆来自蒙哥征蜀军，而不是1260年才临时拼凑的征兵。

较可靠的推断是：

- 浑都海能够接触六盘山一带的旧战役军；
- 部分军人首先认直接将领和蒙哥旧军身份；
- 阿里不哥的命令需要借浑都海这类中介才能进入旧军；
- 即便浑都海死亡，旧军仍可能围绕其他高级将领重新组织。

### C. 军属、辎重和强制能力

耶律希亮家族被浑都海控制并随军西行，反映其集团不是纯粹轻骑突击队，而包含：

- 战斗人员；
- 官员与书记；
- 家属、质子和奥鲁人口；
- 车畜与辎重；
- 对反对者实施扣押、追捕和裹挟的力量。

这类军队移动较慢，却比纯粹临时征集军更像一个可延续的军事社会。它的目标也可能不只是打一场战役，而是保存蒙哥旧军、家属和府库，等待继承局势明确。

### D. 与阿里不哥的关系

阿里不哥派使召浑都海，是其公开站队的重要节点。现有材料不能证明浑都海原本就是阿里不哥的私人旧部。更合理的描述是：

> **一名控制蒙哥西部旧军与后勤节点的将领，在大汗死亡后接受和林竞争汗廷的新命令。**

这也解释了为什么他的服从具有条件性：他接受阿里不哥，不等于自己的军队、府库和旧部从此成为阿里不哥可以直接跨区调遣的私产。

## 2. 阿蓝答儿的资源结构

### A. 中央政治身份

1257年的调查经历使阿蓝答儿熟悉：

- 京兆和河南官员；
- 财赋、军需和违法追究；
- 忽必烈潜邸旧人；
- 蒙哥中央的司法与文书语言；
- 西部官署中哪些人因钩考受益、受损或被撤换。

他的优势不一定是拥有更多私人军队，而是能将阿里不哥的新命令包装成蒙哥中央权力的延续。

### B. 和林来军

耶律希亮传明确记载阿蓝答儿自和林方向率军到焉支山。其兵数无法确认；现有“大军”“数万”等概数不能直接使用。但至少可以确认：

- 这是一支能跨越蒙古本土—唐兀—河西路线的分队；
- 有足够组织维持数千里行军；
- 它能够同浑都海旧军会合；
- 阿蓝答儿拥有阿里不哥汗廷认可的指挥身份。

### C. 合并和联络任务

《廉希宪传》所见，阿蓝答儿与浑都海合军后：

- 分头联络陇、蜀诸将；
- 让纽璘之兄宿敦写信招诱纽璘；
- 试图让奥鲁、旧军和地方将领重新站队；
- 将河西战事与大汗继承争议连接起来。

所以阿蓝答儿的最大价值不是单纯增加一支军队，而是完成以下转换：

```text
和林汗廷的政治命令
          ↓
阿蓝答儿的中央旧臣身份与使者网络
          ↓
河西、六盘山、陇右和四川旧军
          ↓
一条可能绕过京兆、牵制忽必烈北上的西线
```

## 3. 为什么二人不能合称为天然统一的“阿里不哥西路军”

| 项目 | 阿蓝答儿 | 浑都海 |
|---|---|---|
| 核心身份 | 中央调查与司法—政治执行者、阿里不哥代理人 | 蒙哥西部旧军与六盘山节点将领 |
| 主要资源 | 和林命令、远征分队、书记与联络能力 | 旧军、辎重、府库、军属和地方军事关系 |
| 权力来源 | 阿里不哥汗廷＋蒙哥中央旧身份 | 蒙哥亲征体系＋个人军中威望 |
| 优先目标 | 合并代理网络、联络陇蜀、扩大合法性 | 保存旧军、会合援军、控制西部通道 |
| 主要弱点 | 远离和林后依赖本地执行者 | 缺乏全帝国法统，军队行动受辎重拖累 |

二人合作是一次政治—军事拼接，而非同一组织内部两个普通将领的协同。

## 4. 为什么浑都海没有直接扑向京兆

不能只用“畏惧廉希宪”解释。至少存在四个更实际的原因。

### 原因一：先合并远方资源

浑都海若独自东攻，可能遭京兆守军、平阳援军、西道宗王与汪氏夹击。向河西移动能等待阿蓝答儿和蒙古本土援军。

### 原因二：河西更适合联络唐兀和蒙哥旧军

甘州、凉州、山丹和焉支山位于和林—河西—六盘之间，是使者、马匹、军队与牧草较容易汇集的带状空间。

### 原因三：辎重与军属限制速度

浑都海并非轻装骑兵突袭。携带府库、军属和官员会使其更依赖旧军路和绿洲节点，难以快速强攻京兆。

### 原因四：初始目标可能是保存和重组，而非立刻占城

其阶段性目标可能依次是：

1. 阻止蒙哥旧军被忽必烈接收；
2. 会合和林来军；
3. 等待更多宗王与四川将领表态；
4. 再决定东攻京兆、北归和林或控制河西。

## 5. 军队组成：只能分层，不能给总数

| 可能成分 | 依据 | 确定程度 |
|---|---|---|
| 六盘山蒙古军与蒙哥旧军 | 浑都海驻六盘、四川旧将关系 | 高 |
| 河西、唐兀地方军 | 行动区域、战后镇戍与补给需要 | 中 |
| 阿蓝答儿自和林带来的部队 | 耶律希亮传明确记载 | 高 |
| 陕西、巩昌或四川响应者 | 招诱纽璘、奥鲁官响应 | 高，但规模不明 |
| 临时签军、军属和后备 | 府库、征发与随行家属证据 | 中 |
| 特定宗王本部 | 尚无足够材料确认 | 低 |

## 6. 代理人联盟的内在弱点

- 阿蓝答儿的权威来自阿里不哥和中央旧身份；
- 浑都海的权威来自六盘山旧军和个人控制；
- 哈剌不花拥有自己的旧部和婚姻关系；
- 四川奥鲁与纽璘本人并不必然同一立场；
- 河西地方力量更关心道路、赋役和生存，不会无条件追随；
- 一旦主将战败，统一最高指挥很容易重新分裂。

# 七、廉希宪稳定关陇究竟靠什么

## 1. 情报：先知道谁在动

廉希宪在忽必烈即位前后即判断：

- 刘太平、霍鲁海在关中；
- 浑都海据六盘；
- 南征军散在秦、蜀；
- 若这些力量串联，京兆将难以控制。

他建议派赵良弼侦察。其核心不是“神奇预言叛乱”，而是建立一张可操作的情报图：

- 人物最近位置；
- 命令来源；
- 哪些将领可能站队；
- 哪些道路仍可通行；
- 京兆还有多少反应时间。

## 2. 法统：让自己的命令被军人承认

廉希宪需要的不是普通地方官印，而是能够被蒙古军将承认的：

- 忽必烈宣命；
- 虎符；
- 银印；
- 中书或行省职位；
- “事当从宜，毋拘常制”一类追认性便宜权。

这些工具使他能够解释：

- 为什么可以处置蒙哥旧臣；
- 为什么可以调用府库；
- 为什么可以确认军官；
- 为什么地方官应拒绝阿里不哥使者；
- 为什么紧急军令可以先执行、后奏报。

## 3. 先发制人：处置刘太平、霍鲁海

刘太平、霍鲁海赶到京兆后，廉希宪将其拘捕并处决；即使赦令随后到达，他仍以事情已决处理。无论传记是否强化了决断色彩，此举的战略效果相当明确：

- 阻止阿里不哥在京兆城内形成官署核心；
- 使地方官知道等待和林命令可能付出生命代价；
- 清除阿蓝答儿、浑都海的城市联络者；
- 把争议从“谁代表蒙哥旧中央”改造成“谁控制京兆现有官署”。

但这也制造长期裂缝：蒙哥旧臣与相关军队可能更害怕被清洗，从而转向武装自保。

## 4. 财政：把府库变成联盟黏合剂

《廉希宪传》记其：

- 给汪氏等将领虎符、银印；
- 发白银一万五千两；
- 以缯帛制作军服；
- 组织四川戍军和奥鲁余丁；
- 在紧急情况下先行动、后请示。

这些记录说明京兆府库至少能够支持一次高强度临时动员，但不能据此推断它拥有稳定多年财政。钱粮的作用不只是购买物资，更是：

- 证明新汗廷能兑现赏赐；
- 让地方将领承担风险时获得补偿；
- 把原本只听家族首领的军队暂时拉入共同战役；
- 让宗王本部在缺乏自带辎重时能够继续行动。

## 5. 赦免和改编：释放纽璘奥鲁官

八春逮捕纽璘奥鲁官及其党五十余人后，廉希宪没有全部处决，而是判断：

- 军心尚未稳定；
- 若杀将校，部队可能彻底倒向浑都海；
- 释放并给予效力机会，更能获得兵力。

传记称由此得到数千精骑。数字不宜机械使用，但事件本身极能说明秦蜀联合体的性质：

> 部队并非因一纸诏书已经归属忽必烈；它们是在将领安全、奥鲁存亡、旧关系与现实奖惩之间重新选择。

## 6. 宗王协调：合丹等人为什么必须出现

廉希宪有官署和钱粮，却没有成吉思汗家族身份。西道宗王参战带来：

- 对蒙古军的法统说服力；
- 本部骑兵；
- 战役总领资格；
- 对阿里不哥“只有蒙古本土才合法”的反驳；
- 对地方将领军功与官职的宗王层级确认。

因此，战役不可能由廉希宪独立完成。

## 7. 八春、汪氏与其他将领：野战执行层

八春受命节制陕西四川诸军；汪良臣在黄河关隘、巩昌和河西战役中承担具体作战；按竺迩、李忽兰吉等又带来自己的军队。

廉希宪真正完成的是：

```text
忽必烈新汗廷的法统
          │
廉希宪—商挺的官署、情报和钱粮
          │
合丹等宗王的家族合法性与本部军
          │
八春的节制名义
          │
汪氏、按竺迩、巩昌及地方军的野战执行
          │
纽璘奥鲁和四川军的选择性合作
```

## 8. 廉希宪能做与不能做的事

| 能做 | 不能自动做到 |
|---|---|
| 以行省或宣抚名义发布文书 | 让宗王本部永久成为直属军 |
| 动用部分府库和赏银 | 保证数年稳定税收 |
| 确认和临时授予军职 | 取消汪氏、纽璘的家族与个人兵权 |
| 组织联军和分配任务 | 亲自指挥每场野战 |
| 赦免、处决和改编部分人员 | 消除所有蒙哥旧臣的不安 |
| 封锁道路、收集情报 | 控制整个河西和山西驿路 |
| 在紧急情况下便宜处置 | 独立决定大汗继承和长期对宋政策 |

## 9. 廉希宪的不可替代性究竟在哪里

他并不是唯一能带兵的人，也未必是最强野战将领。其真正不可替代性在于同时能同五类主体沟通：

- 忽必烈汗廷与中书；
- 蒙古宗王；
- 汉地官署与府库；
- 汪氏、纽璘等地方军事集团；
- 四川边境和州县财政。

若忽必烈死亡后又失去廉希宪，秦蜀体系不会只是“少一个名臣”，而是失去将合法性、钱粮和多支军队翻译成共同命令的主要连接器。

# 八、1260年西线战役：史料异文与暂定重建

## 1. 主要史料的地点和时间并不一致

| 史料 | 时间 | 地点表述 | 主要参战者 | 叙述重点 |
|---|---|---|---|---|
| 《元史·世祖纪一》 | 中统元年九月 | 姑臧一带／陇右 | 合丹、合必赤、汪良臣等 | 主将伏诛，“陇右悉平” |
| 《廉希宪传》 | 未精确到日 | 西凉 | 合丹、汪良臣、八春等 | 初战失利后反胜，廉希宪坚持不弃两川 |
| 《商挺传》 | 中统元年 | 甘州东 | 合丹、八春、汪良臣三路 | 战前判断、风沙中决战 |
| 《汪良臣传》 | 对峙两月后 | 山丹—耀碑谷 | 汪良臣等 | 地方军野战功劳 |
| 《按竺迩传》 | 中统元年 | 山丹耀碑谷 | 按竺迩、阿曷马、汪良臣 | 老将出兵和风沙战 |
| 《李忽兰吉传》 | 十月 | 合纳忽失温 | 宗王合必赤、李忽兰吉等 | 巩昌集团参战 |
| 《耶律希亮传》 | 事件顺序 | 焉支山、甘州、肃州等 | 阿蓝答儿、浑都海、哈剌不花 | 会合、败后残军北走和人质经历 |

## 2. 为什么不能强行选择唯一地点

这些记载可能包含三种情况：

1. 同一场大战被不同传记用附近区域命名；
2. 数月内实际发生多次接战，各传只突出本部参战的一次；
3. 后来的碑传和本纪对日期、地名进行了压缩、错置或战功重组。

因此本文不把“姑臧”“甘州东”“山丹耀碑谷”和“合纳忽失温”强行判成同一地点，也不把所有功劳归给单一将领。

## 3. 暂定事件链

### 第一阶段：六盘山危机

- 浑都海接受阿里不哥使者；
- 控制六盘山府库、旧军和辎重；
- 京兆方面处置刘太平、霍鲁海并做城防准备；
- 各地尚不确定阿里不哥与忽必烈谁能代表大汗法统。

### 第二阶段：浑都海西移

- 浑都海没有立即进攻京兆；
- 由灵州等处向西凉、甘州方向移动；
- 携带或控制随军家属、官员和辎重；
- 一面等待和林援军，一面保留北归或控制河西的选择。

### 第三阶段：阿蓝答儿南下会合

- 阿蓝答儿自和林率军到焉支山；
- 与浑都海会合；
- 联络陇蜀诸将，招诱纽璘；
- 哈剌不花一度与其集团相连，后来可能分路北行；
- 阿里不哥西线网络从政治联络升级为联合军行动。

### 第四阶段：京兆联合体完成动员

- 廉希宪调动府库和旧人；
- 八春节制陕西四川诸军；
- 合丹、合必赤等宗王出兵；
- 汪良臣、按竺迩、李忽兰吉等分路推进；
- 纽璘奥鲁部分被释放后转为效力；
- 平阳、京兆共同加强陕北守隘。

### 第五阶段：初战不利与河西震动

- 八春等部可能遭遇失利；
- 西部宗王辎重空虚，需要“就食秦雍”；
- 朝廷一度讨论放弃两川、退守兴元；
- 说明阿蓝答儿、浑都海并非轻易溃败，西线确有使关中震动的能力。

### 第六阶段：山丹—甘州—西凉区域决战

- 双方可能对峙约两月；
- 风沙成为多条传记共同保存的细节；
- 合丹等宗王提供总领，汪良臣、按竺迩等承担主要战斗；
- 阿蓝答儿、浑都海被俘杀或战败后处决；
- 具体地点与月份只能保留范围，不制造虚假精确。

### 第七阶段：残部北走

- 残军推哈剌不花为帅；
- 经肃州、天山、北庭等方向撤退；
- 一部分军属和官员继续被裹挟；
- 证明代理网络并未随二人死亡立即消失。

## 4. 为什么战场集中在河西而不是京兆城下

- 浑都海需要会合和林援军；
- 河西有更适合骑兵、牧马和远程移动的空间；
- 京兆已有城防、府库和多路援军；
- 西部军队可能优先保护回和林或中亚的通道；
- 战役的核心是争夺旧军、道路与政治归属，不只是占领城市；
- 远征集团携带军属与辎重，不适合直接进行高速攻城。

## 5. 实际战果

可以确认：

- 阿蓝答儿、浑都海被杀；
- 其合军失去最高执行者；
- 京兆和四川没有被迫放弃；
- 忽必烈获得重要政治胜利；
- 汪氏、宗王和廉希宪地位上升；
- 残部仍有组织地向北、西撤退。

不能确认：

- 双方总兵数；
- 一次决战还是多次战斗；
- 主将具体被俘或战死的瞬间；
- 所有残军最终归属；
- 河西各州何时恢复稳定税收；
- 参战宗王本部何时离开西线。

## 6. 战役最重要的政治后果

这场胜利证明忽必烈能够调动跨区域联盟，却也暴露新政权的结构：

- 中书和行省提供不了全部现成兵力；
- 宗王、家族军和四川军必须分别谈判；
- 钱粮和符印比抽象法统更能决定地方站队；
- 胜利以后必须奖励中介，因而进一步强化其地方权力。

# 九、“西土悉平”以后留下了什么

## 1. 被摧毁的部分

- 阿里不哥在西线最重要的两位代理人；
- 通过阿蓝答儿合并和林来军与六盘山旧军的计划；
- 对京兆形成即时夹击的可能；
- 部分旧中央文书和官员网络；
- 公开反对忽必烈的联军主干；
- 西线军队能够以一套共同命令继续南下的能力。

## 2. 没有被摧毁的部分

### 六盘山与四川旧军的人际关系

哈剌不花和其他蒙哥旧将仍存在；残部可以重新依附宗王、回到原驻地，或在下一次继承危机中恢复联系。

### 河西和唐兀道路

甘州、凉州、山丹、肃州与焉支山仍是军队、使者和贸易通道。战乱只会降低可用性，不会让道路本身消失。

### 宗王份地和本部

合丹、合必赤等支持忽必烈，但其军队仍属于宗王本部，不归行省所有；支持忽必烈本人也不自动等于支持真金。

### 巩昌汪氏家族军

胜利使汪氏获得更高军职和便宜权，也意味着其地方自主性增强。

### 纽璘四川军

纽璘本人入朝并受忽必烈赏赐，但其奥鲁曾出现响应浑都海的企图，说明军队整合并不彻底。

### 蒙哥旧命令的政治记忆

对部分西部蒙古军而言，阿里不哥仍可宣称自己代表和林和蒙哥遗属。忽必烈死亡后，这种记忆可能重新获得吸引力。

## 3. 战后改编的可能类型

| 原有人员 | 可能处置 | 长期风险 |
|---|---|---|
| 高级首脑 | 被杀或处决 | 组织暂时失去中心 |
| 被俘将校 | 赦免、改编或监控 | 在新危机中重新选边 |
| 普通军士 | 归还原万户、编入宗王军或驻防 | 服从直接上级多于行省 |
| 军属与奥鲁 | 返回驻地、分给粮地 | 掌握兵员再生和家族联系 |
| 河西地方人员 | 继续纳税、供驿或两面交易 | 谁控制市场和驿路就可能重新影响他们 |
| 残军 | 北走、推新帅 | 保留阿里不哥代理网络的残余 |

## 4. 1260年胜利反而强化了地方中介

忽必烈需要奖励和确认：

- 廉希宪；
- 合丹、合必赤；
- 汪良臣、汪惟正；
- 八春；
- 按竺迩；
- 李忽兰吉；
- 纽璘。

奖励越多，这些人越深地加入忽必烈阵营；但他们同时获得更强的军职、符牌和地方控制。西线“中央化”因此存在一个悖论：

> 为了击败阿里不哥代理人，忽必烈必须赋予本地中介更强的自主权；胜利以后，这些自主权不会自动消失。

## 5. 1261年阿里不哥重新激活西线的最有效方式

不再是复制1260年远程合军，而是：

- 赦免参与杀死阿蓝答儿、浑都海的军将；
- 确认宗王份地和汪氏、纽璘军职；
- 承认真金是忽必烈家产继承人，但否认其自动继承大汗；
- 要求在和林或中立地点重开宗王会议；
- 通过山西投下、河西市场和旧军使者恢复联系；
- 让关陇从“主动为燕京作战”退化为“中立保境”。

# 十、秦蜀行省：它究竟拥有多少独立行动能力

## 1. 正式设立

中统元年八月，忽必烈设秦蜀行中书省，以廉希宪为中书右丞、行省事。这一时间点很关键：

- 西线战役仍在进行或刚进入决定阶段；
- 四川前线尚未稳定；
- 中央与关陇通信距离很长；
- 行省必须同时处理军事、财政和政治三类紧急问题。

## 2. 它的前身

秦蜀行省不是从一套空白制度中突然出现，而是由以下结构临战升级：

- 京兆等路宣抚司；
- 八春对陕西四川诸军的节制；
- 廉希宪、商挺的官署和财赋网络；
- 汪氏、纽璘等军队的协作；
- 临战便宜处置；
- 平阳、京兆等跨区守隘和转输安排。

因此，1260年的行省首先是一个战时总协调机构，而不是后世那种疆界、属官和常规财政都已经固定的省级政府。

## 3. 三层自主性

### 日常自主

较有能力处理：

- 官文书；
- 州县催征与减免；
- 屯田和军粮；
- 兵籍和奥鲁；
- 边境市场与私商；
- 驿递、渡口和道路维护；
- 小规模军职确认；
- 赈济、军服和短期借贷。

### 战时自主

在危机中可以：

- 临时调动相邻驻军；
- 封锁或守卫关隘；
- 使用府库赏军；
- 释放、逮捕或处分关键人员；
- 要求宗王和家族军配合；
- 处理投降者；
- 先处置、后奏报；
- 暂停执行来源可疑的远程军令。

### 最高政治自主

1261年尚不能稳定做到：

- 独立决定大汗继承；
- 创设自己的成吉思汗家族法统；
- 永久改变宗王份地；
- 强迫所有宗王军交出兵权；
- 单方面同南宋缔结长期国家条约；
- 长期改变全国税制；
- 在没有外部承认时发行全区域有效的新政治名号。

## 4. 财政工具

### 京兆府库

能支持一次紧急动员和赏军，但规模、库存构成和持续时间不明。它是危机财政，不是稳定预算。

### 屯田

凤翔、灵州、四川等处有军屯和种田户。屯田可以提供部分粮食并固定驻军，但收成受季节、战争、征发和劳动力流动影响。

### 盐课和市场

商挺早期通过市场替代长途实物转运，显示关中官署具备将帛、银和地方商品转换为军需的经验。后来四川以茶、盐、商、酒、竹课充军粮，证明边区财政可以逐渐依赖专卖和商业税。

### 交钞和现银

行省需要现银赏军、买马和支付临时费用。交钞能扩大账面动员，却仍取决于市场接受、兑换信用和实物供应。

### 借贷和地方垫付

地方官、豪强或家族集团可能先行垫付军需。它提高短期韧性，也会让行省更加依赖地方债权人、商人和强宗。

## 5. 1262—1264年的后视证据

后来材料显示秦蜀、陕西四川机构能够：

- 向沿边发放大额白银；
- 处理戍兵军需；
- 调整屯田军和四川各翼军税粮；
- 设置四川急递；
- 将四川茶、盐、商、酒、竹课充军粮；
- 把四川军政与刑名钱谷分给不同负责人；
- 向青居等前线增兵。

这些能力说明1260年的机构确有发展潜力；但正因为许多制度到1262—1264年才明确，反而证明1261年仍处于早期拼接阶段。

## 6. 外部依赖表

| 资源 | 本地能够维持什么 | 仍需外部什么 |
|---|---|---|
| 粮食 | 关中屯田、地方税粮、四川部分输入 | 灾荒、北调和大军集结时需山西、河西或市场 |
| 马匹 | 陇右、河西和宗王本部有一定来源 | 大规模补充、良马和驿马仍受草原与山西影响 |
| 军械 | 本地铁冶、库存和工匠 | 铠甲、弓弩材料和大批更新需跨区调拨 |
| 现银与交钞 | 府库、盐课和税收 | 长期军饷和宗王赏赐需中枢支持 |
| 官员 | 潜邸旧人、州县官和地方家族 | 高位任命与普遍承认仍需大汗或燕京中心 |
| 兵力 | 汪氏、纽璘、地方军和宗王分队 | 大规模北战需山西、华北和更多宗王军 |
| 法统 | 可奉忽必烈遗命或真金名义 | 无法独立制造无争议的大汗合法性 |

## 7. 行省不是廉希宪个人领地

必须把三者分开：

- **廉希宪的个人威望与关系；**
- **秦蜀行省的官署、印信和文书；**
- **汪氏、纽璘、宗王等实际军力。**

廉希宪死亡或被调离，会削弱协调能力；行省仍可能继续办公。行省印信被燕京承认，也不等于汪氏和纽璘自动交兵。正因为三者不完全重合，秦蜀体系才有一定韧性，也有很高分裂风险。

## 2. 三条主要纵向道路

### 路线A：燕京—山西—京兆

```text
燕京 / 开平
   ↓
西京—太原—平阳
   ↓
河中渡口 / 延安守隘
   ↓
京兆
```

主要输送：

- 中枢文书；
- 现银和交钞；
- 马匹；
- 铠甲和工匠；
- 华北汉军；
- 宗王使者。

### 路线B：和林—河西—六盘—关中

```text
和林
  ↓
蒙古本土 / 唐兀
  ↓
肃州—甘州—山丹—凉州
  ↓
六盘山—巩昌
  ↓
京兆
```

主要输送：

- 阿里不哥使者；
- 草原骑兵和宗王分队；
- 马匹与牲畜；
- 河西地方征发；
- 蒙哥旧军联络。

### 路线C：京兆—兴元—四川

```text
京兆—凤翔
      ↓
   兴元—利州—剑门
      ↓
成都—潼川—青居—重庆 / 泸州
```

主要输送：

- 四川军粮；
- 军职和文书；
- 巩昌、凤翔和关中援军；
- 降将和俘虏信息；
- 前线请求。

## 3. 横向接口：为什么河中、延安和六盘不能省略

关中不是只靠一条东向道路运行。

- **河中**连接平阳、解盐、黄河水陆运输和京兆东门；
- **延安—绥德**控制河套和山西北部进入关中的多条通道；
- **六盘山**把河西、巩昌、关中和四川分开或接合；
- **凤翔—兴元**决定四川军是关中资源还是独立战区；
- **甘州—山丹**决定阿里不哥命令能否从蒙古本土抵达西部旧军。

任何地图若只标“长安—和林”或“长安—成都”两条直线，都会低估这场战争的节点性。

## 4. 道路存在不等于大军可通

每条路线都受以下条件限制：

- 黄河渡口是否掌握；
- 驿马和车牛是否足够；
- 秋冬牧草和牲畜状态；
- 绿洲与市场能否供给；
- 宗王投下是否允许通行；
- 地方守军是否保持中立；
- 宋军是否同时切断四川水路；
- 文书是否被截、伪造或拒绝承认；
- 大军是否携带奥鲁、军属和攻城器械。

## 5. 信息流与粮物流并不同步

一名使者可以数日或数周内穿越一条路线，而大军、粮车和军属可能需要数倍时间。因此必须分别推演：

- 阿里不哥何时能把忽必烈死讯送到河西；
- 宗王何时能回信；
- 大军何时能真正抵达；
- 粮食和马匹能否跟上；
- 京兆在收到政治威胁后有多少时间修关和储粮。

这也是为什么忽必烈死亡会立即产生政治震荡，却不会让阿里不哥一个月内自动占领长安。

# 十二、山西若停止支援，关陇会失去什么

## 1. 为什么山西不是单纯“中央省份”

蒙古征服后，平阳、太原及河东存在术赤系、察合台系等投下权益。宗王、达鲁花赤、地方汉军和中央官署相互叠加。

这意味着“燕京下令封锁山西”或“山西投向阿里不哥”都不是单一动作，而是多个主体分别选择：

- 宗王投下是否承认命令；
- 地方官是否发兵发粮；
- 渡口和驿站是否开放；
- 商人是否仍能交易；
- 地方军是否愿意离开本镇；
- 文书是否由两地共同签发。

## 2. 1260年的直接连接证据

忽必烈令平阳与京兆共同签发七千人守延安等隘口，并设郑鼎等统领。这个安排说明：

- 关中北防并非只靠陕西本地兵；
- 山西兵籍和京兆官署需要共同文书；
- 守军的粮饷可能跨区承担；
- 山西政治变化会直接影响陕北门户；
- 单方面更换京兆或平阳官员，都会破坏原有协作。

“七千”在这里首先是签军规模记录，不宜等同于某一日全部到位的现役兵数。

## 3. 山西向关陇提供的资源

| 资源 | 作用 | 中断后的时间效应 |
|---|---|---|
| 守隘兵与援军 | 填补陕北和河中防线 | 数周内暴露兵力缺口 |
| 驿马与牌符 | 传递燕京命令和确认真伪 | 数日内导致信息延迟与多头命令 |
| 现银、交钞 | 赏军、买马、采购军械 | 一至三个月内军饷压力上升 |
| 马匹 | 补充骑兵和驿递 | 数月内削弱机动能力 |
| 军械与织物 | 铠甲、冬衣和维修 | 秋冬季影响更快 |
| 河东盐与市场 | 财政收入和地方交换 | 慢性影响，未必立即断粮 |
| 黄河渡口 | 军队与物资东向通行 | 一旦敌对，立即产生战略隔离 |

## 4. 三种状态压力测试

### 状态一：停止中央转输，但允许民间贸易

立即中断：

- 官府现银和大宗军械；
- 统一调发的马匹；
- 部分华北援军；
- 急递优先权；
- 由中枢承担的宗王赏赐。

仍可维持：

- 地方商旅；
- 盐、粮和牲畜交易；
- 关中屯田；
- 汪氏和四川军本地供给；
- 既有库存；
- 行省日常文书。

结果：

> 关陇不会一个月内崩溃，而会在三至六个月内出现军饷、马匹、军械和驿畜的慢性短缺。

### 状态二：宗王中立，允许阿里不哥使者和商队通行

新增风险：

- 阿里不哥能够向西道宗王和六盘山旧军发出赦免与确认书；
- 关陇部队接触到互相冲突的命令；
- 陕北守军更可能观望；
- 行省需要投入更多兵力检查渡口和驿站；
- 河西地方市场会重新成为两面交易区。

但这仍不足以：

- 让阿里不哥大军自动获得粮仓；
- 使京兆城内官署倒戈；
- 直接穿越所有守隘军；
- 接管关中州县税赋。

### 状态三：宗王主动提供驿马、粮食与渡口

这会产生质变：

- 阿里不哥使者可快速到达平阳、延安和河中；
- 小规模骑兵可先行进入陕北；
- 黄河渡口不再是可靠屏障；
- 关中需把兵从河西、四川抽到北线；
- 汪氏和西道宗王开始重新评估胜负；
- 燕京若不能及时援助，秦蜀联合体可能内部裂开。

## 5. 最先短缺与最晚耗尽

| 时间 | 最先出现问题 | 仍可维持的部分 |
|---|---|---|
| 0—30日 | 急递可信度、现银、外来马匹、政治确认 | 库存粮、地方守军、行省文书 |
| 31—90日 | 冬衣、军械维修、驿畜、外援兵力 | 屯田粮、盐课、汪氏和四川地方资源 |
| 91—180日 | 大规模军饷、宗王赏赐、持续北战能力 | 保境防御和小规模调兵 |
| 180日后 | 若两线作战持续，粮、马和财政同时吃紧 | 只有缩短防线、停战或获得新外援才能维持 |

## 6. “山西中立”对第三中心的悖论作用

它一方面削弱秦蜀，使其难以长期作战；另一方面却增强秦蜀拒绝燕京调兵的理由：

- 中央供给既已停止，中央便更难要求西军无条件服从；
- 本地官署必须直接同商人、宗王和地方军协商；
- 行省从中枢分支变成事实上的区域资源分配者；
- 对真金的名义服从可以与财政自主并行。

# 十三、纽璘、奥鲁与四川蒙古军

## 1. 纽璘军为什么不能视为秦蜀行省直属军

纽璘的军队源自：

- 其父所率陕西、巩昌和西海等军；
- 蒙哥征蜀期间的战役调动；
- 成都和重庆方向驻军；
- 新附汉、番人口；
- 自己的军官、家臣与奥鲁。

其传记记，前任主将死亡后，因距离朝廷太远，诸王和将领共同推举纽璘统军。这一细节极重要：

> **四川前线本来就具备在中央无法即时任命时自行选择统帅的传统。**

这种传统使四川军能够在危机中保持连续性，也使它不容易被京兆或燕京用一纸命令完全接收。

## 2. “军队”与“奥鲁”必须分开

- 前线野战军由纽璘直接率领；
- 奥鲁负责家属、补给、后备兵员和驻地；
- 奥鲁官员曾试图响应浑都海；
- 纽璘本人随后入朝并接受忽必烈虎符和赏赐。

所以，同一军事集团内部也可能出现：

- 主将倾向忽必烈；
- 奥鲁担忧清洗或断粮；
- 部分将校愿意响应蒙哥旧军；
- 普通军士只希望家属安全和军饷连续。

## 3. 纽璘军兵数为何只能作类型分析

传记中有“一万”“二万”“号五万”等不同数字。这些可能分别表示：

- 最初受命的名义部队；
- 某一时点实际可用人数；
- 分驻成都与重庆方向的战役配置；
- 包含奥鲁、降附人口或后备的号称规模。

因此，本专题只确认：纽璘拥有一支足以独立承担四川方向战役、并能分兵驻守多个节点的军团，不给出1261年精确总兵数。

## 4. 廉希宪为何选择释放奥鲁官

因为杀死奥鲁官会导致：

- 军属恐慌；
- 前线军失去补给；
- 纽璘被迫在个人安全和新汗廷之间选择；
- 数千骑兵直接转向浑都海；
- 四川防线同时出现政治和军事断裂。

释放并吸收，是把“可能叛乱的军队”转化成“条件性盟友”。

## 5. 1261年纽璘体系的状态

可以确认：

- 纽璘已接受忽必烈任命和赏赐；
- 其军队被用于镇守秦、巩、唐兀及四川相关节点；
- 四川仍有独立前线任务；
- 奥鲁与地方军官体系保留；
- 行省需通过诏令、粮饷和军职协调，而非直接吞并。

## 6. 忽必烈死亡后的可能选择

纽璘最优先考虑：

1. 四川前线是否会被宋军突破；
2. 成都和奥鲁粮饷能否维持；
3. 谁能确认其都元帅地位；
4. 是否会因蒙哥旧军身份遭燕京新军府清洗；
5. 阿里不哥是否承认其既有军职；
6. 秦蜀行省能否提供稳定文书和钱粮。

最可能的初始选择是继续与秦蜀行省合作、暂不北调，而不是立即接受燕京或和林的远程命令。

## 7. 纽璘在第三中心中的功能

- 为秦蜀提供真正的四川野战军；
- 使行省拥有同南宋谈判或作战的筹码；
- 阻止燕京把关陇视作只需防御阿里不哥的单线战区；
- 也给秦蜀联合体带来一个拥有独立军权、可能重新议价的内部中心。

# 十四、巩昌汪氏：第三中心的地方军事骨架

## 1. 家族资源

汪氏长期拥有：

- 巩昌地方基础；
- 蒙古军、汉军和地方兵；
- 西番与陇右作战经验；
- 入川道路；
- 青居、利州等前线联系；
- 同宗王和大汗之间的多重授职关系；
- 家族成员分守不同节点的能力。

## 2. 汪良臣在1260年战役中的位置

不同传记虽争夺战功，但都承认汪良臣是击败阿蓝答儿、浑都海的关键野战将领之一。战后他获得虎符和便宜都总帅等权力。

这意味着：

- 汪氏军被进一步合法化；
- 汪氏能够节制更多军民官；
- 行省必须依赖其实际作战能力；
- 家族拥有更强的议价资本；
- 其忠诚从“服从忽必烈”变成“忽必烈确认并扩大了汪氏既得权力”。

## 3. 汪惟正与四川接口

汪惟正镇青居等地，连接巩昌与嘉陵江前线。后来中央仍需要直接奖谕、发钞并要求其增援或调动。

这表明汪氏不是单纯地方守军，而是能决定：

- 巩昌兵是否入川；
- 青居是否得到增援；
- 四川军能否北调；
- 行省命令能否穿过利州—兴元；
- 宋军若反攻，哪一条防线先获得救援。

## 4. 汪氏为什么不宜轻易倒向阿里不哥

- 1260年已直接参与杀死其代理人；
- 获得忽必烈的虎符、赏赐和军职；
- 京兆行省能保护巩昌与四川接口；
- 阿里不哥若恢复蒙哥旧中央，可能重新调查或重分军权；
- 汪氏的地方利益与关中、四川贸易和粮道相连，不只依赖蒙古本土。

## 5. 汪氏为什么也不会无条件听燕京

- 家族军和地方税源仍在本手；
- 西线与四川实际威胁远离燕京；
- 燕京若抽兵过多，会直接危及其辖区；
- 若新政权不确认原军职，汪氏有自保动机；
- 对真金的名义支持可以与实际自主并存；
- 一旦山西转输中断，汪氏本镇资源会比燕京命令更重要。

## 6. 汪氏的最可能策略

在忽必烈死亡后的最初三个月：

- 不主动攻击燕京或阿里不哥；
- 守巩昌、利州、青居；
- 要求秦蜀行省确认军职和军饷；
- 同西道宗王保持联系；
- 拒绝大规模北调；
- 在宋军压力与阿里不哥政治招降之间两面观察。

这不是“背叛”，而是典型的区域军事集团保境行为。

# 十五、南宋四川：第三中心的南方压力

## 1. 1261年的前线并不安静

宋理宗景定二年，刘整在泸州方向转而降蒙；宋方俞兴随即出兵，试图阻止或收复。泸州地理志和宋方编年又显示其后控制反复。

这说明：

- 四川边境不是两大汗争位时的静止背景；
- 任何蒙古军北调都会被宋方观察；
- 降将、堡寨、舟师和粮道能迅速改变局部态势；
- 秦蜀行省必须保留一套独立于北方汗位战争的南线决策。

## 2. 刘整归附带来的不是一支孤立部队

刘整的价值至少包括：

- 熟悉南宋四川防区；
- 掌握泸州相关军队、家属和地方关系；
- 提供城防、水路与宋军内部信息；
- 向其他边将展示归附后的待遇；
- 同时制造宋方报复和反攻压力。

因此，秦蜀体系既得到新资源，又必须立即投入兵力保护新降集团。

## 3. 宋方最可能的第一反应

### A. 侦察和试探

先确认忽必烈是否真的死亡、四川蒙古军是否北撤，而不是立即发动全国性决战。

### B. 夺取外围堡寨与水路节点

目标可能包括：

- 泸州周边；
- 嘉陵江和长江上游渡口；
- 青居、合州外围；
- 被蒙古新占而守军薄弱的州县；
- 蒙古粮船和转运节点。

### C. 招诱和赦免

向降附人口、汉军和地方军提供回归条件，尤其利用他们对燕京或和林清洗的恐惧。

### D. 局部贸易和俘虏交换

若秦蜀需要稳定南线，双方可能恢复小规模市场或交换俘虏，但这不等于军事联盟。

## 4. 为什么南宋不太可能成为稳定盟军

- 宋廷的战略目标仍是收复四川失地；
- 秦蜀军仍占领宋地和堡寨；
- 刘整等降将使互信更差；
- 即便停战，宋方也会利用蒙古内部消耗扩展防线；
- 关陇无法向宋承诺永久边界或完整外交合法性；
- 宋方各级统帅也不一定能自行缔结长期和平。

## 5. 有限停战成立的条件

- 双方各守当前主要堡寨；
- 秦蜀不立即大举南攻；
- 宋方无力迅速攻取主要坚城；
- 允许局部市场、俘虏交换或粮食交易；
- 秦蜀不要求宋军协同攻击阿里不哥；
- 停战期限较短，由前线统帅和地方利益维持。

## 6. 对秦蜀第三中心的双重作用

南宋压力同时：

- **削弱秦蜀**：迫使其留兵、耗粮，不能全力北上；
- **增强秦蜀自主**：使其有充分理由拒绝燕京抽调，并要求自行处理边境；
- **提高汪氏和纽璘权重**：真正能守四川的军队在谈判中更重要；
- **限制阿里不哥接管价值**：即便获得关陇名义承认，他仍必须找到能治理和供养四川的人。

## 矩阵的三个共性

### 第一，各集团首先保全直接资源，而不是抽象阵营

宗王保份地，汪氏保本镇，纽璘保军和奥鲁，官署保印信与府库。只有这些资源得到保证，阵营效忠才有现实意义。

### 第二，对真金的接受度普遍高于对燕京军府的无条件接受

真金可以代表忽必烈家族连续性；燕京某个宗王或军将集团却未必有权取消原职位、抽走西军。因而“奉真金”可能成为秦蜀争取自主性的合法外壳。

### 第三，阿里不哥最容易争取的是中立，不是立即归附

他只需让宗王和地方军拒绝为燕京远征，便已显著改善战略形势；不必在最初阶段要求他们公开背叛1260年的选择。

# 十八、忽必烈死亡后的30日压力测试

## 一、分叉设定

- 昔木土脑儿相关战斗大体按现实表面结果展开；
- 忽必烈战后重伤；
- 约一个月后死亡；
- 死亡消息最初由前线核心、斡耳朵和少数军将掌握；
- 本专题只考察关陇—四川的反应，不推演整个蒙古世界。

## 二、第0—3日：消息封锁与文书冻结

秦蜀方面最先面对的不是阿里不哥大军，而是：

- 死讯真假；
- 是否有遗命；
- 真金位置；
- 前线军队由谁接管；
- 哪一枚印信仍然有效；
- 燕京是否已发生夺权；
- 阿里不哥是否知道消息。

合理行动：

1. 暂停执行任何要求大规模北调的口头命令；
2. 要求使者出示正式牌符和多重证明；
3. 加强京兆府库和行省印信警戒；
4. 通知巩昌、六盘、兴元和四川只守原防区；
5. 不立即公开改换最高名号；
6. 禁止未经行省共同署名的军队跨区移动；
7. 清点粮仓、马匹、军械和驿畜。

## 三、第4—10日：确认真金与燕京局势

廉希宪等会派出多路使者：

- 向前线确认死亡与遗命；
- 向开平、燕京确认真金和察必安全；
- 向合丹、合必赤等宗王征求共同表态；
- 向汪氏、纽璘确认军队不擅动；
- 向山西询问转输和驿路；
- 监视阿里不哥使者；
- 向宋边境加强巡逻，防止对方先得消息。

此时最可能的政治措辞不是“秦蜀独立”，而是：

> 奉先帝旧命，保护皇子与边境，在宗王议决以前，各军守职，不得擅自调动。

## 四、第11—20日：阿里不哥的政治攻势

阿里不哥最快可以：

- 宣称开平竞争汗廷因忽必烈死亡失去主体；
- 承认真金为宗王和忽必烈家产继承人，但否定自动继承大汗；
- 赦免1260年西线旧参与者；
- 确认宗王份地、汪氏和纽璘军职；
- 要求暂停交战、重开宗王会议；
- 向山西、河西、六盘和四川旧军派使；
- 把燕京若出现的中书清洗宣传为开平集团内部失序。

他暂时不能可靠做到：

- 数周内把大军从昔木土或和林送到长安；
- 沿途获得所有驿马和粮仓；
- 直接替换京兆州县官；
- 为四川军长期发粮；
- 强迫参与1260年战役的宗王立刻交出本部。

## 五、第21—30日：秦蜀作出临时定位

最可能的临时决议：

- 名义奉真金；
- 行省原官继续任职；
- 宗王、行省、汪氏和纽璘共同署名重要军令；
- 不承认阿里不哥已自动成为唯一大汗；
- 也不承认燕京任何未获真金和宗王共同认可的军府有权抽调西军；
- 对南宋提出短期停战或至少严守边境；
- 储粮、修关、清点军籍和奥鲁；
- 要求山西继续履行既有守隘与转输义务。

## 六、30日结论

> 关陇不会立刻从忽必烈阵营脱离，却会把对忽必烈个人的服从转换成对“真金名义＋本地共同保境”的服从。

这已经是第三中心的雏形。

# 十九、90日压力测试

## 1. 燕京—山西—关中线

### 若燕京迅速拥立真金并确认旧官职

- 秦蜀继续使用原行省印信；
- 山西转输恢复；
- 廉希宪和宗王获得正式授权；
- 汪氏、纽璘军职得到确认；
- 关陇逐步重新并入燕京体系；
- 但秦蜀仍会保留较大的战时便宜权。

### 若燕京发生宗王—军府政变

- 中书旧臣被清洗或权力受限；
- 对秦蜀发出互相冲突的调兵令；
- 真金可能被控制而非真正主持；
- 山西各投下开始观望；
- 秦蜀拒绝交出军权，第三中心加固；
- 阿里不哥更容易将自己包装成恢复宗王会议者。

### 若燕京不能确认真金

- 秦蜀只接受暂行文书；
- 宗王要求更广泛会议；
- 汪氏和纽璘缩回本镇；
- 行省开始独立筹措三至六个月军粮；
- 真金名义仍可能被秦蜀地方化使用，即“奉皇子而不奉燕京军府”。

## 2. 和林—河西／河套—陕北线

90日内阿里不哥有能力：

- 重建使者网络；
- 进入河套或部分河西节点；
- 争取山西宗王中立；
- 争夺黄河渡口和陕北守军；
- 通过赦免分化秦蜀联盟；
- 让残余蒙哥旧军停止作战；
- 在河西建立一个前进政治中心或集结点。

若无山西或河西主动供给，他仍很难：

- 带大军持续深入关中；
- 围攻京兆；
- 同时维持和林、前线和河西的粮草；
- 接管四川；
- 向州县提供替代秦蜀官署的财政与司法体系。

## 3. 南宋四川—秦蜀线

90日内宋方可能：

- 攻击一至两个薄弱堡寨；
- 收复部分泸州外围或水路；
- 向刘整旧部和降附人口招降；
- 迫使纽璘、汪惟正保留前线军；
- 用停战换取市场、俘虏或边界让步；
- 将蒙古北方内乱的消息用于动摇地方军心。

秦蜀若同时北调，会使内部矛盾迅速上升：

- 宗王希望北战；
- 汪氏担心巩昌和青居；
- 纽璘坚持守四川；
- 行省财政无法同时满足两线；
- 陕西汉军可能反对将粮马全部送往草原战场。

## 4. 90日结论

关陇能否继续统一，取决于三个最低条件：

1. 真金名义仍被保留；
2. 行省原官与军职得到确认；
3. 山西至少不主动为阿里不哥开放军事转输。

若三项同时存在，秦蜀可继续保境；缺少两项以上，内部将出现明显分裂。

# 二十、180日压力测试

## 1. 秦蜀行省的资源消耗

六个月后最难维持的是：

- 宗王和大军赏赐；
- 大规模马匹补充；
- 铠甲、弓弩与军械维修；
- 驿马和车牛；
- 同时支撑陕北、河西和四川三线的现银；
- 对地方军的政治奖励；
- 跨区域官员和使者的安全通信。

仍可能维持：

- 京兆和主要城池守备；
- 汪氏巩昌本镇；
- 纽璘四川核心军；
- 局部屯田和盐粮；
- 行省文书和官员网络；
- 与南宋的小规模防御战；
- 对周边州县的日常征收。

## 2. 阿里不哥的推进上限

### 无地方倒戈

可做到：

- 在河套、河西建立政治存在；
- 持续向关陇派使；
- 牵制陕北和六盘山；
- 迫使秦蜀消耗；
- 争取宗王和旧军不再主动为燕京作战。

难以做到：

- 稳定围攻京兆；
- 接收关中税赋；
- 管理州县；
- 越过兴元接管四川。

### 获得山西中立与部分河西供给

可做到：

- 对延安、河中和六盘形成两面压力；
- 支持宗王或旧军在关陇内部起事；
- 迫使秦蜀缩短防线；
- 使燕京无法从西线获得主动兵力。

### 获得山西主动支持或秦蜀内部宗王倒戈

才可能：

- 以地方兵为前锋进入陕北；
- 争夺京兆外围；
- 迫使汪氏、纽璘分别谈判；
- 将关陇联合体拆成京兆、巩昌、四川数块；
- 要求在控制区内举行更广泛宗王会议。

## 3. 第三中心的成熟条件

到180日，如果秦蜀仍满足：

- 拥有真金或得到真金正式承认；
- 廉希宪—商挺官署未被替换；
- 汪氏与纽璘继续合作；
- 山西贸易未完全封锁；
- 南宋未取得决定性突破；
- 至少两位西道宗王认可共同保境；

它就会从临时保境变成事实上的第三军政中心。

## 4. 第三中心不必拥有统一意识形态

各集团可以出于完全不同理由合作：

- 官署维护忽必烈路线；
- 宗王维护议决权；
- 汪氏维护本镇；
- 纽璘维护前线军；
- 汉军和州县避免重复征发；
- 商人希望道路和市场恢复。

共同威胁足以形成政体，不需要所有人形成统一政治理论。

# 二十一、四种情景比较

## 情景A：真金名义下的秦蜀保境集团

### 形成条件

- 真金仍在忽必烈家族核心控制中；
- 燕京政治不稳定，无法直接接管西线；
- 秦蜀原官职和印信得到真金或察必确认；
- 汪氏、纽璘和西道宗王同意共同守境；
- 山西不主动倒向阿里不哥。

### 运作方式

- 名义奉真金；
- 行省负责文书、钱粮和地方官；
- 宗王共同决定重大军事；
- 汪氏守巩昌—青居；
- 纽璘守四川；
- 对燕京交换情报和有限兵力；
- 不接受无条件抽调；
- 必要时与宋方维持局部停战。

### 内部矛盾

- 真金能否真正签发命令；
- 宗王是否接受汉地行省长期存在；
- 汪氏与纽璘的军饷分配；
- 北战与四川防御的优先级；
- 山西转输不足时谁承担财政缺口。

### 评价

**最符合1261年资源条件，是本文的基准情景。**

## 情景B：关陇与燕京重新合并

### 形成条件

- 燕京快速拥立真金；
- 保留中书和潜邸旧人；
- 确认廉希宪、商挺、汪氏和纽璘职位；
- 恢复山西转输；
- 允许秦蜀在西线便宜行事；
- 东道诸王提供外部军力；
- 不因汗位危机立即强行收回地方军权。

### 评价

这是秦蜀官员在政治上最愿意接受的结果，但要求燕京表现出足够克制和供给能力。若燕京试图立即收权，反而会阻止合并。

## 情景C：关陇内部再次分裂

### 触发条件

- 阿里不哥承诺宗王份地和军职；
- 燕京清洗汉地官署或否认真金；
- 山西主动开放道路；
- 行省断饷；
- 南宋在四川取得重大突破；
- 汪氏或纽璘判断合作无法保护本镇；
- 廉希宪等协调者死亡或被捕。

### 可能分裂

```text
京兆官署与陕西汉军：继续奉真金
西道宗王：要求会议或接受阿里不哥
巩昌汪氏：保全本镇、两面议价
纽璘四川军：独立守边
河西地方：依附实际控制道路的一方
山西投下：分别开放或关闭渡口
```

### 评价

不是最初30日最可能情形，却是90—180日风险最大的情形。

## 情景D：秦蜀与南宋有限停战

这不是与A、B、C完全互斥的政权方案，而是可以叠加其上的边境策略。

### 形成条件

- 双方都需要把兵力用于别处；
- 秦蜀承诺暂不南攻；
- 宋方无力迅速攻取主要坚城；
- 允许局部市场和俘虏交换；
- 停战由前线统帅维持；
- 双方不要求共同对付第三方。

### 评价

**可能出现，但很难升级为共同对抗阿里不哥的军事联盟。**

# 二十二、哪一种情景最符合1261年

## 第一位：情景A——真金名义下的秦蜀保境集团

理由：

- 行省官员对忽必烈个人依附较深；
- 真金可提供最低限度的延续名义；
- 地方军更需要保护既有军职，而非重新接受和林调查；
- 关陇同时面对阿里不哥和南宋，必须保留本地联合；
- 燕京不稳定会自然提高行省自主性；
- 阿里不哥短期没有能力替代秦蜀财政和四川军政。

## 第二位：情景B——重新并入燕京

只要燕京能够：

- 保有真金；
- 不清洗潜邸旧人；
- 恢复山西供给；
- 承认秦蜀便宜权；
- 不要求立即交出所有地方军；

关陇没有必要主动独立。

## 第三位：情景C——内部再分裂

它需要至少一个额外冲击：

- 宗王倒戈；
- 山西主动支持阿里不哥；
- 行省严重断饷；
- 宋军重大突破；
- 燕京否认真金或清洗西线旧臣；
- 关键协调者死亡。

## 情景D的位置

最可能作为A或B的临时附属策略存在，而不是长期政权归属。

# 二十三、“主角自毁陕西长城”究竟有多严重

如果架空中的主角通过政变、清洗或错误调兵破坏秦蜀体系，所谓“自毁陕西长城”至少包含五种具体后果。

## 1. 失去廉希宪—商挺的文书和财政连接

不是少两名文官，而是失去：

- 京兆旧人网络；
- 对1257—1260政治冲突的记忆；
- 府库和军需协调；
- 同宗王、汪氏、纽璘沟通的共同中介；
- 判断哪些旧臣可赦、哪些人必须先发制人的经验。

## 2. 迫使西道宗王重新要求会议

如果燕京否认既有军功和份地，合丹等人没有理由把对忽必烈的支持自动转给新军府。他们最温和的反应是中立，最激烈的反应才是转向阿里不哥。

## 3. 使汪氏和纽璘优先保境

他们不会必然投阿里不哥，却会拒绝远距离调兵。燕京因此失去西线机动军和四川保障。

## 4. 打开阿里不哥的政治招降空间

阿里不哥无需立即攻长安，只要承诺：

- 赦免；
- 确认军职；
- 不追究1260旧事；
- 尊重宗王份地；
- 承认真金的宗王地位；
- 召开更广泛会议；

就可能让关陇从主动支持燕京转为中立。

## 5. 给南宋制造北调窗口

一旦青居、泸州、合州和重庆方向守军被抽走，宋军会优先夺回外围据点和水路，进一步迫使秦蜀拒绝燕京命令。

## 6. 严重度的时间结构

| 时间 | 直接后果 |
|---|---|
| 30日 | 秦蜀暂停执行燕京军令，宗王和军将观望 |
| 90日 | 山西转输下降，西军不再主动北援，宋方开始试攻 |
| 180日 | 燕京失去对关陇兵粮与四川战线的实际调度权，秦蜀可能分裂或事实独立 |

## 最终判断

> **它未必让阿里不哥一个月内进入长安，却会让燕京在半年内失去对关陇兵粮和四川前线的实际调度权。**

这比单纯丢失一座城严重得多，因为燕京同时失去：

- 西部屏障；
- 四川军；
- 河西和山西之间的中介；
- 对南宋西线施压的能力；
- 向阿里不哥西侧迂回的战略空间；
- 以真金名义统一忽必烈旧部的可能。

# 二十四、最终回答：关陇为何可能成为第三中心

1260年的关陇不是忽必烈已经完成中央集权的“稳定后方”。它是一套在极端危机下拼接起来的联合体系。

其形成过程是：

1. 1257年中央调查打断忽必烈京兆旧政，使关陇留下互相冲突的合法性；
2. 1258—1259年蒙哥亲征又把六盘山、巩昌、河西和四川接成一条战役走廊；
3. 蒙哥死亡后，阿蓝答儿和浑都海试图继承中央和旧军两类资源；
4. 廉希宪依靠忽必烈新授权、京兆府库、潜邸旧人和情报先发制人；
5. 西道宗王、八春、汪氏、按竺迩和纽璘奥鲁构成联军；
6. 1260年胜利摧毁代理人首脑，却保留各集团兵权；
7. 秦蜀行省为多集团合作提供临时官署外壳；
8. 山西转输和四川前线又使它必须继续与外部合作。

因此，关陇具备成为第三中心的四项条件：

- **有中心：**京兆及秦蜀行省；
- **有军队：**宗王军、汪氏、纽璘和地方驻军；
- **有财政：**府库、屯田、盐课、市场和地方税粮；
- **有独立议程：**同时处理阿里不哥、燕京和南宋三方压力。

它又缺少独立国家的三项条件：

- 无无争议的大汗法统；
- 无完全统一的军队；
- 无足以长期脱离山西、河西和四川外部交换的财政。

所以最准确的定义是：

> **关陇在1261年有条件成为一个奉真金名义、以秦蜀行省为官署、由西道宗王与地方军共同维持的区域军政共同体。它可以同燕京合作，却不会把自己的军队、府库和边境决策无条件交给燕京；它可以同阿里不哥谈判，却不会因和林一纸诏令自动投降；它可以同南宋停战，却不会把宋军视为盟友。**

若忽必烈死亡后的燕京保留真金、承认旧官职、恢复山西转输并尊重西线便宜权，关陇最可能重新并入燕京体系。

若燕京发生激进军府政变、清洗中书旧人、切断山西输送或强抽四川军，关陇就会优先保境，成为真正的第三中心。

阿里不哥在这一局面中最有效的行动也不是急攻长安，而是：

- 承认既得军职；
- 赦免1260旧敌；
- 争取宗王中立；
- 打开山西和河西驿路；
- 让秦蜀联合体不再愿意为燕京主动作战。

由此可以得到本专题最重要的反事实判断：

> **忽必烈死亡不会把关陇自动送给阿里不哥，却会把关陇从“忽必烈的西部联合体”转化为“所有继承者都必须重新谈判的军政枢纽”。**

# 结语

专题三说明，阿里不哥能够把和林命令伸向河西和关陇，却难以保证代理人持续服从。专题四进一步表明，关陇之所以危险，正因为那里不是一条简单的远程代理链，而是一个拥有自己军队、官署、府库、道路和边境任务的复杂系统。

1260年廉希宪一方的胜利，并不是中央国家彻底接管地方，而是一次成功的资源拼接：

- 以忽必烈新汗廷提供名义；
- 以京兆官署提供文书和钱粮；
- 以西道宗王提供家族合法性；
- 以汪氏、按竺迩等提供野战军；
- 以纽璘和四川军维持南线；
- 以山西接口补充兵粮；
- 以秦蜀行省把它们暂时包裹在同一体系中。

忽必烈活着时，他是这套联合体的最高外部仲裁者。忽必烈一死，关陇不会失去所有机构，却会失去“为什么所有集团必须继续服从同一个中心”的最终答案。

因此，后续燕京政变最自然的后果，不是关陇立即宣布独立，而是秦蜀行省发出类似以下的临时命令：

> **先帝新丧，汗位未定，西北未靖，南边有敌。秦蜀诸军各守原防，府库印信不得擅移，宗王、行省与诸帅共同议事；待真金与诸王定议，再奉统一军令。**

这道命令在形式上仍然忠于忽必烈家族，在实质上却已经制造了第三中心。
