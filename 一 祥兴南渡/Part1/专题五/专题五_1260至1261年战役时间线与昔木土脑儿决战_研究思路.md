# 专题五：1260—1261年战役时间线与昔木土脑儿决战——研究思路

> 本专题承接[专题一的1259年军事快照](../专题一/1259年8月蒙古帝国军事力量分布：蒙哥死亡时的战略快照与指挥链重建.md)、[专题二的忽必烈联盟研究](../专题二/专题二_忽必烈为何迅速成为大汗候选人_详细调研结果.md)、[专题三的阿里不哥资源研究](../专题三/专题三_阿里不哥到底有多强_详细调研结果.md)与[专题四的关陇研究](../专题四/专题四_关陇战线为何可能成为第三中心_详细调研结果.md)。
>
> 前四个专题已经大致说明双方拥有什么、为什么能够开战，以及关陇为何不能被视作稳定后方。专题五要把这些静态资源放回时间中，回答：**1260—1261年两方究竟打了哪些仗、分别在哪里、由谁指挥、战果有多大；昔木土脑儿与失儿干脑儿记载是否属于同一场决战；忽必烈在这一战役链中受重伤并于约一月后死亡，怎样设置才是对真实历史扰动最小、而又足以触发后续世界线的分叉。**

---

## 一、研究范围与最终目标

### 1. 时间范围

- **前史起点：1259年冬。**忽必烈从攻宋战场北返，蒙哥远征体系开始分解；
- **政治成军期：1260年春夏。**开平、和林先后拥立，两套汗廷开始发布命令、征兵和争夺道路；
- **第一阶段战争：1260年夏至冬。**漠南、关陇与蒙古本土外围发生多路交战，阿里不哥一方第一次南向行动受挫；
- **第二阶段战争：1261年春夏。**阿里不哥休整、重新集中，并争夺斡耳朵、边境军和牧地；
- **主体阶段：1261年秋季前后。**昔木土脑儿及约十日后另一场会战；
- **收束观察：战后30日。**两军撤退、整补、传报和最高统帅状态；不在本专题完整推演忽必烈死亡后的帝国政治反应。

必要时可后视1262年初的记录，用来判断某支军队或某位将领在1261年战后是否仍然存在、驻于何处，但不得用后来的结局倒推战场当日的立场。

### 2. 地理范围

研究对象不是一条从开平到和林的直线，而是下列相互连接的空间：

| 区域 | 本专题要判断的功能 |
|---|---|
| 开平—燕京 | 忽必烈汗廷、后方官署、补给转换和伤情可能传回的方向 |
| 漠南北缘—戈壁通道 | 大军北上、车运、驿递和季节性水草约束 |
| 和林—斡耳浑区域 | 阿里不哥的中央政治资源与蒙古本土争夺 |
| 东蒙古与哈拉哈河上游相关区域 | 昔木土脑儿等候选地理范围，须继续考证 |
| 叶尼塞—吉尔吉斯方向 | 阿里不哥败退、休整和私人兀鲁思纵深 |
| 河西—唐兀—关陇 | 与主战场同步发生的西线代理战争及道路牵制 |
| 高丽—辽东—东道诸王区域 | 忽必烈东侧合法性、兵力与交通背景 |

### 3. 本专题的核心产出

本专题最终不是写一篇笼统的“忽必烈战胜阿里不哥”，而是形成一条可以逐日或逐旬核验的战役链：

1. 每一项命令何时发出；
2. 每一支军队何时开始移动；
3. 两军在哪里首次接触；
4. 昔木土脑儿是单场战斗还是战役群中的一环；
5. 约十日后的第二次会战是否对应失儿干脑儿等记载；
6. 双方各翼发生了什么；
7. 谁先撤退、向哪里撤退、是否发生追击；
8. 战后哪些军队仍保持建制；
9. 忽必烈本人最迟、最早在何处可能受伤；
10. 伤情能被哪些人看见，又能对哪些人暂时隐瞒。

### 4. 本专题不预设的结论

开始研究时不得先认定：

- 昔木土脑儿只有一场战斗；
- 《元史》所称“大败”意味着阿里不哥全军被歼；
- 《史集》中的两次会战可以无缝对应《元史》的一条记载；
- 所有异名一定指向同一地点；
- 忽必烈一定亲自冲阵或参与追击；
- 忽必烈受伤后，战场上的所有人都会立即知道；
- 一方撤退便等于失去继续作战能力；
- 战后军队会立刻返回燕京、开平或和林；
- 后世地图上的最短道路就是十三世纪大军实际行军路线。

## 二、我们真正想知道的内容

### 问题一：1260年的战争究竟从哪一个动作开始

“两汗并立”是政治节点，不等于同一天两军已经进入全面战争。需要分别确认：

- 开平与和林拥立的原始日期及换算；
- 双方第一批敌对命令、征兵和截断粮道的日期；
- 阿里不哥方向的南下军由谁组织；
- 忽必烈的前锋、主力与后方何时分开；
- 1260年秋的第一次大规模交战发生在哪里；
- 战败后阿里不哥是退出和林、退往北方份地，还是仍能控制若干蒙古本土节点；
- 关陇战役与北方主战役是否存在可以证明的统一部署。

这一问题的目的，是找出战争从“竞争性拥立”转变为“持续性军事对抗”的时间，而不是为内战寻找一个形式化宣战日。

### 问题二：1260年第一次失利后，阿里不哥为何还能在1261年重新进攻

专题三已经说明阿里不哥没有因一次战败消失。专题五需要把恢复过程写进时间线：

- 他退往何处、停留多久；
- 哪些宗王军和斡耳朵仍随行；
- 何时重新获得马匹、牧草和兵员；
- 对阿鲁忽或中亚资源的请求发生在何时；
- 1261年“诈降”或战略欺骗叙事的先后关系；
- 也松格等边境力量何时遭受打击；
- 忽必烈是在什么消息刺激下决定亲自或以主力北上。

这里要区分“恢复一支能够突击的骑兵军”和“恢复能够长期供养汗廷的国家能力”。前者可能较快，后者未必恢复。

### 问题三：昔木土脑儿究竟在哪里

需要同时检索并登记：

- 昔木土脑儿；
- 昔木土淖尔；
- 昔木土；
- Shimultu Nuur；
- Shimut-nor；
- Šimültü Na’ur；
- 阿卜只阿、阔帖格儿等相邻地名；
- 与额列帖、失儿干脑儿、失鲁格里克相关的异名。

不得只凭音近把地名钉在现代地图上。每一个候选地点至少检查：

1. 原文出现顺序；
2. 从上一地点到此地所需时间；
3. 是否有足够水源与牧草容纳大军；
4. 是否符合两军来向和撤退方向；
5. 是否能解释“约十日后再战”；
6. 现代考证依据的是语音、地图、旅行记还是考古资料；
7. 候选地之间应保留多大的不确定范围。

本专题可以接受“只能定位到区域、不能定位到单一湖泊”的结论。

### 问题四：昔木土脑儿与失儿干脑儿是一战还是两战

这是专题五最重要的考证问题。

至少建立三种模型：

#### 模型A：同一场大会战的不同叙述

《元史》压缩了战事，《史集》按不同战斗阶段展开，异名指向同一片战场。

#### 模型B：相隔约十日的两场会战

第一战忽必烈方面明显占优；双方重整后再战，第二战更接近互有胜负、分别撤退。

#### 模型C：一场主战加若干追击、阻击战

所谓第二战可能是追击军、后卫或不同军翼之间的连续接触，而不是两军再次完整列阵。

判断时必须比较：

- 日期和时间间隔；
- 地名移动顺序；
- 左、中、右翼叙述；
- 战后追击里程；
- 失马、徒步和夜间撤退记录；
- 两方主帅是否仍在同一战场；
- 后续命令是否表现出已经取得决定性胜利。

### 问题五：两军的参战序列和指挥关系是什么

不能用“忽必烈军”与“阿里不哥军”两个整体名词取代军序。至少分为：

#### 忽必烈方面

- 忽必烈本人、斡耳朵与宿卫；
- 东道诸王本部；
- 漠南蒙古军；
- 汉军世侯及其部队；
- 前锋、侦骑、右翼、左翼、中军与后卫；
- 车营、粮运、驿递和伤员转运；
- 留守开平、燕京及道路节点的军队。

#### 阿里不哥方面

- 阿里不哥本人、斡耳朵与宿卫；
- 蒙哥诸子及其本部；
- 斡亦剌等北方军；
- 支持他的各宗王本部；
- 左翼、中军、右翼和前锋；
- 随军家属、牧群与辎重；
- 后方份地、和林与中亚方向的补给关系。

每支部队应分别记录：名义统帅、战场实际指挥者、最近可证位置、兵源、补给来源、所属军翼、战后去向和证据等级。传记中的“万户”“万人”“数万”不得直接相加。

### 问题六：双方想通过会战得到什么

不能只用“击败对方”概括战略目标。需要判断：

- 阿里不哥是要夺回和林、进入漠南、破坏封锁，还是逼迫宗王重新选择；
- 忽必烈是要歼灭阿里不哥、把他赶回北方份地，还是守住开平—漠南边缘；
- 谁更需要主动寻找决战；
- 谁可以承受一次不彻底的撤退；
- 水草、冬季和马力是否迫使双方在特定时间交战；
- 是否存在通过缴获斡耳朵、牧群、印信和家属实现的政治目标；
- 战后设置关隘、换马和守备意味着继续追击，还是转入防御。

只有弄清战略目标，才能区分战术胜负、战役结果和政治结果。

### 问题七：忽必烈本人在战役各阶段位于哪里

这是架空分叉能否成立的硬前提。需要建立忽必烈的“最后可证位置表”：

- 哪一条材料明确说他亲临；
- 哪些行动由他本人下令，但不能证明他在现场；
- 哪些军翼由宗王或将领独立指挥；
- 斡耳朵、中军、观战高地和追击线分别可能在哪里；
- 战后他是否巡视阵地、追击、转营或处理俘虏；
- 下一条明确记载他健康、发令或出现在其他地点的材料是什么；
- 两条记录之间存在多大的“受伤窗口”。

如果史料只能证明忽必烈在战区而不能证明他亲自冲阵，架空伤势就应优先设置在中军受袭、转营、追击途中或战后意外，而不是强行写成单骑陷阵。

### 问题八：怎样设置“重伤后一月死亡”的最小分叉

研究结果应至少比较三种机制，但不必在指引阶段选定：

| 分叉类型 | 对真实战果的扰动 | 必须解释的问题 |
|---|---|---|
| 战斗中受伤 | 较直接，目击者较多 | 为什么没有立即影响指挥，如何封锁消息 |
| 追击或撤营时受伤 | 不改变主战胜负 | 忽必烈是否亲临该阶段，同行者是谁 |
| 战后伤病恶化 | 最容易保持历史表面结果 | 初伤、感染或旧病过程怎样维持约一月 |

无论采用哪一种，都要满足最低约束：

1. 真实历史中的表面战果大体保留；
2. 阿里不哥军没有因伤情在当天突然反败为胜；
3. 忽必烈在短时间内仍可能发令或以其名义发令；
4. 伤情首先只被斡耳朵、宿卫、医者和少数重臣掌握；
5. 前线军、开平、燕京、关陇和阿里不哥得知消息的时间不同；
6. 真金、察必、中书与军将因信息差进入不同政治节奏。

本专题只确定“何时、何地、哪些人可能知道”；完整的死讯封锁和继承压力测试留给专题七。

### 问题九：战后双方究竟还剩下什么

应分别判断：

- 哪一翼伤亡最大；
- 哪些宗王或将领仍能独立行动；
- 哪些军队只是失马、掉队或缺粮，而不是被消灭；
- 两军分别退到哪里；
- 伤员和辎重如何拖慢行军；
- 谁仍能控制驿站、渡口和水草地；
- 谁能在30日内再次集中；
- 哪一方战后命令仍能抵达关陇、山西和中亚；
- 忽必烈若死亡，战场胜利中有哪些成果无法继承。

专题三的“阿里不哥军事上受挫但未政治死亡”应在这里被落实成具体军队与具体时间，而不是再次作抽象论证。

### 问题十：主战役与其他战区如何同步

同一时间至少需要并列标出：

- 关陇与河西战后的军队状态；
- 山西—燕京—开平转输；
- 四川与南宋前线；
- 高丽、辽东与东道诸王；
- 阿鲁忽和察合台地区的立场变化；
- 忽必烈中书、斡耳朵和真金的所在地。

这些支线不在本专题展开完整研究，只用于回答：当主战场出现最高统帅死亡危机时，哪些力量已经在路上、哪些还没收到消息、哪些根本无法迅速介入。

## 三、时间线必须采用的记录格式

### 1. 每个事件保留四种日期

| 字段 | 内容 |
|---|---|
| 原始纪年 | 史料原载年号、干支、月日 |
| 历法换算 | 儒略历日期；必要时同时保留推算区间 |
| 记载性质 | 事件发生日、命令发布日期、战报到达日或后世追述 |
| 置信度 | 确定、约定、区间、无法换算 |

不得把“某月下诏”自动视为“某月军队已经抵达”。

### 2. 每个事件至少保留八个字段

| 日期 | 地点 | 人物／军队 | 行动 | 命令来源 | 结果 | 史料原文／出处 | 证据等级 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |

### 3. 三种时间必须分开

- **政治时间：**拥立、任命、赦免、宣称胜利；
- **军事时间：**出发、接敌、交战、追击、撤退、整补；
- **信息时间：**战报、死讯和正式诏令到达各地。

三个时间轴最后可以合并显示，但原始记录中不能混为一列。

## 四、地名与战场考证方法

### 1. 建立地名卡，而不是立即画确定坐标

| 原文地名 | 语言／转写 | 出现顺序 | 候选现代区域 | 来路与去路 | 水草条件 | 可靠度 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

### 2. 优先使用“关系定位”

先判断某地：

- 在开平以北还是和林以东；
- 位于哪条季节性牧道；
- 同上一战场相距几日；
- 是否连接阿里不哥北方份地；
- 是否允许大军展开；
- 战后撤退方向是否合理。

只有关系链能够闭合，才尝试给出较精确的现代坐标。

### 3. 地图至少画三层

1. **确定节点：**开平、和林等无重大争议地点；
2. **区域性候选：**只能定位到河流、山地或草原带的战场；
3. **行军可行区：**按照十日间隔、水草与速度推定的范围，而非一条精确路线。

## 五、最低限度材料包

### 第一组：可以直接开工的原始叙事

1. **《元史》卷四《世祖纪一》、卷五《世祖纪二》**  
   建立1260—1261年命令、交战、追击、守隘和战后任命的汉文时间底表。

2. **《元史》相关列传**  
   优先检索史天泽、张柔家族、董文炳以及参与北方主战、东道诸王军、宿卫和驿递的将领；只收与具体日期、位置、军翼和命令有关的条目。

3. **拉施特《史集》阿里不哥战争部分**  
   这是重建连续两场会战、左右中军、夜战、撤退与失马过程的主干材料。必须保留所用版本、译者、卷页和地名原转写。

4. **《元朝名臣事略》及元代碑传、行状**  
   用于补本纪省略的随驾、前锋、战后受赏和人物位置。

5. **《新元史》相关本纪、列传**  
   只作为材料索引和异文汇集工具，不作为独立的十三世纪证人。

### 第二组：现代综合研究

1. Hodong Kim关于忽必烈政权形成、高丽与东道诸王的研究；
2. Morris Rossabi的忽必烈传记，用于快速定位现代叙事与参考文献；
3. 新版 *The Cambridge History of the Mongol Empire* 的政治史、军事制度与帝国交通章节；
4. John W. Dardess、Peter Jackson等关于内战、忽里勒台和帝国分裂的研究；
5. Michael Hope关于阿里不哥兀鲁思、代理人与战争余波的研究。

1. 《高丽史》《高丽史节要》及Hodong Kim的对读；

外部材料的作用不是扩大专题，而是校正“某人当时是否可能在主战场”。

### 第一批最值得优先准备的文件

如果只准备能够立即开工的一批，优先级为：

前两项到位即可先建立双源时间表，其余材料可以在出现具体缺口后补。

## 七、暂定假说

以下只是等待材料检验的工作假说。

### 假说一：昔木土脑儿应当理解为战役链，而不是单日歼灭战

《元史》的明确胜利叙事与《史集》的连续两战可以同时成立：忽必烈在第一场主战中占优，约十日后的第二场会战却没有完成对阿里不哥军的彻底歼灭。

### 假说二：忽必烈赢得的是战场主动，而非终结内战

阿里不哥部分军翼遭受重大损失，却仍保留汗廷、私人兀鲁思、部分宗王军和再谈判能力。因此忽必烈之死能够重新打开继承问题，而不是让一支已经消失的军队凭空复活。

### 假说三：补给和马力比单次伤亡更能解释双方撤退

长途行军、失马、牧草、水源与冬季临近，可能迫使双方在没有彻底分出胜负时分别撤退。后续政治结果不能只从杀伤数字推导。

### 假说四：忽必烈受伤的最低扰动位置在主战之后、政治胜利固化之前

最合适的分叉应保留忽必烈方面已经取得的战场优势，又让其无法亲自完成追击、整军、封赏与继承安排。受伤发生在战斗后段、追击、转营或战后短期内，可能比“开战即重伤”更符合这一要求。

### 假说五：战后一个月内存在三只不同的钟

- 前线核心知道伤情的时间；
- 开平、燕京和真金方面确认伤情的时间；
- 阿里不哥、关陇、山西与南宋获知死讯的时间。

这三只钟不会同步。专题七的政治压力测试必须建立在专题五给出的传播起点上。

### 假说六：忽必烈之死首先使“胜利归谁继承”成为问题

参战将领可能仍愿意对抗阿里不哥，却不一定同意把兵权交给燕京某个宗王军府。战役胜利不会自动变成真金、中书、东道诸王或汉军世侯中任何一方的独占资源。

## 八、史料警戒线

1. 《元史》本纪倾向把复杂战役压缩成世祖大胜，必须与《史集》和列传对读。
2. 《史集》虽保留更多军翼与战斗过程，也有成书时间、信息来源和译名问题，不能自动视作现场记录。
3. 后出史书汇集的细节必须追溯来源；找不到来源时只作线索。
4. 地名音译相似不等于同地，同一地点也可能有多种语言和书写传统。
5. 追击“数十里”不能在未核历制、地形和原文以前直接换算成现代公里。
6. “大败”“败绩”“走”“还”分别可能指军翼溃退、全军撤退或战略退却，必须结合上下文。
7. 传记常把集体战功集中到传主身上，不能据此重建唯一总指挥。
8. 战后受赏能够证明参与或获承认，未必能证明具体位于哪个军翼。
9. 1262年以后的官职和立场不能自动倒推到1261年战场。
10. 任何伤势、医治、封锁死讯的细节若无史料，必须明确标为世界线设定。

## 九、与专题六、专题七的边界

### 专题五负责

- 给出1260—1261年可用的战役时间骨架；
- 解释两次会战、地名、军序与撤退；
- 确定忽必烈可能受伤的时间和空间窗口；
- 给出战后30日内双方军队的初始状态；
- 列出伤情最初可能被哪些人掌握。

### 专题六负责

- 深入研究真金、察必、斡耳朵、中书、东道诸王和主要将领；
- 判断谁能持印、发令、封锁消息或接管军队；
- 建立承重人物失去忽必烈后的第一选择。

### 专题七负责

- 把死讯沿不同道路传播；
- 推演燕京宫变、山西中立、关陇保境和阿里不哥政治反攻；
- 完成死亡后第3日、第10日、第30日、第90日的全局压力测试。

专题五不应提前替专题七决定谁发动政变；专题七也不能跳过专题五，随意指定所有人同时知道忽必烈死亡。

## 十、何时可以停止搜集并开始写综合稿

满足以下条件即可停止第一轮扩张：

1. 《元史》与《史集》的1260—1261主干事件已经逐项对读；
2. 能说明昔木土脑儿至少有哪三种定位或战役解释；
3. 能判断是一战、两战还是主战加追击，而不要求完全消除争议；
4. 双方主要军翼和直接统帅已有证据等级；
5. 1261年主战前后各有一张军队状态表；
6. 忽必烈的可证位置和受伤窗口已经划出；
7. “重伤后一月死亡”没有破坏已知战役结果；
8. 战后30日内双方能够和不能够做到什么已有边界；
9. 所有无法确认的地名、日期、兵数和伤情都列入缺口表。

本专题不必解决阿里不哥战争直到1264年的每一次行动，也不必现在完成所有蒙古高原地名的精确定位。真正拟定故事大纲时，若某一场景需要具体到日程、营地或目击者，再针对性补材料。

## 十一、本专题预期得到的最终判断

专题五最理想的成果不是一篇充满精确坐标和兵数、却无法说明证据来源的战役故事，而是一组有边界的结论：

- 忽必烈方面在哪一层意义上获胜；
- 阿里不哥方面在哪一层意义上仍然存在；
- 两次会战之间有多长的可用时间；
- 双方战后分别停留在什么状态；
- 忽必烈在何处受伤最不改变真实战局；
- 伤情与死讯能够被控制多久；
- 当忽必烈死亡时，胜利尚未被制度化到哪一个继承中心手中。

如果这些问题能够回答，专题六就可以研究“谁有能力接住这场胜利”，专题七则可以正式推演“没有人完整接住时，帝国如何在三十天内开始裂变”。
