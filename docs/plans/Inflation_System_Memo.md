# 通胀系统备忘录

这份备忘录记录项目在通胀、累计物价水平和名义/实际金额方面的长期约束。它不是当前立即执行的实施路线，也不要求一次性重写所有价格。当前优先级仍以 [`Roadmap.md`](Roadmap.md) 为准；当客流、融资、经营、合同、项目或资产模块分别继续深化时，应回到本备忘录检查口径。

## 一句话结论

现有模型已经能够生成有跨年记忆的通胀率，并把通胀传到政策利率、国债收益率、贷款报价和客流压力；但尚未生成从 2025 年起累计的 CPI 物价水平，也没有统一声明所有现金、价格、债务和资产究竟采用名义金额还是 2025 年不变价。

不应因此发动一次“所有价格统一乘 CPI”的全项目改造。更稳妥的方向是：

1. 将累计价格水平和名义/实际换算建立为共享基础能力；
2. 保留已经完成的客流、利率和贷款传导；
3. 在每一类价格真正深化时，为它单独选择指数、传导比例、调整频率和滞后；
4. 在正式估值、跨区域经营和资本市场以前，完成关键现金流与折现率的口径对账。

## 当前已经存在的能力

### 通胀不是逐年独立抽取

`global_inflation_annual_sim.py` 保存总体通胀、核心通胀、通胀预期、工资压力、能源通胀和进口通胀等状态。上年的状态会通过平滑、预期和冲击存量影响下一年，因此当前路径已经具有通胀持续性和回落过程。

当前输出的主要物价字段仍是年度变化率：

- `headline_inflation_pct`；
- `core_inflation_pct`；
- `energy_inflation_pct`；
- `import_inflation_pct`；
- `wage_pressure_pct`；
- `inflation_expectation_pct`。

它们描述“本年比上年上涨多少”，不描述“相对 2025 年已经累计上涨多少”。

### 利率与贷款已经消费通胀路径

通胀缺口和通胀预期会影响政策利率，政策利率再进入收益率曲线。机场短期贷款使用区域政策利率，长期贷款使用区域 10 年期收益率，并叠加产品、期限、宽限期、信用和杠杆利差。贷款在提款时锁定报价，之后不会每年用新基准重定价。

这条链的方向是正确的，不应因为缺少累计 CPI 而撤销。新贷款报价本来就主要读取当前和预期通胀，而不是读取几十年来累计上涨了多少。

### 客流已经承受通胀的跨年后果

区域客流以年度通胀、能源、汇率、收入、信心和金融压力形成票价敏感度及客群增长。年度增长继续乘到上年的客流指数，因此连续高通胀会把客流带到更低的发展路径；通胀恢复后，需求不会自动跳回未受冲击的反事实路径。

这是“客流结果的复利”，不是“累计 CPI 的价格会计”。两者不能混为一谈。

## 当前缺口

### 没有累计价格水平

模型尚未发布类似以下字段：

```text
cpi_price_level_index_2025_100
core_price_level_index_2025_100
wage_level_index_2025_100
```

最基础的 CPI 水平恒等式应当是：

```text
price_level[t] = price_level[t - 1] * (1 + inflation_rate[t] / 100)
price_level[2025] = 100
```

没有价格水平就无法严格回答：

- 一笔名义现金相当于多少 2025 年购买力；
- 固定利率债务的实际负担下降了多少；
- 收入增长究竟来自实际业务扩张还是一般物价上涨；
- 名义资产回报扣除通胀后的实际回报是多少；
- 经营现金流与名义折现率是否处于同一口径。

### 固定基价与动态压力并存

机场经营中大量金额采用固定的每旅客基价或明确的 2025 年不变价建造成本；与此同时，通胀会提高成本压力、压制消费和客流，并通过名义政策利率提高新贷款报价。

单独看这些机制都有合理性，但把它们放在一起时，可能形成以下错配：

- 成本和融资条件完整承受通胀压力；
- 收费、租金和商业售价缺少对应的重定价能力；
- 固定名义债务没有显示实际负担被通胀侵蚀；
- 实际口径的经营现金流可能直接搭配名义利率或名义回报率。

因此需要统一的是“口径和换算桥”，不是所有价格的同一涨幅。

## 客流模型仍需怎样细化

客流 v0.4 已经完成总量、五类分项、航司供给、城市承接、固定 Seed 和真实 Viewer 的系统收口。通胀备忘录不否定这些成果，也不意味着刚完成的客流结构需要推倒重做。

后续细化应把当前较粗的“年度通胀压力”拆成更可解释的真实负担：

```text
累计 CPI 与工资水平
  → 实际可支配收入
  → 机票相对居民收入和一般物价的变化
  → 商务、休闲、探亲、长途、中转的不同弹性
  → 客流增长和结构
```

建议未来优先区分：

1. **一般物价水平**：居民购买力的共同背景，不直接等于机票价格；
2. **实际收入**：工资或可支配收入扣除 CPI 后的变化；
3. **相对机票价格**：机票价格相对 CPI、工资和收入的涨幅；
4. **预期与意外通胀**：稳定的预期通胀和突然的购买力冲击不应产生同样反应；
5. **成本传导**：能源、汇率和工资如何进入航空公司票价，而不是把它们与 CPI 重复计价；
6. **客群差异**：商务较能承受票价，休闲更依赖实际收入，探亲和中转又有不同替代空间。

当前 `airfare_price_sensitivity_index`、`airfare_pressure_index`、收入、能源、汇率和宏观压力已经同时进入客流层。未来增加 CPI 或相对票价时，必须先画出字段来源和传导图，删除或降权重复渠道，避免“高通胀既直接压客流、又经收入、能源、汇率和票价重复压客流”。

客流细化完成后仍应保持现有硬契约：

- 五类需求指数与总量加总口径不漂移；
- 单类可承接供给不超过该类潜在需求；
- 总有效供给不超过需求和投放运力；
- 同一 Seed 可复现，短路径是长路径前缀；
- 不同 Seed 的城市和区域发展差异继续存在；
- 不能为了修通胀而重新引入固定排名或统一世界线。

## 其它价格不采用一次性统一改造

不同价格面对通胀的方式本来就不同。以下内容应在对应模块进入真实开发时逐项推进。

| 模块 | 更合适的未来处理 | 不应采用的简化 |
| --- | --- | --- |
| 航空性收费 | 监管周期、审批滞后、部分指数化 | 每年完整跟随 CPI |
| 餐饮零售售价 | 较快传导，同时由需求弹性压低实际销量 | 只涨收入、不影响消费量 |
| 商业租金与保底合同 | 按合同条款、重定价日、固定递增率或 CPI 条款 | 所有合同自动同年调价 |
| 人工成本 | 跟随核心通胀或工资指数，并具有议价和调整滞后 | 直接跟随总体 CPI 或油价 |
| 能源与公用事业 | 消费量乘能源/公用事业价格指数 | 与一般 CPI 重复叠加 |
| 维护成本 | 工资、材料和设施年龄共同决定 | 只使用单一 CPI |
| 建设成本 | 独立建造成本指数、项目签约时点和超支风险 | 用居民 CPI 替代建造价格 |
| 银行贷款 | 保留名义报价和提款锁定，增加实际利率与实际债务负担诊断 | 用累计 CPI 直接决定贷款报价 |
| 资产与估值 | 现金流、增长率、回报率和折现率严格同口径 | 实际现金流直接配名义折现率 |
| 跨区域经营 | 区域通胀、汇率和当地价格共同换算 | 假定所有区域共享同一 CPI |

这种逐项接入意味着通胀工作会跨越多个版本。每次只修改一个价格族，并为该价格族完整声明基准、指数、传导比例、滞后、重定价频率和上下界，比一次性建立一个全局 `inflation_multiplier` 更安全。

## 共享基础能力的最小边界

当第一个真实消费者准备接入累计物价水平时，可以先建立一轮只负责公共口径的基础改动：

1. 全球与区域输出发布版本化的 CPI 水平指数，起点统一为 `2025=100`；
2. 明确全球 CPI 只是共同锚，区域价格水平由区域通胀独立累计；
3. 提供名义金额与 2025 年不变价的纯换算函数；
4. 为字段增加 `nominal_*`、`real_2025_*` 或等价的不可混淆命名；
5. 暂不让新字段自动改变所有下游模型；
6. 由每个消费者在自己的模型版本中显式声明是否接入。

这轮基础能力本身不应偷偷改变客流、贷款、经营、合同或资产结果。它只提供可验证的价格坐标，真正的结果变化由后续模块 Goal 分别承担。

## 每次深化一种价格时的检查表

1. 当前金额是名义值、实际值，还是尚未声明的游戏单位？
2. 应跟随总体 CPI、核心 CPI、工资、能源、建造成本、汇率，还是独立合同条款？
3. 传导比例是多少，调整发生在当年、下一年还是合同重定价日？
4. 价格上涨是否同时改变真实需求量、服务量或客群结构？
5. 是否与现有宏观压力、收入、能源、汇率和利率渠道重复？
6. 存量合同、存量债务和在建项目是否保持签约时口径？
7. API、CSV、Schema、缓存指纹、存档和 Viewer 是否需要版本升级？
8. 是否能用固定 Seed 对照解释结果变化，而不只是更新快照？

## 验收底线

未来任何累计价格水平或具体价格传导实现，至少需要覆盖：

- `price_level[t] = price_level[t-1] × (1 + inflation[t]/100)` 的逐年恒等式；
- `year_index=0` 的统一起点和长短运行严格前缀；
- 名义金额与实际金额往返换算误差；
- 高通胀、低通胀、通缩和通胀回落路径；
- 预期通胀与一次性意外冲击的差异；
- 客流 CPI 接入后的五类分项、需求—供给和城市容量契约；
- 新贷款仍由当前基准报价，已提款固定利率贷款不被追溯重定价；
- 固定名义债务的实际负担随累计价格水平下降；
- 实际现金流只能搭配实际折现率，名义现金流只能搭配名义折现率；
- 不出现 CPI、工资、能源、汇率和宏观压力的无意重复计价。

## 工作量判断与触发条件

这是一个高工作量、跨模块的长期问题。它会触及宏观与区域字段、客流、季度经营、合同、项目、财务、融资、资产估值、Schema、缓存、存档、Viewer、文档和固定 Seed 测试，不适合在一个大 Goal 内完成。

以下情况出现时，相关部分应从备忘录转为独立实施 Goal：

- 下一轮需要进一步解释客流中的收入、票价与通胀关系；
- 某一经营价格开始支持玩家定价或合同重定价；
- 需要比较固定利率债务的名义和实际负担；
- 资产层开始发布实际回报，或估值开始使用长期现金流；
- 新城市或跨区域经营要求处理不同通胀和汇率；
- 页面需要同时展示名义金额和不变价金额。

在这些触发条件之前，现有年度通胀率、客流压力和贷款利率链可以继续使用。任何临时修补都不应通过给全部金额乘一个累计 CPI 来绕过逐模块设计。
