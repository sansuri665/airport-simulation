## 2. 宏观与区域基础

- 编排器不再丢失宏观反馈强度和 raw 诊断；区域政策不确定性能够读取真实反馈状态。
- 区域软对账后重新执行公开边界，并以最终值计算裁剪计数、加权残差和质量标签；GDP 硬对账仍精确守恒。
- 宏观反馈采用确定性完整更新与独立无松弛固定点残差验证。未收敛、旧版或缺失诊断的 Run 不能成为活动 Viewer Release。
- GDP 输出缺口使用唯一版本化口径，增长支持与拖累改为对称关系，并保留软限制和实际硬安全边界诊断。
- 2Y、10Y、期限溢价、影子短端、美元资金条件代理和 FCI 的重复宽松计价已经拆分；`global_dollar_index` 的正式含义是美元资金条件代理，不是现实 DXY。
- 信用、资产和能源的七组次级饱和字段发布未裁剪目标、边界状态和连续命中年数；盈利指数不再受固定 460 上限截平。
- 全球八层的 `year_index=0` 统一为配置起点，不执行年度转移、不消费 RNG。第一次更新位于第 1 行，`years=0/1/2/60` 保持严格前缀关系。

详细模型口径由[全球宏观模型](../models/Global_Macro.md)和[区域宏观模型](../models/Regional_Macro.md)维护。

## 3. 贷款利率 v0.3

三种玩家贷款保持原有金额、期限、还本、宽限和授信边界，仅升级基准选择与可解释性：

| 产品 | 权威基准 | 还本结构 |
|---|---|---|
| 短期周转 | 区域年度政策利率 | 4/8/12 季，到期一次还本 |
| 长期建设 | 区域年度 10 年期收益率 | 40/60/80 季，等额本金 |
| 宽限建设 | 区域年度 10 年期收益率 | 60/80 季，宽限后等额本金 |

政策利率和 10Y 均沿现有 `regional_macro_annual` 链传到城市年度、季度经营、财务层和 API。零或负政策利率是合法输入；只有缺失、空值、非有限值或来源不匹配才使用对应回退基准。

服务端权威报价按以下五项守恒：

```text
基准利率
+ 产品利差
+ 期限 / 宽限利差
+ 信用利差
+ 杠杆利差
= 未裁剪报价
-> 1.0%–9.5% 边界
= 提款锁定年利率
```

提款状态保存最终利率、基准、各分项、回退和模型版本；后来政策利率、10Y、HY 或杠杆变化不会重定价旧贷款。浏览器候选报价使用独立无 DOM 纯函数，并通过 Python/Node 共享向量验证；真实提款结果仍以服务端返回为准。

贷款、现金流和 API 的长期说明分别位于[财务、合同与项目](../models/Finance_Contracts_and_Projects.md)、[财务与估值参数](../reference/Finance_and_Valuation_Parameters.md)和[API 与数据契约](../reference/API_and_Data_Contracts.md)。

## 4. 明确未改变

- 没有增加违约、提前还款、浮动重定价、再融资、银行竞价或贷款审批概率。
- 没有改变三种产品的金额范围、期限、还本方式、每季一笔限制、HY 捕获、杠杆曲线、80% 拒绝线或现金流公式。
- 没有把 2 年期收益率引入短期贷款；2Y 继续只服务宏观收益率曲线解释。
- 没有改变估值、合同、项目、城市客流或机场经营公式来配合贷款报价。
- 没有把开发期 Run、缓存或验收数据纳入 Git。
