# Global Macro Narrative Layer Design

## 当前定位

宏观叙事层目前实现在 `web/pages/global_gdp_viewer.html` 内，是一个只读解释层：

```text
Macro stack outputs -> narrative scoring -> overview commentary
```

它不改变 GDP、通胀、利率、信用、油价或资产价格，也不向模型注入冲击。它只读取当前年份的宏观状态，为游戏界面生成局面解说。

## 显示规则

- 只在 `总览` 模式显示。
- 如果当前年份没有足够强的宏观特征，解说面板会隐藏。
- 如果识别到连续年份属于同一个主线，会显示为一个时期，例如 `2047-2051`。
- 主线之外的次级叙事会以标签形式显示。

## 当前可识别叙事

- 金融危机
- 能源危机
- 滞胀
- 软着陆
- 信用紧缩
- 政策宽松修复
- 美元挤兑
- 风险资产牛市
- 资产负债表衰退
- 债券市场冲击
- 倒挂预警
- 通胀再加速
- 再融资墙
- 需求破坏后的油价回落
- 金发姑娘

## 判定口径

叙事层使用打分规则，而不是硬编码某一年为某个事件。主要读取：

- GDP 增长率和产出缺口
- headline / core 通胀和通胀变化
- 政策利率、QE、流动性脉冲
- 收益率曲线和 10Y 利率变化
- 美元指数、美元融资压力、新兴市场压力
- HY 利差、信用可得性、银行放贷意愿、信用疤痕
- 股票回报、估值、债券回报
- Brent 油价、能源成本压力和油价需求压力

## 与事件层的关系

叙事层是“解释当前局面”，事件层才是“注入外生冲击”。后续如果做事件层，可以复用叙事层的结果作为命名和说明来源，但不应该让叙事层直接改写模型路径。

分岔风险层见 `Global_Macro_Branch_Risk_Layer_Design.md`。它回答“未来几年可能拐向哪里”，和叙事层共用总览解说区。baseline 中它只读；当 viewer 临时模拟或 `macro_run_orchestrator_sim.py` 生成 occurred/counterfactual 路径时，才会形成另一条宏观路径。
