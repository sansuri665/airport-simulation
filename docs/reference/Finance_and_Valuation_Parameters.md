# 财务与估值参数参考

本文列出当前北京财务、合同融资和估值模型真正使用的来源与主要参数。金额默认是百万元人民币，界面输入贷款时会换算为亿元。

若要建立其它城市的完整财务和估值配置，请先阅读[北京样板与新增完整经营城市指南](Beijing_Template_and_New_City_Guide.md)，尤其不要复制北京的初始资产、示例贷款和城市风险假设。

## 时间与单位

- 财务从 2025 Q1 开始；2025–2029 是开局历史，2030 Q1 起允许玩家行动。
- 金额字段 `*_million_cny` 使用百万元人民币。
- 利率 `*_pct` 使用百分数；`4.8` 表示年利率 4.8%。
- 利差 `*_bps` 使用基点；100 bp = 1 个百分点。
- 贷款利率为年化，季度利息按年利率除以 4。

| 参数 | 当前值 | 说明 |
|---|---:|---|
| 开局现金 | 18,000 | 180 亿元 |
| 开局留存收益 | 0 | 后续按季度净利润累积 |
| 开局短期债务 | 0 |  |
| 开局长期债务 | 0 |  |
| 自动负现金借款 | 关闭 | 现金可以变为负数 |

开局投入资本不是手工常数。模型用“开局现金 + 2025 年初固定资产账面值 - 开局债务”自动平衡。

## 初始固定资产

| 资产 | 原值 | 投运年 | 使用寿命 | 残值率 |
|---|---:|---:|---:|---:|
| 首都 T3 | 51,000 | 2008 | 40 年 | 10% |
| 首都 T2 | 28,500 | 2000 | 35 年 | 10% |
| 大兴 T1 | 78,750 | 2019 | 45 年 | 10% |

固定资产使用直线折旧，并保留残值底线：

```text
年折旧 = (资产原值 - 残值) ÷ 使用寿命
季度折旧 = 年折旧 ÷ 4
```

翻新、新建和重建资产的寿命与残值来自经营配置，不从这张初始资产表复制。

## 所得税

| 参数 | 当前值 |
|---|---:|
| 企业所得税率 | 25% |
| 盈利季度预缴比例 | 100% |
| 年度汇算季度 | Q4 |
| 亏损结转 | 启用 |
| 最长结转 | 5 年 |
| 递延所得税资产 | 不确认 |

季度先对正的税前利润预缴 25%。Q4 再按全年税前利润扣除可用历史亏损后计算应纳税额，并与全年预缴相减。亏损桶按先进先出使用。

## 玩家融资产品

| 产品 ID | 玩家名称 | 期限（季） | 宽限期（季） | 还本方式 |
|---|---|---|---|---|
| `short_turnover` | 短期周转贷款 | 4 / 8 / 12 | 0 | 到期一次还本 |
| `long_construction` | 长期建设贷款 | 40 / 60 / 80 | 0 | 等额本金 |
| `grace_construction` | 宽限期建设贷款 | 60 / 80 | 8 / 16 | 宽限后等额本金 |

操作边界：

- 单笔融资额 1,000–100,000 百万元，即界面中的 10–1000 亿元；
- 界面步长 10 亿元；
- 每个季度最多新增一笔贷款；
- 利率在提款季锁定；
- 被拒绝的提款不会形成贷款余额和利率。

## 贷款利率

### 基础参数

| 参数 | 短期 | 长期 |
|---|---:|---:|
| 基准 | 区域政策利率 | 区域 10 年期收益率 |
| 对应基准无效时的回退利率 | 3.6% | 4.8% |
| 参考调整 | -0.25 个百分点 | 0 |
| 产品基础利差 | 60 bp | 145 bp |

共同参数：

- 高收益信用利差基准：420 bp；
- 超过基准的部分按 10% 捕获进贷款利差；
- 当前城市固定利差：0 bp；
- 最低/最高年利率：1.0% / 9.5%。

### 期限与宽限期利差

| 产品 | 选项 | 附加利差 |
|---|---|---:|
| 短期周转 | 4 / 8 / 12 季 | 0 / 15 / 30 bp |
| 长期建设 | 40 / 60 / 80 季 | 0 / 20 / 45 bp |
| 宽限期建设 | 60 / 80 季 | 20 / 45 bp |
| 宽限期附加 | 8 / 16 季 | 10 / 25 bp |

宽限期建设贷款同时叠加期限利差和宽限期利差。

### 杠杆加点和拒绝线

杠杆使用“总负债 ÷ 总资产”，并按提款后的资产负债率定价：

| 提款后资产负债率 | 杠杆附加利差 |
|---:|---:|
| 45% | 0 bp |
| 60% | 60 bp |
| 70% | 150 bp |
| 80% | 300 bp，但 80% 已触发拒绝 |

控制点之间线性插值。提款前或提款后资产负债率 **达到 80%** 时拒绝提款。

### 完整公式

```text
提款年利率
  = 当季产品基准（短期政策利率；长期/宽限 10 年期，无效时用对应回退值）
  + 短期/长期参考调整
  + 产品基础利差
  + 期限利差
  + 宽限期利差
  + max(0, 当季 HY 利差 - 420bp) × 10%
  + 城市利差
  + 提款后杠杆利差
```

结果再限制到 1.0%–9.5%。

基准为有限的 `0.0` 或负数时仍是有效宏观输入，不触发回退；字段缺失、空值、非有限值或来源不是当前区域年度宏观链时才回退。服务端在提款时保存 `benchmark + product + term/grace + credit + leverage` 的完整分解，浏览器候选报价使用相同参数并由共享测试向量校验，但真实提款结果以服务端锁定值为准。

## 还本付息

```text
季度利息 = 当季计息前余额 × 锁定年利率 ÷ 4
```

- 到期一次还本：存续期只付息，最后一季归还全部余额；
- 等额本金：本金 ÷ 总期限，每季归还；
- 宽限后等额本金：宽限期只付息，之后按剩余季数等额归还本金；
- 最后一季会清偿剩余尾差。

## 财务公式

### 利润

```text
税前会计利润
  = 折旧前经营利润
  - 初始/翻新/新建/重建资产折旧
  - 拆除费用
  - 被重建或拆除的旧资产减记
  - 贷款利息

净利润 = 税前会计利润 - 所得税费用
```

### 现金

```text
融资前自由现金流
  = 折旧前经营利润
  - 项目资本化支出
  - 拆除现金费用
  - 现金所得税

融资现金流 = 贷款提款 - 本金偿还

期末现金
  = 期初现金
  + 融资前自由现金流
  + 融资现金流
  - 利息支付
```

折旧和资产减记已经影响利润，但不在现金公式中再次扣除。

### 资产负债表

```text
固定资产账面值
  = 初始资产 + 已完工翻新/新建/重建资产 - 累计折旧 - 已核销资产

非流动资产 = 固定资产账面值 + 在建工程
总资产     = 现金 + 非流动资产
总负债     = 短期债务 + 长期债务
所有者权益 = 开局投入资本 + 累计净利润
```

## 回放示例贷款与玩家贷款的区别

财务配置包含三笔长期路径检查用的示例贷款：

| 名称 | 开始 | 本金 | 期限 | 方式 |
|---|---|---:|---:|---|
| 北京短期周转贷款测试 | 2030 Q1 | 5,000 | 8 季 | 到期一次还本 |
| 首都机场重建期长期贷款测试 | 2056 Q1 | 30,000 | 80 季 | 等额本金 |
| 大兴扩建宽限期长期贷款测试 | 2065 Q3 | 24,000 | 60 季，宽限 16 季 | 宽限后等额本金 |

它们用于“加载历史”和模型测试。进入模拟运营时，服务端把 `general_loans` 替换为玩家行动日志生成的贷款；玩家不会自动继承这三笔贷款。

## 估值数据边界

估值从 2030 起按每个季度生成一条 as-of 记录：

- 数据截止到当前季度；
- 最多读取最近 12 个历史季度；
- 预测未来 20 季，即 5 年；
- 估值输出不会反过来改变经营、合同或贷款。

### 预测参数

| 参数 | 当前值 |
|---|---:|
| 历史季度 | 12 |
| 最少历史季度 | 4 |
| 预测期 | 20 季 / 5 年 |
| 无历史时客流年增长 | 2.2% |
| 无历史时收入年增长 | 2.6% |
| 年增长下限 / 上限 | -8.0% / 7.5% |
| 长期利润率权重 | 55% |
| 简化现金税率 | 25% |
| 维护资本开支 / 折旧 | 78% |
| 维护资本开支 / 固定资产账面值 | 0.85% |
| 维护资本开支年增长 | 1.7% |

预测先从历史客流和收入增速出发，收入增长再混合 55% 自身趋势、45% 客流趋势和当期宏观修正。利润率从当前值向历史长期水平收敛。

第一年维护资本开支取以下两者较大值：

```text
年折旧 × 78%
固定资产账面值 × 0.85%
```

实验 FCFF 使用：

```text
FCFF = 预测折旧前经营利润 - 预测维护资本开支 - 简化现金税
```

不扣利息、不扣还本、不加新借款；净债务在企业价值转股权价值时统一处理。

## 当前主估值

配置的 `primary_method` 是 `net_asset_value`：

| 参数 | 当前值 |
|---|---:|
| 股权价值基础 | 财务层所有者权益 |
| 企业价值基础 | 所有者权益 + 净债务 |
| P/B 锚 | 1.0 倍 |
| 现金确认率 | 100% |

```text
净债务 = 短期债务 + 长期债务 - 现金
主股权价值 = 所有者权益
主企业价值 = 主股权价值 + 净债务
```

因此当前主估值没有“便宜/昂贵”的市场报价含义，它只是账面状态的稳定表达。

## 实验性 DCF 观察参数

这些参数生成观察字段，不是当前正式定价：

| 组别 | 主要参数 |
|---|---|
| 经营折现率 | 归一化无风险利率 3.0%，基础经营风险溢价 3.6%，范围 5.2%–9.5% |
| 终值增长 | 基准 1.2%，范围 0.2%–2.0%，且至少比折现率低 2.8 个百分点 |
| 终值上限 | 正 FCFF 最高 18 倍；负 FCFF 使用 4 倍观察 |
| 历史 FCFF 锚 | 24 季，权重 70% |
| 资产质量调整 | 固定资产账面值最多 +5% / -7% |
| 合同质量调整 | 年合同收入倍数 0.45，调整比例最多 +22% / -16% |
| 不确定性范围 | 基础 14%，最终限制在 10%–38% |

市场观察乘数还读取：

- 10 年期利率相对 3.0% 中性值的折溢价；
- HY 利差相对 420 bp 的信用折溢价；
- 市场 PE 相对 17 倍中性值的调整；
- 权益市场当期收益情绪；
- 历史分岔处于观察或已发生状态的折价。

输出会同时保留经营 EV、市场观察 EV、实验股权价值、折现率、终值、净债务、P/B、PE 类比和风险标签。北京经营 Viewer 可以加载这些结果，但动态经营页没有将它们作为交易或玩家动作。

## 估值的明确限制

- 主估值固定为净资产，不是可交易市场价格。
- 实验 DCF 依赖简化的 5 年趋势预测，不含独立航线、合同竞标或资本配置预测。
- 目前没有分红、回购、再投资选择和现金折价，长期现金可能抬高净资产。
- 其它城市没有北京同等完整的财务和估值配置，不能进行可靠横向比较。
- 估值不决定贷款授信、合同报价、胜负或资产交易。

## 修改参数时的检查清单

1. 保持经营和财务时间线一致。
2. 确认百分数、乘数和基点单位没有混用。
3. 修改服务端贷款期限时同步检查期限利差映射。
4. 杠杆拒绝线应高于开始加点的 45%，并与界面提示一致。
5. 项目资产寿命、残值和资本开支必须与经营配置一致。
6. 税率变化同时影响季度预缴、Q4 汇算、净利润和现金。
7. 不要把实验 DCF 字段改名为“正式估值”，除非交易和结算逻辑也真正接入。
8. 调参后运行财务平衡、固定 seed 和 60 年长期测试。
