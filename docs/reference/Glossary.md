# 项目术语表

这份术语表用于统一项目中的常用说法。文档、界面和代码名称不完全相同时，以这里的中文解释理解其含义。

## 模拟与情景

| 术语 | 含义 |
| --- | --- |
| Seed | 随机种子。相同代码、配置、Seed、年数和情景参数应生成相同结果。它不是某个“预设剧本”的编号。 |
| Run | 一次完整计算及其输出目录。Run 通常包含 baseline，也可以包含某条事件发生路径。 |
| Baseline | 基准路径。在给定 Seed 下，不强制指定某个历史分岔发生的主要对照结果。 |
| Scenario | 情景路径。用于比较某个风险事件发生、未发生或按概率演化时的结果。 |
| Branch | 分岔事件，例如某项宏观风险在特定年份触发后改变后续路径。 |
| Counterfactual | 反事实路径。用于观察“如果事件没有这样发生”时可能出现的结果。 |
| Model version | 模型实现版本，记录在配置和输出 Manifest 中。 |
| Schema version | 输出或 API 数据结构版本，用于判断读取方是否兼容。 |

## 客流与容量

| 术语 | 含义 |
| --- | --- |
| 潜在客流 | 市场在没有供给瓶颈时希望实现的航空出行量。 |
| 航司供给 | 航司能够提供的运输能力。 |
| 有效客流 | 在需求和供给约束后实际能够实现的客流。 |
| 供给满足率 | 航司供给能够覆盖潜在需求的比例。 |
| 供给缺口 | 潜在需求超过航司供给的部分。 |
| 设计容量 | 航站楼或机场设施按设计能够承载的能力。 |
| 舒适容量 | 为维持服务体验而采用的较保守容量口径。 |
| 容量使用率 | 实际客流相对于相应容量口径的比例。 |
| 瓶颈 | 限制有效客流继续增长的主要因素，例如潜在需求、航司供给或机场容量。 |

## 机场经营与财务

| 术语 | 含义 |
| --- | --- |
| 经营季度 | 动态测试中推进和决策的最小时间单位，即 Q1、Q2、Q3、Q4。 |
| 报告口径 | 界面展示数据的聚合范围，例如最新季度、一季报、半年报、三季报或年报。 |
| 航空收入 | 与航班和旅客航空服务直接相关的收入。 |
| 非航收入 | 餐饮零售、免税、奢侈品及其它商业经营形成的收入。 |
| 经营利润 | 经营收入扣除经营成本后的结果；它不等同于最终净利润。 |
| 税前利润 | 在经营结果基础上再考虑折旧、拆除或核销、利息等项目后的税前结果。 |
| 自由现金流 | 经营现金变化在考虑资本开支等项目后的现金流口径。 |
| 合同 | 机场与商业合作方之间按期限、分成和保底等条款形成的经营安排。 |
| 项目 | 新建、翻新、拆除或重建等改变设施、容量、质量和资产状态的行动。 |
| 融资 | 通过贷款等方式获得资金，并形成利息和偿债义务。 |
| 估值观察 | 根据当前模型输出形成的价值参考；它不是独立交易市场，也不是完整投资建议。 |

## 文件、缓存与界面

| 术语 | 含义 |
| --- | --- |
| Output | 模型生成的可再计算结果，统一位于 `output/`。 |
| Cache | 为避免重复计算而保留的临时 Run；依赖或指纹变化后可以失效重建。 |
| Save | 玩家主动保存的动态经营进度，位于 `saves/`，不会随普通缓存清理删除。 |
| Manifest | 描述一次 Run 或 Viewer 发布内容、版本和文件关系的清单。 |
| Viewer | 读取已发布结果的只读浏览页面。 |
| Seed Explorer | 运行指定 Seed、查看城市市场并进行北京机场季度动态测试的界面。 |
| Canonical output | 为兼容固定页面和脚本而保留的稳定输出路径。 |
| Viewer release | 一次经过完整校验、带版本目录和校验和的 Viewer 数据发布。 |
| Staging | 正式切换前的临时写入区域；只有计算和校验全部成功后才会成为正式结果。 |
| 8776 服务 | 仅在本机运行的统一 HTTP 服务，提供首页、Viewer、动态测试和 API。 |

## 开发与验证

| 术语 | 含义 |
| --- | --- |
| 固定 Seed 回归 | 使用固定 Seed 对比关键数值和结构，检查代码整理是否改变结果。 |
| API 快照 | 固定一组代表性 API 返回结构，用于发现不兼容修改。 |
| JSON Schema | 对 JSON 数据字段、类型和必需项的机器可检查说明。 |
| 兼容入口 | 为旧脚本、旧模块导入或旧浏览器地址保留的薄转发层；正式实现位于新入口。 |
| 原子切换 | 先完整生成新结果，再一次性替换指针或目录，避免页面读到半成品。 |
