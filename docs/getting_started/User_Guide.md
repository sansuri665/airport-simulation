# 用户指南

本文面向不熟悉代码的使用者，说明五个页面分别做什么，以及哪些动作会改变本地数据。

## 1. 首页：先确认你在看哪批数据

地址：

```text
http://127.0.0.1:8776/
```

首页的“当前 Viewer 数据”来自 `output/current_viewer_manifest.json`，主要显示：

- 当前发布模式；
- Run 和变体；
- Seed；
- 模型版本；
- 发布时间。

`versioned_release` 表示三个只读 Viewer 正在读取一份版本化发布；`legacy_canonical` 表示没有有效发布清单，页面会尝试读取兼容输出。首页显示的缓存数量和存档数量只用于说明工作区状态，不代表所有数据属于同一个 Seed。

## 2. Seed 动态测试

地址：

```text
http://127.0.0.1:8776/seed-explorer
```

这是当前唯一同时支持“生成世界线”和“执行玩家行动”的页面。

### 2.1 运行世界线

左侧参数含义：

| 控件 | 含义 |
|---|---|
| Seed | 世界线的随机起点，必须是非负整数 |
| 年数 | 模型运行长度，界面允许 5–90 年 |
| 已有缓存 | 选择本机已经计算过的 Seed 与年数组合 |
| 运行全链路 | 运行或读取宏观、区域航空、城市市场和北京下游结果 |
| Python 随机 Seed | 只生成一个新 Seed，不立即运行 |
| 忽略已有结果，重新生成 | 强制放弃可用缓存并重算 |

相同 Seed 只有在年数、模型版本、配置和 Python 环境也一致时才代表相同结果。正常情况下不要勾选强制重算；代码或配置变化后，服务会用依赖指纹自动拒绝过期缓存。

### 2.2 城市市场

全链路完成后，“城市市场”提供中国大陆已配置城市的：

- 潜在客流；
- 航司供给；
- 最终有效客流；
- 供给缺口与满足率；
- 瓶颈状态和长期变化。

可以按远期规模或 CAGR 排序，也可以用中英文城市名和标签筛选。这里展示的是同一正式 Python Run 的城市结果，不是浏览器自行计算的另一套世界线。

### 2.3 北京运营的两种模式

进入“北京运营”前，先在左侧选择运营口径，再点击“运营”。

| 模式 | 用途 | 可否执行事务 |
|---|---|---|
| 加载历史 | 只读回放已经生成的完整经营结果 | 否 |
| 模拟运营 | 从可操作季度开始推进，并记录玩家行动 | 是 |

模拟运营至少需要 60 年世界线。若左侧年数更短，页面会自动扩展到 60 年并重新取得完整经营范围，避免只运行开头几个季度。

“上一季度”和“下一季度”用于切换当前季度。没有新增行动时，页面可以复用已加载的季度结果；确认合同、项目或融资后，Python 服务会按完整行动日志重新计算经营和财务路径。

### 2.4 经营报告

经营报告是当前最完整的北京机场运营视图，包含：

- 财务分析；
- 客流与容量；
- 服务质量；
- 设施与项目；
- 债务与融资；
- 航空、餐饮零售、免税和奢侈品板块；
- 合同与合作；
- 经营总览。

图表会随当前季度、指标和口径变化。报表的权威数值来自 Python 返回的季度经营与财务结果；浏览器负责选择、汇总和绘制。

### 2.5 合同、项目与融资事务

这些操作只有在“模拟运营”且当前季度允许决策时才可用。

- **合同事务**：在开放谈判窗口内查看下一期建议条款、确认签署或暂缓；逾期规则由服务端经营路径执行。
- **项目事务**：按槽位发起翻新、新建、拆除或重建；容量、工期、资本开支、资产和维护年龄会进入后续季度。
- **融资事务**：选择产品、金额、期限和宽限期；提款、利息与还本进入现金和资产负债表。

按钮灰色不一定是故障。常见原因包括仍在“加载历史”、尚未进入玩家决策期、不在合同谈判窗口、槽位已有施工、项目冷却期未结束、现金或负债约束不满足。

### 2.6 玩家存档

模拟运营加载后可以点击“保存当前”。存档绑定 Seed 和年数，主要保存：

- 当前季度；
- 玩家行动日志；
- 页面恢复所需的少量选择状态。

“读取存档”会按保存的 Seed、年数和行动日志由服务端恢复报表。存档不会复制整套长期输出，因此需要的计算缓存不存在时可以重新生成。玩家存档位于 `saves/seed_explorer/`，不会随普通缓存清理删除。

## 3. 全球宏观 Viewer

地址：

```text
http://127.0.0.1:8776/global-gdp
```

该页面用于查看已经发布的：

- 全球 GDP、增长、通胀、利率、收益率、美元、信用、资产和石油；
- 14 个区域的宏观结果与对账结果；
- 区域航空需求、运力供给和满足率；
- baseline 与可选情景变体。

Run、变体、视图、面板和 Seed 选择器只切换已有数据，不会启动 Python 计算。

“浏览器预览”是快速观察用途的近似模型，只存在于当前页面，不写入正式 Run、缓存或存档，不能用于核对正式世界线。

## 4. 城市航空市场 Viewer

地址：

```text
http://127.0.0.1:8776/city-markets
```

这是中国大陆城市市场的只读分析页，可以：

- 按年份、城市名和市场指标筛选或排名 47 个城市；
- 在城市标题下切换总客流、商务、休闲、探亲访友、长途和中转六种口径；
- 查看单城市潜在客流、城市航司座位投放、有效供给和供给约束后需求的完整长期轨迹；
- 切换客群后，摘要、长期轨迹、供给分配解读和年度明细统一使用该客群口径；
- 查看航司供给周期、波动、偏离、闲置量与供需缺口。

该页面不计算 47 城合计，也不展示机场容量和最终经营承接，不提供合同、项目、融资、财务和存档操作。北京的完整季度经营历史与行动统一留在 Seed 动态测试中，避免两套经营界面重复和口径漂移。

## 5. 有效客流预测 Viewer

地址：

```text
http://127.0.0.1:8776/beijing-forecast
```

该页面默认进入“报告视图”，按发布年份和报告机构展示：

- 一句话报告观点、主要和次要驱动；
- “报告等级 · 基础风格”的研究画像；
- 按立场、方法侧重、修订行为和不确定性分类的中文标签；
- 基础方法说明、典型盲点，以及标签悬停时显示的作用与代价；
- 需求与航司供给的模糊研究信号；
- 预期转向窗口、报告信心和本期修订原因；
- 潜在客流预测；
- 航司供给预测；
- 两者共同约束后的有效客流预测；
- 总客流、商务、休闲、探亲访友、长途和中转六种口径；
- 预测区间和逐年明细。

普通报告不是隐藏真实曲线的伴飞版本。模型只把未来压缩成方向、强弱、周期和大致拐点窗口，再由不同等级和研究风格生成整条预测路径。同一机构的新一期报告会继承上一期观点，并说明为什么调整。

“开发审计”需要显式切换，切换后才会按需加载隐藏真实路径、真实值圆点、神级报告、误差、拐点分和修订纪律分。真实值圆点悬停可查看该年预测值、高估或低估幅度及百分比。该模式用于核对模型，不代表正式玩家已经获得这些信息。

普通报告的结果分、区间命中率和拐点判断分都以隐藏真实路径为评分基准。“真实路径”报告本身直接读取隐藏未来，固定作为误差为零的审计参照和数据链路校验，不作为一份可购买预测报告评价其自身质量。

开发审计标题区会把现有报告质量分显示为醒目的“实际评分”。80 分以上使用绿色或青色，60–79 分使用橙色，60 分以下使用红色；结果分、加权误差、区间命中、拐点判断分和修订纪律分继续用于解释总分。“真实路径”不显示 100 分，而显示“审计基准 · 不参与评分”。

实际评分采用 v1.2 标准：总量结果占 70%，分项结果占 15%，拐点判断占 8%，修订纪律占 7%。分项结果分别评价潜在需求结构、航司有效供给结构、供给满足率差异和分项区间；修订纪律也会同时检查总量和分项观点是否稳定。报告等级仍不直接加分，因此初级报告也可能凭借准确路径、诚实区间和合理修订获得高分。

切换到商务、休闲、探亲访友、长途或中转后，页面展示的不是把总预测按固定占比缩小。报告会分别预测潜在需求结构与航司客群优先权重，再使用与城市年度市场相同的封顶分配规则计算计划投放、有效供给、满足率和未满足需求。分项区间是该客群的边际范围，五类上限不能直接相加。

开发审计还提供“候选报告实验室”。可以选择初级、中级、高级或专业级，固定一种基础风格，并让系统自动附加标签、保持纯风格或手动选择最多两个兼容标签；目标实际评分范围至少需要 8 分宽。生成结果是可复现的独立首次发布临时候选，命中失败时会显示最近候选，并同时给出总量结果分和分项结果分。初级、中级、高级和专业级分别保持完整 6、8、10 和 12 年预测期；接近 60 年数据尾部且未来不足时按钮会禁用。候选不会写入正式发布或游戏存档。

预测报告是城市市场真实未来之后产生的“信息分支”，不是季度经营模型的输入，也不会改变城市真实客流或航司供给。

## 6. 什么会修改本地数据

| 操作 | 写入位置 | 是否影响玩家存档 |
|---|---|---|
| Seed Explorer 运行/重算 | `output/seed_explorer_runs/` | 否 |
| 命令行正式 Run | `output/macro_runs/` | 否 |
| `--publish-viewer` | `output/viewer_releases/` 与当前 Manifest | 否 |
| 模拟运营保存 | `saves/seed_explorer/` | 是，创建或更新当前 Seed 存档 |
| 只读 Viewer 切换选项 | 不写盘 | 否 |
| 浏览器宏观预览 | 不写盘 | 否 |

若页面或图表异常，先不要删除 `output/` 或 `saves/`；按 [故障排查](../development/Troubleshooting.md) 的顺序确认服务、发布清单和浏览器状态。
