# 地图研究工作要求（窗口交接）

当前 `map_research/` 只保留铁路预研：中国大陆与港澳台线路／站点查看。机场页、城市身份、路径规划与旅行记录已删除。

## 数据范围

- 线路与站点只写在 `railways.js`。
- 允许区域：`china_mainland`、`hk_macao_taiwan`，以及仅连接二者的 `cross_region`。
- 不要再加入海外区域或跨境延伸到第三国的线路。

## 新增／修改线路

- 铁路节点统一写入 `railways.js`。
- 暂未确定线路的节点使用 `stationOnly: true` 的“站点集合”；已有线路则写入对应线路的 `stations`。
- 优先复用已有站点对象的 `id`，不要为同一城市重复造站点 ID。
- 同一实体站点出现在多条线路时，必须复用同一个站点 ID。
- 跨区域线路（大陆 ↔ 港澳台）使用 `region: "cross_region"`，并填写 `regions: ["china_mainland", "hk_macao_taiwan"]`；每个站点仍须填写自己的 `region`。
- 支线必须设置 `parentLineId` 与 `networkRole: "branch"`；起点应复用主线站点 ID。
- 线路必须明确 `type`（`high_speed` 或 `conventional`）和对应的 `typeLabel`。
- 环线使用 `closed: true`，站点列表不要重复写首站。
