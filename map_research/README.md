# 铁路网络研究

独立的静态铁路网络查看器，以**站点和站点间的直接连接**为基本单位。统一入口为 `railway.html`，目录首页和旧 `new-railway.html` 地址均自动跳转到该页面。

在仓库根目录启动：

```powershell
py -m http.server 8780 --bind 127.0.0.1 --directory map_research
```

访问 `http://127.0.0.1:8780/`，无需构建或 Airport 主服务。

## 浏览方式

- 左侧切换连接／站点，按端点名称或城市搜索。
- 统一显示整个泛中国路网，不按区域拆分；高速／普速筛选同时作用于列表和地图，搜索只筛选列表。
- 每条连接只有两个端点；点击连接只高亮该连接与两端站点。
- 点击站点查看直接相连的站点，再点击相邻项查看对应连接。
- 滚轮缩放、拖动平移；地图聚焦后支持 WASD／方向键、加减键和 Esc。
- 地图工具栏可适配当前网络、开关站名；重置视图清除筛选和选择。
- 窄屏下地图置顶，列表位于下方。

- 跨界连接仅分局内半段参与集体高亮。地图点选按中点区分内外侧；连接详情仍然只列出原有两个端点。
- 分局列表和概览显示站点数、高速和普速估算里程，不显示连接数量。里程按站点坐标之间的球面距离累计，跨界连接只累计内侧站至中点，按连接计长，不按轨道条数重复计算；这些数值不是实测铁路营业里程。

## 数据维护

当前数据包含 **2,289 个站点、2,588 条连接**，其中高速连接 1,790 条、普速连接 798 条。

`window.RAILWAY_DATA.stations` 每个 ID 对应一个站点，保存名称、城市、经纬度和区域。`connections` 保存 `{ id, from, to, type }`，`from`、`to` 引用两个站点 ID，`type` 为 `high_speed` 或 `conventional`。

连接不区分方向。同一对端点、同一类型只保留一条连接；同一对端点的高速与普速连接分别保留。新增一组连续站点时，只添加相邻两站之间的连接，不添加首尾直连或自动补齐其他站对。

本轮迁移保留所有原有站点及相邻连接，移除了整条线路的分组模型。坐标和分类遵循用户研究方案；地图连接表示邻接关系，不代表精确线路走向或现实开通状态。
