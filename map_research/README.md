# 铁路网络研究

独立的静态铁路网络查看器，以**站点和站点间的直接连接**为基本单位。统一入口为 `railway.html`，目录首页和旧 `new-railway.html` 地址均自动跳转到该页面。

在仓库根目录启动：

```powershell
py map_research/serve.py
```

访问 `http://127.0.0.1:8780/`，无需构建或 Airport 主服务。该服务同时提供按 seed 生成情景的接口；普通静态 HTTP 服务只能查看预置情景。

## 浏览方式

- 地图顶部“经济环境”打开 `economy.html`；分局概览的同名入口自动选中其经济区。返回铁路网络时恢复分局选择、筛选、地图位置和列表滚动。

- 左侧只保留分局列表，按分局或所属站点名称搜索；不再生成全网连接／站点大列表。搜索索引预先缓存，地图筛选和普通点选不重建分局列表。
- 统一显示整个泛中国路网，不按区域拆分；高速／普速筛选作用于地图，搜索只筛选分局列表。
- 每条连接只有两个端点；点击连接查看两端站点，并高亮所属分局管辖网。
- 点击站点查看直接相连的站点，再点击相邻项查看对应连接。
- 滚轮缩放、拖动平移；地图聚焦后支持 WASD／方向键、加减键和 Esc。
- 地图工具栏可适配当前网络、开关站名；重置视图清除筛选和选择。
- 窄屏下地图置顶，列表位于下方。

## 经济环境子页面

`economy.html` 展示以压缩包 `railway_economy_integration_v02.zip` 为基础扩展的 V0.5 游戏情景：2025—2085 共 61 个年度节点、八区五类价格／需求指标、全国实际利率，以及折叠显示的行业 PE 与行业 PE 参考指数。默认查看 2035 年，曲线和年度表只展示截至所选年份的样本；悬停曲线可查看对应年份及当前所选经济区的指标值，也支持聚焦图表后用左右键逐年查看，不改变样本年份。单独选择经济区时提示只显示该区。这是开发研究界面，不是正在运行的经营年份或现实预测。

`railway-economy-data.js` 保留包内分局经济区映射，并使用当前生成器预置种子 20261014 的完整公开情景。模型版本为 railway-real-macro-v0.3.1。`economy_model/` 保留原基准配置、扩展生成器及六类情景参数，由独立的 `serve.py` 调用；未接入虚构的分局收支样例。每家分局按映射读取所属经济区；利率和 PE 为全国共同参考。

页面支持输入 0—9,007,199,254,740,991 的整数 seed，点击“生成情景”重新计算，或点击“随机生成”。同一版本、配置和 seed 可重现相同路径，不同 seed 改变后续冲击和走势，2025 基期保持一致。当前 seed 写入页面 URL，刷新和复制链接可以重现；切换经济区、指标或年份不会重抽随机数。

V0.3 中 seed 还决定六类情景倾向：平稳增长、繁荣扩张、高波动、大危机、长期低迷、危机后复苏。参数调整长期增长、周期倾向、惯性、冲击强度和状态持续性；危机类预置多年度损失与渐进修复。页面显示情景类型、所选年份阶段及可展开的参数和示例 seed。类型、参数和事件使用独立随机流；扩展时间长度不重抽既有历史。类型是倾向，不保证每年表现或期末收益。旧 V0.2 相同 seed 的路径会因升级改变，已有世界应记录版本和配置哈希。

对照 seed：2 平稳、9 繁荣、0 高波动、1 大危机、7 低迷、13 复苏。预置参数位于 `economy_model/scenario_profiles.json`；以上都是游戏假设，不是历史拟合。

V0.3.1 工资由长期工资基础和滞后劳动市场压力共同决定：持续低迷、需求损失和危机可使实际工资下降；压力消退后逐步恢复，保留工资水平缺口及调整惯性。修改只作用于工资，客货需求、其他价格、利率及 PE 的同 seed 路径保持 V0.3.0 结果。行业 PE 参考指数仍为 PE／基期 PE×100，底层字段 `valuation_index` 保持兼容。

V0.4 加入地区独立发展路径：阶段持续 10—22 年、数年渐变，按地区不同权重抽取人口收缩、产业复苏、枢纽集聚、资源／贸易／旅游兴衰等状态。客运、货运和工资分别形成趋势，不要求一起涨跌；东北衰退概率较高，也可以复苏。年度指标表显示各区当前发展状态。设置位于 `economy_model/regional_profiles.json`，均为游戏假设；全国情景权重、利率及 PE 路径保持原规则。模型回归校验：`cd map_research; py -m unittest economy_model.test_regional`。

V0.5 校准成熟市场的长期趋势：阶段抽取的正客货运目标增速缩至 45%，负增速保留，之后再加入全国情景附加项；不削弱全国经济周期和危机冲击。提高人口收缩、长期调整及成熟发展阶段的持续性，降低收缩后复苏的额外加权，允许几十年衰退和后续复苏，不设置需求硬上限。工资公式保留并内生响应新需求。首批 128 个 seed 的 2085 年八区客运／货运等权平均中位数由 186.66／169.44 降至 125.90／118.94；独立 128 个 seed 的结果为 129.38／109.88。摘要见 `economy_model/calibration_v05.json`；这些指标不代表现实全国运输总量或分局财务结果。

本地 `GET /api/economy?seed=...` 返回该 seed 的研究情景公开指标，不返回潜在状态、随机数状态或事件台账；内存最多缓存 16 个 seed，不写入文件。只监听 127.0.0.1，不调用机场服务。

当前为静态样本浏览器，完整样本可在客户端查看。未来正式经营和决策 AI 需要由服务端按游戏年份仅返回当年及历史指标，不能直接使用这个完整样本脚本作为游戏数据接口。

### 指数预测

只在单一经济区、单一指数下开放“开始预测”。可设预测起始年份、2／5／10 年期限和 0—100 的期望准确得分。起点加期限不得超过 2085 年；生成后样本年份移到起点，历史实线截止当年，预测中位线以虚线向后延伸，悬停可查看预测值。推进样本年份后可叠加已发生的实际值，全部预测年份都已发生时显示回测得分。

`economy-forecast.js` 以真实未来、历史趋势及新的连续判断偏差形成每次预测的中位估计，不绘制区间。100 分直接复制真实未来，完全准确且不抽取随机扰动；其余期望得分是生成目标，实际得分通常在目标上下约 4 分内。预测评分 V2 按期限分别映射到全期平均绝对百分比误差（不计已知起点），回测时用同一映射反算得分；得分不再等于 100 减百分比误差。设置面板显示当前期限、得分对应的目标偏差。

| 得分 | 2 年平均年度偏差 | 5 年平均年度偏差 | 10 年平均年度偏差 |
| --- | --- | --- | --- |
| 100 | 0% | 0% | 0% |
| 95 | 0.6% | 1.2% | 2.2% |
| 90 | 1.2% | 2.5% | 4.5% |
| 80 | 2.5% | 5% | 8.5% |
| 70 | 5% | 10% | 17% |
| 60 | 8% | 17% | 28% |
| 50 | 12% | 25% | 40% |
| 0 | 25% | 50% | 80% |

分数节点之间连续插值。每次先抽取期望附近的质量得分，再用该期限误差尺度生成预测；相同得分不同期限的容许误差不同。单一年份绝对百分比偏差不超过该次全期平均偏差的 2.4 倍，下行预测保持正值；避免平均得分掩盖个别极端错误。以上为游戏设计尺度，不是现实报告行业评级。

每次点击“生成预测”使用新随机扰动，同一设置可以产生不同曲线。当前页面会话内按经济区／指数保留最近一份结果，悬停、缩放布局、切换显示和修改设置不重新抽取；再次生成或移除时才改变，成功切换情景 seed 时清除旧预测。刷新页面不保留预测。正式游戏应把生成放到服务器，客户端及决策 AI 只接收预测结果与已发布历史。

检查：`node map_research/test-forecast.cjs`。

经济环境页面右上角的“分局经营试算”进入 `bureau.html`，保留当前 Seed、年份及可用分局。当前东北十二家、华北十家共22家分局具备经营参数，其余经济区标为待初始化。页面完整显示 2025 基期及 2026—2085 六十年经营情景，可切换经营收支、投入成本、业务规模、人工对照与货运收入曲线；悬停查看年份，点击曲线、年份滑条或年度表同步单年十二项成本明细。累计结余不含基期。可查看当前配置并导出包含十二项成本明细的年度 CSV，配置只读。

`window.RAILWAY_DATA.stations` 每个 ID 对应一个站点，保存名称、城市、经纬度和区域。`connections` 保存 `{ id, from, to, type }`，`from`、`to` 引用两个站点 ID，`type` 为 `high_speed` 或 `conventional`。
