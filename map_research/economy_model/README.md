# 铁路宏观生成器

`simulate.py`、`config.json` 基于用户提供的 `railway_economy_integration_v02.zip` 中 `railway_economy/real_macro/`。基准配置原样保留，生成器增加了受校验的年度 `regime_index` 状态覆盖；不传覆盖时仍按原规则生成。

`scenarios.py` 与 `scenario_profiles.json` 提供 V0.3 的六类游戏情景：平稳增长、繁荣扩张、高波动、大危机、长期低迷、危机后复苏。seed 独立决定类型、区间内参数、事件窗口和具体随机路径。情景权重为 24／20／18／16／12／10，属于游戏设计假设。

V0.3.1 增加工资的滞后劳动力市场传导：需求收缩、持续偏弱、危机信用压力和需求永久损失累积为劳动市场压力；压力降低目标工资水平。实际工资从上一年压力逐步调整，允许负增长；需求复苏后压力消退，工资渐进追赶。该机制不强迫每年工资跟随客流同涨同跌，也不把负增长永久累加。六类 seed 选择及原客货需求、价格、利率、PE 路径不变。

界面的“行业 PE 参考指数”仍使用兼容字段 `valuation_index`，计算为 PE／基期 PE×100，不计算公司权益价值。

## 地区长期分化（V0.4 引入，V0.5 校准）

`regional.py`、`regional_profiles.json` 为八区增加独立、持续的长期发展路径。每个阶段抽取 10—22 年的持续期；每年以 25% 的速度向阶段目标调整，约数年完成主要转变。客运、货运、工资分别抽取趋势，能源与材料还有较小的本地价格水平影响；实际年度数值仍受全国周期、危机和原有地区扰动影响。

十二类状态包括人口收缩、长期调整、成熟发展、枢纽集聚、产业复苏、产业升级、资源繁荣／低谷、贸易扩张／承压、旅游兴起／低谷。客运与货运不要求同方向，产业升级可以表现为工资上升而铁路货运平缓。状态描述的是长期背景，不是该年实际同比涨跌。

地区初始抽取权重分别配置，每组合计 100：东北人口收缩 52、长期调整 16、成熟发展 10、产业复苏 16、枢纽集聚 2、旅游兴起 4。其他地区偏向对应的枢纽、资源、贸易、产业或旅游状态。以上权重都是游戏设定，不是现实概率或预测；东北并非必然衰退。

后续阶段沿用本区权重，并按上一阶段调整。V0.5 保留多数繁荣阶段的重复系数 0.22；人口收缩、长期调整、成熟发展的重复系数分别为 1.0、0.9、0.8，资源／贸易／旅游低谷分别为 0.55、0.5、0.45。降低收缩后转向复苏的额外加权，同时仍保留复苏机会。单个阶段仍为 10—22 年，相同或相邻的低迷状态可连续几十年。因此初始权重不等于长期年份占比。

V0.5 将每次阶段抽取的正客运／货运目标增长率乘以 0.45，负增长不变；然后再加入全国情景附加项，并按原规则逐年平滑。2025 年基期、初始过渡值和全国附加项不做同样折减，不能把这项调整解读为“把最终需求乘以 45%”。阶段之外的结构扰动、生产率项、经济周期与危机损失继续生效；不设置需求总量硬上限或回升保底。

工资目标不作同样缩放，工资的滞后劳动市场公式保留；需求与地区阶段变化会内生影响工资，因此工资数值可能改变。此处没有分局成本／企业效率模型，不把宏观生产率信号当作企业免费的单位成本改善。

全国六类情景的选择及全国利率、PE 路径保持原随机流；全国情景对本地目标增长率作有限调整，不把所有地区趋势拉回同一个正增长值。地区路径使用按地区隔离的选择、参数、持续期随机流，完整 60 年计划不随显示年份或内部遍历顺序改变。模型配置哈希包含地区预置配置，升级到 V0.5 后同一 seed 的地区数据会变化。

### 60 年校准检查

基期 2025=100；八区平均为等权诊断值，不是运输规模加权的全国总量。对照基线为提交 `c2b767d` 的 V0.4。

| 2085 年指标，中位数 | V0.4，seed 0—127 | V0.5，seed 0—127 | V0.5，独立 seed 10000—10127 |
| --- | ---: | ---: | ---: |
| 八区客运平均 | 186.66 | 125.90 | 129.38 |
| 八区货运平均 | 169.44 | 118.94 | 109.88 |
| 东北客运 | 84.78 | 58.72 | 55.69 |
| 东北货运 | 144.47 | 110.28 | 102.38 |

首批 128 个 seed 中，八区客运／货运平均的第 95 百分位分别为 216.60／219.20；东北连续低迷至少 30 年的样本由 44 个增为 76 个。独立的 128 个 seed 中分别为 238.43／244.35，长期低迷样本为 80 个。另检查预置 seed 和当前界面 seed，共 258 个 seed 的全国潜在因素及情景类型与 V0.4 完全一致，保留了危机和周期路径。

完整摘要见 `calibration_v05.json`。这些是合成游戏结果，45% 不是根据现实人口预测直接估计的系数，也未据此推算分局盈亏。

API 的 `regionalPhases` 只提供逐年地区状态名称，用于年度指标表；不返回未来阶段的参数、目标或结束时间。当前接口仍是完整研究样本，正式经营接口必须继续按经营年份截断。

验证：在 `map_research` 执行 `py -m unittest economy_model.test_regional`，检查复现、历史前缀、地区顺序独立、统一金融序列、共同基期、公开历史边界，以及东北可衰退也可增长、客货可分化。

危机在若干年间逐步损失需求，传导至信用、情绪、能源和材料价格。大危机仅部分修复损失；危机后复苏允许逐步追赶。所有情景保留相同的基期指数、全国利率及 PE。配置和事件计划与运行长度独立，短历史与长历史的前缀保持一致；完整事件计划只留在生成层。

第一批对照 seed：平稳 2、繁荣 9、高波动 0、大危机 1、低迷 7、复苏 13。同一版本、配置、seed 可复现；升级版本后相同 seed 可以产生不同路径，保存情景应同时保存模型版本及配置哈希。

由上级目录的 `serve.py` 调用，仅生成独立铁路研究情景；不运行机场模型、不生成分局财务、不写出完整潜在状态和事件序列。
