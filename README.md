# 万邦入洛

## 项目简介

《万邦入洛》是一套历史架空世界观与长篇叙事设定。本仓库首版只收录世界观正文，以及“祥兴南渡”第一阶段已经整理成 Markdown 的研究材料。

## 首次公开提交范围

以下内容属于首版公开内容：

- `世界观总纲.md`：全项目的总世界观构想；
- `一 祥兴南渡/`：祥兴南渡篇目前的 Part1 材料，包括阶段总览、专题一至专题七的研究思路与调研结果。

这些文件是项目自身的设定、问题意识和研究性整理，不依赖把原始书籍文件一并放进仓库才能阅读。

## 有意排除的内容

以下内容保留在本地资料库，不纳入公开仓库：

- `参考文献/` 下下载的 PDF、EPUB、TXT、小说电子书及其他原始资料；
- `tmp/` 下的临时文件、转码文件和处理中间产物；
- OCR 模型（如 `*.traineddata`）、压缩包及其他工具或缓存文件。

这样既能保持仓库轻量，也避免重新分发不必要的整本参考书。若日后需要公开研究过程，可另建“研究笔记”目录，只加入自行撰写的摘要、史料出处和公开链接，不加入原书文件。
