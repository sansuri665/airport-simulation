一、虚构国家

中文名：仙洲
英文名：Siano

设定用途：

1. `Siano` 是 `ASHEN PERIMETER` 世界观中的虚构国家。
2. 当前阶段只记录国家名、旗帜名和视觉意象，不展开完整政治、历史或地理设定。
3. 后续新手教程、战术简报、基地 UI、行动档案和过场文本可以引用该名称。
4. 国家视觉不应走现实国家直接映射，而应保持“山海文明 + 印度洋边缘基地 + 军事监视器”的混合气质。


二、国家旗帜

中文名：蜀山碧海旗
归属：仙洲 / Siano
英文工作名：Shushan Jade-Sea Flag
描述性译名：Shu Mountains and Jade Sea Flag
当前状态：仅记录设定和视觉口径，暂不生成旗帜图片。

核心意象：

1. 蜀山
   这里的“蜀山”不是单一山峰，而是从峨眉山一带远眺蜀山之王贡嘎山的视角。
   画面关键词：远山层叠、雪峰、冷白峰顶、深灰山脊、云雾间的高山轮廓。
   未来设计时不建议做成旅游风景明信片，而应抽象成可识别的远峰轮廓、负形雪顶或几何化山脊。

2. 碧海
   这里的“碧海”是印度洋风格的海，不是北方冷海或内陆湖。
   画面关键词：深青蓝、碧绿海面、热带 / 亚热带海域、辽阔洋面、带湿润空气感的海色。
   海色应偏印度洋的深青、绿蓝和湿润暖光，不要做成地中海旅游蓝或北大西洋冷灰。

3. 旗帜整体读法
   `蜀山碧海旗` 应该表达“山与海共同构成国家精神”的感觉。
   山代表纵深、坚守、古老高地和内陆文明根系；海代表开放、航路、南方洋面和海外基地。


三、可实现性判断

该旗帜可以通过静态图实现。

建议不要一开始做复杂写实国旗，而是先做三种可选方向：

1. 标志化国旗
   用简化山形、雪峰和海浪色带组成，可用于 UI、军徽、旗帜、地图标记。

2. 战术简报插图
   用更写实的峨眉远眺贡嘎山 + 印度洋碧海构图，作为教程开场或国家介绍背景。

3. 监视器化低色版本
   把旗帜压成灰白监视器风格，只保留山形和海纹轮廓，适合游戏当前黑白灰 UI。

生成约束：

1. 不使用现实国家旗帜、国徽或政党符号的直接构图。
2. 不加中文或英文文字，避免小尺寸 UI 中变成噪点。
3. 标准旗帜应控制在 2-4 个主色，方便之后做灰度、低透明和战术 UI 版本。
4. 小尺寸下必须仍能看出“远峰 + 碧海”的二元结构。
5. 如果后续生成写实教程背景图，仍要保留与国旗标志版一致的山海关系。


四、初步构图建议

旗帜标准版可以考虑：

1. 上半部为蜀山远峰。
   多层山脊从深灰过渡到冷白雪峰，最高峰暗示贡嘎山。

2. 下半部为碧海。
   使用深青蓝到碧绿的水平海色或抽象波纹。

3. 中央过渡带为雾或云。
   用云雾把山与海连接，避免硬切。

4. 不使用过多具象太阳、龙、鸟或现实国徽元素。
   当前方向应保持克制、冷静、军用、可图标化。

5. 可以考虑把雪峰做成中央或偏上方的负形白三角，海面做成底部两到三道低饱和青绿波带。

6. 如果需要更国家化的正式感，可以只在边缘加入极窄暖白或低饱和金线，不作为主色。


五、色彩方向

主色：

1. 山体深灰 / 青灰
2. 雪峰冷白
3. 海面深青蓝
4. 碧海青绿

辅助色：

1. 雾白
2. 暖白高光
3. 少量低饱和金色或淡黄色可用于正式国旗边饰，但不建议早期使用。

避免：

1. 高饱和红色主导。
2. 过度奇幻仙侠化。
3. 直接照搬现实国家旗帜构图。
4. 太复杂导致小尺寸 UI 无法辨认。


六、新手教程中的使用方式

在新手教程的静态分镜中，`蜀山碧海旗` 可以这样出现：

1. 开场战术简报角落的国家标识。
2. 半岛基地指挥所墙面或操作界面的低透明徽记。
3. 行动档案页的国家 / 行动归属字段。
4. 通讯字幕中的署名，例如 `SIANO PERIMETER COMMAND`。
5. 过场中一帧短暂的旗帜特写，用于建立“这是仙洲的防线”。
6. 如果做连环静态动画，旗帜更适合以档案封面、简报页角标、通讯界面水印和基地外墙标识出现，不宜做成过长的国家介绍段落。


七、主角组记录

当前主角组预计为五人，先记录已确定角色。
当前主角组已确定为以下五人，不再默认扩充核心主角人数。

1. 青阳成安
   项目显示名：Tsingyang Chengan
   威妥玛备查写法：Tsing-yang Ch'eng-an
   拼音备查写法：Qingyang Cheng'an
   性别：男
   年龄：28 岁
   国籍 / 阵营：仙洲 / Siano
   面孔与族裔读法：华裔面孔为主，可带很弱的北欧混血痕迹
   军种 / 单位：仙洲军第 3 本土快速反应集群第 16 联合航空营战术支援中队
   英文单位工作名：3rd Homeland Rapid Reaction Group, 16th Joint Aviation Battalion, Tactical Support Squadron
   军衔：空军上尉
   英文军衔工作名：Air Force Captain
   游戏视角职责：无人机引导操作员，也是当前玩家战斗视角背后的战术支援人员。

   角色功能：

   1. 在新手教程中承担玩家视角的第一层人格化入口。
   2. 可通过通讯框、战术简报署名、任务语音字幕或静态分镜头像出现。
   3. 他的存在解释了为什么玩家能以高空无人机视角观察基地、引导 12.7 HMG 与 40MM AGL 火力。
   4. 叙事上不必一开始完整介绍个人经历，先让玩家知道“有一个具体的人在操作这套支援链路”。

   专业能力补充口径：

   1. 青阳成安不只是“会操作无人机”的军官，他本身也是高水平的 `Energy` 专家。
   2. 这个世界的无人机控制并不主要依赖传统摇杆和姿态参数微调，而更像是在连接、拨动和重排 `Energy` 的分布与通路。
   3. 因此真正高超的操纵，本质上是一种近乎艺术的 `Energy` 编排能力。
   4. 成安的优势不是单纯反应更快，而是他已经开始接近一种“自动化直觉”。
   5. 他能够提前搭建一些 `Energy` 的反馈通路，让无人机在既定边界内自行顺应编队变化、目标变化和机体状态变化。
   6. 这意味着他在操纵攻击无人机甚至攻击无人机集群时，不必持续调用庞大 `Energy` 去逐项修正各种动作参数，而是让机群沿着预先搭好的反馈通路获得某种自适应助力。
   7. 从技术路线看，这种能力已经接近当前世界里“自动化”甚至更高阶无人协同的萌芽。
   8. 不过当前剧情阶段，他手里主要仍只有侦查无人机，这使他的真正上限尚未完全兑现。
   9. 另一个很重要的口径是：成安并不只是操作员。他作为战术支援中队出身的空军上尉，本身也兼有营参谋职能，因此天然具备接管基地系统、整理态势和承担实时指挥职责的条件。
   10. 在这个世界里，操纵无人机、接管建筑系统和拨动大型装置的 `Energy` 信息流，本就是相通的能力谱系。
   11. 如果再往深一层写，成安真正触碰到的其实是这个世界的底层计算器件路线。
   12. 若琳更像在做 `Energy runtime` 与能流编排，成安则更像在做一种“集成光路”级别的东西，只不过在那个世界里应称为 `集成能子处理器`。
   13. 在微通路中，他通过设置一组组模板，让不同偏振态、波长、相位或相近属性的 `能子束` 表示不同状态，并进一步完成类似芯片中的数字、模拟、门控和反馈功能。
   14. 换句话说，成安路线并不只是更会操纵无人机，而是在一步步搭这个世界自己的计算机、神经网络与人工智能底层。
   15. 因此到了 `Stage 2`，当思琳越来越多地被困在能舱中时，成安事实上会开始承担基地的实时指挥官职责。
   16. 甚至连 AC-130 这类平台，在 `Energy` 驱动逻辑足够接近的前提下，他也完全具备接手操纵的可能。
   17. 也正因为如此，他在 `Stage 2` 里其实拥有一条很危险的潜在道路：
       抽走思琳的治疗资源和曦岭的地面防御资源，把它们全部转去航空支援，然后在“不得已”的逻辑下成为新的事实指挥官。
   18. 无线电里甚至会传来别处据点已经出现过类似资源倾斜的消息，这让这种可能性不再只是理论。
   19. 但成安最终做出的恰好是反方向选择：优先建医院改善思琳的治疗与生活条件，保住曦岭的地面防御资源，并由自己承担自杀无人机带来的神经冲击代价。
   20. 这种选择会成为他人格可信度的真正来源，而不只是战斗能力。
   21. 每次成安承受完自杀无人机带来的脑部震荡后，艾琳娜都可以成为最直接的缓解执行者。
   22. 她在一次处理后轻轻说一句“你还是我认识的那个成安”，会很准。
   23. 这句话不是在奖励他，而是在确认他仍然是那个握住权力后没有顺势放弃别人的人。

   肖像 / 分镜视觉备忘：

   1. 28 岁高颜值华裔男性军官，可带很弱的北欧混血痕迹；整体仍应首先读作华裔 / 东亚面孔。
   2. 视觉年龄必须接近二十代后段，避免画成中年、沧桑老兵、胡茬重或面部沟壑过深。
   3. 气质应偏冷静、专业、疲惫但不崩溃；更像战术航空支援人员，不是前线突击兵。
   4. 服装可采用仙洲军飞行 / 战术支援制服、耳麦、轻量化通讯终端和肩章。
   5. 在静态教程中适合出现在灰白监视器通讯窗口、战术平板反光、简报页证件照或操作席侧影。
   6. 后续生图时应避免过度动漫化或英雄海报化，保持军用监视器和战术简报气质。

2. 李思琳
   项目显示名：Li Celine
   拼音备查写法：Li Silin
   性别：女
   年龄：31 岁
   国籍 / 阵营：仙洲 / Siano
   面孔与族裔读法：中国和俄罗斯人混血面孔；与李若琳有明显姐妹相似度，混血痕迹同样应较明显
   军种 / 单位：仙洲军第 3 本土快速反应集群第 16 联合航空营航空打击 A 中队
   英文单位工作名：3rd Homeland Rapid Reaction Group, 16th Joint Aviation Battalion, Air Strike Squadron A
   军衔：空军少校
   英文军衔工作名：Air Force Major
   职务：航空打击 A 中队指挥官；AC-130 驾驶员、机长和任务指挥官。

   番号合理性备忘：

   1. `第 3 本土快速反应集群` 可以作为战区 / 任务集群级编制，负责半岛基地和本土应急防御。
   2. `第 16 联合航空营` 适合作为混编航空支援单位，容纳无人机引导、武装运输机、炮艇机和战术支援分队。
   3. 从更深的技术路线看，第 16 联合航空营不只是传统空军单位，也可以视为仙洲军内部一个相当独特的“联合非均一化架构”试验场。
   4. 这能解释为什么它比很多传统基地与重装单位更容易接住后续主角组那条新路线。
   5. `航空打击 A 中队` 与同营下的 `战术支援中队` 层级并列，中文和英文都更清楚。
   6. `空军少校` 作为 AC-130 机长兼中队指挥官合理；31 岁偏年轻但可成立，尤其在高强度战时、快速反应部队或精英航空单位中。

   角色功能：

   1. 可作为空中火力链条的上级飞行端角色，与青阳成安形成“地面 / 无人机引导 - 空中炮艇机”协作关系。
   2. 在教程中可负责解释空中支援、弹药限制、火力窗口、AC-130 待命与撤离流程。
   3. 她既是飞行员也是机长 / 指挥官，因此可以在静态分镜里出现在驾驶舱、任务简报席和无线电频道中。

   进一步定位补充：

   1. 李思琳的价值不能只写成“会开飞机”。她真正稀缺的地方，是她既懂飞行、懂火力，也懂战时残存建制之间那种近乎老狐狸式的博弈。
   2. 当后续出现其它残存基地、集群残部、地方守军甚至外军单位时，主角组里真正有资格坐上桌谈条件、压人、试探、让步和下狠心的人，首先应是她。
   3. 这能解释她为什么像一个真正的少校指挥官，而不只是漂亮的 AC-130 机长。
   4. 与另外四人相比，她身上应多一层更冷的现实主义：别人还在想着技术、理想、感情和善意时，她已经在计算谁会背叛、谁会谈判、谁还能被组织起来。
   5. 但思琳本人在生理层面并不是这支队伍里最适应非均一化环境的人。
   6. 相比陈曦岭的原生改造体质，以及成安、若琳、艾琳娜与蓝色药剂体系形成的适应性，思琳对非均一化环境的承受能力明显更弱。
   7. 这会让她在后续长期处于“精神上最硬、身体上却更容易被拖垮”的状态，并解释她为何需要反复进入能舱治疗。
   8. 更进一步地说，她是当前主角组里唯一没有注射蓝色药剂的人，因此在 `Stage 2` 以后，她的痛苦和能舱依赖都应比其他人更明显。
   9. 她仍会通过无线电与其它残存部队交流，试图维持建制感和外部联系，但所有人其实都知道：当前已经很难形成真正意义上的互相支援。
   10. 这也会形成一个很冷的现实：思琳名义上仍是最高指挥，可她本人越来越难离开能舱，而那台 AC-130 也会因为 `Energy` 不足而在一段时间内无法起飞。
   11. 她不会轻易把这种处境浪漫化。她很清楚，只要成安有心，再加上艾琳娜掌握她的治疗链路，她理论上几乎是十死无生。
   12. 她自己未必会太在乎生死，但她会非常在乎若琳的命运；这会成为她在虚弱状态下仍保持警惕的核心原因之一。
   13. 因此她与成安之间很适合有一场极短的病房对话。
   14. 她先和若琳聊一阵，再借故把妹妹支开，只留下成安。
   15. 然后她递给成安一张旧照片，上面是他们都认识的、曾经来自隔壁营的上尉军官。
   16. 她只说：
       “认识他吧？他现在是中校了。那个营的指挥官。”
   17. 这不是闲聊，而是在提醒成安：战乱会迅速制造新的位置，也会迅速吞掉旧的人。
   18. 等成安点头后，她再问：
       “为什么你这样做？”
   19. 这里的潜台词很明确：你明明有机会把我技术性放弃，为什么没有。
   20. 成安的回答可以定为：
       “这里只有五个人了。
       而且我答应了若琳，一定有办法救她姐姐。”
   21. 这会让思琳第一次真正确认：成安不是没看懂，而是看懂之后仍然没有顺着那条路走下去。
   22. 到了 `Stage 2` 后半段，思琳的病情会逐渐稳定下来。她离完全恢复仍远，但已经不再只是被动维持的重症伤员。
   23. 反过来，真正开始被透支拖垮的人会变成成安。
   24. 艾琳娜会借故说要做实验，私下从曦岭那里提取一部分血液样本，并手工做出一支更弱化的衍生药剂。
   25. 这支药剂无法完整复现最初蓝色药剂的强度，却足以配合医院治疗把思琳推回缓慢恢复区间。
   26. 等思琳终于恢复基本指挥能力后，成安会把自己临时承担的指挥职责交还给她，而自己住进病房接受恢复观察。
   27. 这一连串结果会让成安与艾琳娜都更加确认：当初优先修建医院，是一个真正改变了结局的决定。
   28. 到了 `Stage 2` 最后，众人会开始讨论未来规划。
   29. 思琳会本能地主张继续补强防卫力量；既然 AC-130 的起飞能源已经重新足够，她也会明确说，不能再让成安继续做那种损伤巨大的事情。
   30. 但成安会在这个节点上坚持提出：一定要给若琳修建实验室。

   3. 气质应是镇定、疲惫、温和但能下硬决定；不要做成单纯治愈系或柔弱角色。
   4. 静态分镜里适合出现在临时手术灯下、伤员分诊台、撤离名单前或通讯频道里的医疗状态汇报。
   5. 暂不生成肖像图；后续可先做医疗频道头像、战地医院内景或分诊静态分镜。


八、科技树基调

当前世界的科技发展不走全面未来化，而是呈现不均衡状态。

1. 武器阶段
   主流武器仍处在现代常规阶段，玩家当前使用的 `12.7 HMG`、`40MM AGL`、AC-130 风格炮艇机、轻机枪阵地和常规防御墙都应保持可理解的现代军事读法。

2. 后续扩展
   后续可以出现电磁加速武器、实验性特种武器或更高阶弹药，但它们应作为少量高价值装备、试验型号或后期解锁内容出现，不应一开始覆盖整体世界观。

3. 无人作战平台
   与常规武器相比，无人作战平台、无人机侦察、战术数据链、远程引导、自动化监视和空地协同已经非常成熟。

4. `Energy` 基础口径
   `Energy` 不是单纯的电力，也不是纯粹的魔法资源。它更接近极其复杂的电流和信息流的混合体，能够在材料、设备和周围环境之间建立高效交互。

   补充定义：

   1. 从人类工业角度看，`Energy` 已经开始成规模应用，而不是只停留在实验室或神秘遗物阶段。
   2. 当前设定中，基础矿物被称为 `Energy原石`。
   3. `Energy原石` 经过冶炼和处理后形成可用成品，即 `能解质`。
   4. 但“将电能注入能解质”这种说法并不完全准确。
   5. 更接近真实的理解是：人类通过烧水、风力、水力等宏观做功手段制造受控 `能流`，再借这股流动去对自然 `能场` 富集区施压，完成额外自然 `能子` 的提取、均一化与调用。
   6. 因此 `能解质` 的作用并不只是储能，而更像是这种杠杆式提取、均一化、暂存和释放过程中的稳定介质。
   7. 真正特殊的地方在于：这里被提取和整理的不是普通意义上的电荷，而是一种近乎带有灵性、信息性和环境响应能力的 `Energy` / `能子流`。
   8. 这使它能够跨越能源、控制、信息、生物医疗和环境交互等多个边界，而不只是单纯供电。
   9. 这一工业过程本身还会伴随大量损耗与逸散，它们对当地自然 `能场` 的扰动效果，近似于现实世界中温室气体对气候系统的长期影响。
   10. `能解质` 的再生能力显著强于自然矿物；当前人类侧推测，这与微生物聚合、矿物活化以及世界中某种“自然 Energy 流动”有关。
   11. 换句话说，人类已经会“用”它，甚至会“工业化放大”它，但未必真的理解它。

   更深层口径：

   1. 从总剧情层面看，`Energy` 并不是单纯的人类本土技术发现，其背后与明确存在的外星势力介入有关。
   2. 这个外星势力不应被简单理解为纯粹恶意入侵者；从其自身立场出发，它所做的事情甚至可能被视作一种“善事”。
   3. 因此 `Energy` 不只是高效能源，也会在后续剧情中成为文明立场、价值判断和“谁在拯救谁”这一问题的核心媒介。

5. 生物路线与企业口径
   当前人类并非没有尝试把 `Energy` 用在生物体上。

   1. 其中最明确、最危险的企业力量可命名为 `开云生物 / Kairon Bio`。
   2. 从人类立场看，`Kairon Bio` 是确定无疑的反派组织之一，但危险点不在于它“反军方”或“反均一化”，而在于它把生物改造推成了另一条更失控的道路。
   3. 它代表的是人类在机械路线之外，对“改造生命”“激活生物体”“让生物直接承载 Energy”这条路线的激进尝试。
   4. 这家公司与外星势力存在秘密合作关系，虽然并非只有它一家在做类似尝试，但它是当前最典型、最核心的案例。
   5. 它的目标并不只是治疗或增强人体，而是尝试用 `Energy` 激活、重塑甚至重新定义生物体。
   6. 不过外星合作方显然隐瞒了关键步骤或关键知识，因此人类生物路线始终无法真正成熟。
   7. 现阶段制造出来的很多产物虽然具备某种活性或强化痕迹，却常常表现得呆滞、迟钝、失衡，像是只拿到了半套方法。
   8. 换句话说，开云并不是站在旧式均一化架构那边死守的人；它其实也在试图适应非均一化架构，只是方式是把生物体本身改造成相容容器。
   9. 这也解释了为什么当前世界的人类总体上仍然“重机械而轻生物”：不是没人尝试，而是生物路线既危险、又不稳定、又被关键信息卡住。

6. 无人化原理
   由于 `Energy` 本身带有复杂的信息流和控制特性，许多无人装置不需要依赖高度复杂的芯片、光纤传输、传统算法堆叠和大规模训练，就能实现对环境的快速感知、反馈和机械动作控制。

7. 无人化边界
   这个世界的“无人化”更多意味着指挥官通过 `Energy` 系统长出了很多只手，可以远程控制、分配、协调大量器械；它并不等同于人们印象中的全智能、自主思考机器人社会。

8. 非均一化与自动化萌芽
   当前世界的无人化其实也被点偏了。

   1. 主流路线更强调均一化、标准化和可大规模部署，因此更擅长做“稳定工具”而不是“复杂适应体”。
   2. 非均一化 `Energy` 应用恰恰对应了更接近现实世界人工智能萌芽的那条方向：不是把每一步动作写死，而是让系统在反馈中逐步形成自适应。
   3. 只是这条路线在当前世界里过于不受重视，因为它不够赚钱、不够标准，也不够容易纳入主流工业与军用体系。
   4. 成安的操纵天赋与若琳的研究方向，其实在这一点上是隐秘呼应的：一个在实战中凭直觉搭建反馈通路，一个在理论上研究非均一结构如何承载 `Energy`。
   5. 因此两人并不只是“懂技术”，而是在触碰这个世界尚未被主流承认的另一条未来路线。
   6. `Stage 3` 开头可以把这件事写得更具体：
      若琳尝试让不同性质的 `Energy` 不再被强行抹平，而是在更精细的通路设计中彼此中和、缓冲、错位与接力，从而让不完美输入依旧得到稳定输出。
   7. 成安则把自己长期依赖直觉完成的操纵经验，逐步翻译成可继承的反馈结构。
   8. 两人共同逼近的，不是完整意义上的人工智能，而是一种近似早期神经网络的非均一 `Energy` 响应结构。
   9. 这种结构最先改善的，就是成安此前负担最重的自杀无人机路线：
      平台开始具备更高程度的末端自主性，成安不再需要把神经连接维持到爆炸最后一瞬。
   10. 这也会让艾琳娜最直接地松一口气，因为她终于看到成安不必继续用自己的脑部冲击去硬补整条打击链路的结构缺陷。
   11. 若琳路线之所以难，不只是理论深，而是要同时处理输入紊乱、缓存容量、终端容忍度、反馈预测与错误传播。
   12. 因此它不像传统均一化路线那样追求“先把世界变整齐”，而更像在混乱输入里实时维持一个可工作的概率秩序。

9. 三条路线的当前格局

   1. 第一条路线是传统均一化架构，它依然是仙洲军和多数幸存基地的现实底盘，但整体上已经越来越像苟延残喘的巨型系统。
   2. 第二条路线是各大生物公司陆续采用的非均一化生物体改造架构，它危险、激进、产物不稳定，却也是当前最像真正敌对进化方向的路线。
   3. 第三条路线则是主角组正在逼近的联合非均一化架构：
      不是让人变成怪物，而是让人通过 `Energy` 介质层去高效统御 `Energy` 驱动的机械与武器系统。
   4. 这条路线成熟后，甚至可能让陈曦岭一人承担一个重装甲集群的实时指挥与协同。

10. 游戏视角解释
   玩家能够以高空无人机视角观察战场、引导火力、读取基地状态和进行战术部署，是因为仙洲军的无人平台与指挥链成熟，而不是因为所有武器都进入科幻阶段。

11. 视觉边界
   装备可以有先进传感器、冷色 HUD、数据链终端、无人平台挂架和自动化接口，但枪炮本体、弹药、墙体和基地设施仍应有现代材料、铆接、复合装甲、油污和战损痕迹。

12. 叙事用途
   五人主角组正好覆盖这条科技树的不均衡性：青阳成安负责无人机引导，李思琳负责常规空中炮艇火力，李若琳解释材料与能源系统，陈曦岭解释地面协同，艾琳娜·索尔贝格解释战地医疗和感染压力。

13. 李若琳的重要性
   因为 `Energy` 横跨材料、能源、控制、信息和生物医疗边界，李若琳这样的应用材料与能源博士不是普通技术顾问，而是能够理解基地资源系统、能舱、能源装置、无人器械和混合疫苗底层逻辑的关键人物。

14. 幸存势力格局
   当前世界不会只剩五名主角。

   1. 仙洲军第 3 本土快速反应集群在整体崩溃后，仍会有残存部队在不同区域据守、撤收或重建基地。
   2. 除仙洲本土残部外，后续也可以存在外军、地方守军、撤离链残部和少量仍保有航空能力的单位。
   3. 但除少量航空兵、炮艇机、运输机与无人机链路还能勉强跨区域活动外，大多数地面力量已经失去稳定跨区域机动能力。
   4. 因此后续世界的结构更像许多彼此失联、技术路线不同、资源状况差异极大的孤岛据点，而不是彻底空无一人的废土。

15. 均一化基地在紊乱时代的代价
   这个设定非常重要，它会直接影响后续基地强弱关系。

   1. 随着自然 `Energy` 流动持续紊乱，传统大型均一化基地虽然仍有规模、库存和建制优势，却会越来越吃亏。
   2. 原因在于它们的系统是按大规模稳定输入、标准化输运和均一环境维持来设计的；一旦外界紊乱加剧，维持整套体系本身就要吞掉巨量 `Energy`。
   3. 某些时候，这类基地甚至需要额外消耗能源，只为了压平局部紊乱、维持内部设备和生活区不失稳。
   4. 结果就是：人数越多、设施越大、防线越广，日常生活反而越艰难，许多防线也无法再长期保持全面激活状态。
   5. 这会让主角所在的小型基地在后期获得一种反直觉优势：它未必更强，但更容易被重新设计、更容易调整流路，也更可能撑过高紊乱阶段。
   6. 不过均一化环境仍然有一个巨大优点：人类待在其中，会更接近正常氧含量环境那种舒适感，不像直接暴露在非均一化环境里那样容易产生类似高原反应的负担。
   7. 这也解释了为什么传统路线不会轻易退出历史舞台。它正在变贵、变笨重、变危险，但它对普通人依然更“好住”、更“像文明”。

16. 后期战略节点
   这部分更接近后期剧情与大型抉择，不一定会立刻进入当前 demo，但建议尽早定口径。

   1. 李思琳在后期完全有可能提出一次极度冒险的先发制人空袭计划，代号可定为 `弩箭`。
   2. 这一命名可视作对旧时代“弩炮行动 / Crossbow”一类战略空袭概念的致意。
   3. 她的目标不是单纯炸地面，而是优先一举消灭其它组织仍残存的空中力量，以免这些力量后续在压力、利益或恐惧驱动下投向开云阵营。
   4. 这非常符合思琳的角色逻辑：她最清楚谁一旦还握有飞机、航程和空中投送能力，谁就还保有继续下棋的资格。
   5. 关于“为什么开云的生物兵器没有顺手统治天空”这一逻辑，可补充为：
      这类非均一化生物兵器在地面突击、近距压制、复杂地形渗透和短时爆发上很强，但在高空、远程航渡、持续编队、精密对空拦截和复杂空战中稳定性不足。
   6. 这既能解释为什么思琳仍把其它人类组织的空中力量视为首要战略威胁，也能避免游戏后续系统被拖入过度复杂的生物空战展开。
   7. 但思琳自己也会明白：就算 `弩箭` 成功，后续的地面决战依旧未必有高胜算。
   8. 更狠的一招，反而会来自若琳。
   9. 她提出的 `能源震荡器`，名字听上去像普通工程或能源设施，实质却是用来彻底破坏一个区域所有 `Energy` 运转波动的装置。
   10. 它的可怕之处不在爆炸规模，而在于它会直接把区域性的 `Energy` 协调秩序撕碎。
   11. 对普遍已经做过改造的生命体而言，这种武器甚至比核武器更残酷。
   12. 改造程度越深，越可能在瞬间失去结构稳定，直接解体成血雾。
   13. 但若琳这条线很关键的一点是：她做出来的不是失控灾厄，而是高度可设计、可收束、可复盘的工程化杀伤。
   14. 因此这一装置真正投入使用后，影响范围会被压得很准，绝大多数后果都被限定在预定区域内，而不是无边扩散成世界级惨案。
   15. 也正因为如此，主角组在真正执行后未必会陷入想象中的巨大心理崩塌；他们甚至会发现，这件事做起来比预想中更容易被接受。
   16. 一方面，投靠生物公司的平民成分本就极其复杂，实际规模也未必有战前宣传想象得那么大；另一方面，只要在战后报告中轻描淡写地处理平民部分，整次行动几乎就是一次结果漂亮、边界清晰的完美作战。
   17. 这一点比“痛苦抉择”更末世：真正高级的残酷，不再需要靠情绪支撑，而是会直接伪装成高效、克制、专业和可汇报。
   18. 不过 `能源震荡器` 依旧不是万能解。某些生物兵器基地难以被这一机制直接抹除，仍会在后期持续生产。
   19. 这些残存基地反而更像是外星势力留下的正统“教学”兵器，它们不断迫使人类去理解非均一化环境下更成熟的组织、适应和战斗方式。
   20. 因而后期结局会保留希望：世界范围内自然 `Energy` 流动的紊乱开始缓慢缓解，但新的技术竞争并未结束。
   21. 思琳会倾向于把这一切理解为一种非常冷的外星干预逻辑：
       他们不是单纯在毁灭，而是在用兵器、压力和筛选过程，强迫这个世界的人类朝某条更可接受的技术路线成长。


九、感染与尸潮设定

当前角色对病毒所知很少，只知道尸潮已经以排山倒海的规模冲入各国。

基础认知：

1. 这种病毒可以通过咬伤传播。
2. 与通常丧尸病毒不同，被咬者不会迅速狂暴，也不会在短时间内直接转化成新的丧尸。
3. 感染者的病程较慢，早期症状甚至接近轻感冒，因此非常容易被误判或延误处理。
4. 当前推测死亡机制不是“病毒直接制造丧尸化”，而是病毒与机体之间发生剧烈排异，最终导致系统性崩溃。
5. 军方和医疗系统已经陆续观察到异常“昏睡症”患者，也就是中段病程患者；这使内部开始意识到常规医疗手段几乎没有希望。
6. 角色组无法确认全部机制，因此教程和剧情中应避免把病毒解释得过满。
7. 另外，“病毒”这个叫法本身也未必精确。它更像一个沿用旧时代语言的方便称呼；在更正式的技术语境中，可把它理解为一种 `微动力生物引擎`，即对自然病毒、细菌乃至微生物协同机制进行改造后形成的 `Energy` 扰动载体。

深层真相口径：

1. 这种病毒并非单纯自然产生，而是与 `开云生物 / Kairon Bio` 之类企业的人造生物技术路线直接相关。
2. 它的本质不是“让人变成传统丧尸”，而是强行改写人体内部 `Energy` 的流动方式。
3. 到了 `D Year` 那段时间，世界本身的自然 `Energy` 场开始出现明显紊乱，可类比某种周期性但极端化的气候变化。
4. 正是在这种大环境下，病毒活性被大幅放大，原本就危险的病程变得更容易集体爆发。
5. 但更早以前，异常“昏睡症”的先兆其实已经出现。那时它的强度很低，更像长期化感冒、体力下降、咳嗽增多和偶发性 `Energy` 通路紊乱，而不是大规模公开恐慌。
6. 当时社会普遍已经知道自然 `Energy` 流动会周期性失稳，因此主流治疗逻辑不是单纯“杀病毒”，而是重新调整人体的 `Energy` 通路，让患者重新接上更稳定的内部循环。
7. 这也解释了为什么能舱会在灾难前就逐渐成为高端医疗的核心设施之一：它不只是抢救装置，也是当时被寄予厚望的标准化治疗平台。
8. 到 `D Year` 前夕，仙洲社会整体上已进入一种类似现实疫情时代的低活力期：感冒频发、请假增多、训练与生产效率下滑、医疗系统被长期拖累，但秩序表面上仍未崩盘。
9. 医疗条件良好的官员与行政系统并不把这视为真正无解的危机；他们更倾向于认为，只要继续扩建能舱、完善导流治疗和提高配给，疫情终究会被压住。

病程口径：

1. 早期，前两三天
   症状类似轻感冒，可能出现低热、咳嗽、乏力、轻微头痛、脸色差等表现。感染者仍能交流和行动，因此最危险的是“不像马上要死”。
   这里的咳嗽不只是普通炎症反应，也可以理解为生物体在初期试图重新稳定自身 `Energy` 流动时出现的第一层免疫 / 排异表现。

2. 中期
   体力迅速下降，感染者会虚弱到几乎无法做任何事。这个阶段更像身体被拖空，而不是进入攻击性狂暴。
   军营和医疗系统内部可将这类患者称为异常“昏睡症”患者。
   更深层地说，病毒导致的 `Energy` 乱流会开始明显干扰肌肉、神经和协调系统，因此患者会表现出无力、迟滞、行动困难和意识状态恶化。

3. 末期
   感染者出现类似狂犬病末期的抽搐并死亡，但抽搐并不一定剧烈，甚至通常不需要拘束。表现应更偏衰竭、神经性痉挛和安静死亡，而不是夸张挣扎。
   这也解释了为什么患者会抽搐、痉挛、失控，却终究无法像传统丧尸设定那样稳定控制活人身体。

4. 死亡后
   当前文档暂不确定被咬感染者死亡后是否会转化为尸潮的一部分。第一幕只需要保留“咬痕会导致严重病程”的恐惧，不急着解释完整生态。

与常规丧尸设定的区别：

1. 咬伤传播成立，但感染者不会立刻变成敌人。
2. 恐惧重点不是短时间内失控咬人，而是长时间等待、医疗无力和撤离选择压力。
3. 李若琳的咬痕因此更适合表现为低烧、苍白、虚弱和被包扎监测，而不是当场变异。
4. 艾琳娜·索尔贝格的医疗判断会更痛苦，因为她面对的是缓慢恶化的病人，不是可以立刻按敌我处理的怪物。
5. 异常“昏睡症”之所以无力、抽搐、衰竭，却不会自然变成传统意义上的活人丧尸，正是因为病毒擅长制造 `Energy` 乱流与系统性干扰，却并不能真正完成对活体的稳定接管。

国家社会崩溃机制：

1. 该世界的尸潮并不是单靠普通丧尸本身击溃国家组织。
2. 第一阶段，在灾难前相当长一段时间里，低强度病程已经在军营、警察、医疗、交通和基础设施岗位中扩散。大量关键岗位人员陷入“感冒、无力、反复治疗、短暂恢复、再次发作”的循环，先一步拖慢了整个社会的节奏。
3. 第二阶段，到 `D Year` 前夕，这种长期化病程进一步降低了训练质量、值班覆盖和应急效率，使各类体系虽然还在运转，却已经明显失去弹性。
4. 第三阶段，明确的外星势力介入，并与本土生物公司共同制造、放大或释放更危险的生物兵器。
   当前最关键的本土公司口径可指向 `开云生物 / Kairon Bio`。
5. 第四阶段，这些力量对重点目标发起有组织突袭，包括军营、机场、能源节点、通信枢纽、医院、政府中心和交通关口。
6. 因此各国被击溃的原因是复合灾难：内部战斗力先被长期病程削弱，外部有组织敌对势力再趁机打击关键节点，尸潮最后利用崩溃后的缺口扩大灾害。
7. 这能解释为什么有现代军队和重武器的国家仍会失控，也能避免把丧尸表现成不合理地“自然战胜一切”的单一威胁。

已知对抗手段：

1. 常规医学手段
   对这种病症和引发病症的患者几乎没有有效对抗希望，只能做基础隔离、补液、镇痛、降温和维持生命体征。

2. 能舱
   除常规支持治疗外，当前已知最强手段是使用极高强度消耗 `Energy` 的“能舱”，对人体进行长时间能量冲刷。
   能舱并不是高深莫测的神秘科技，但复杂度远高于普通病床，需要专门结构、控制系统、防护与监测设备。
   即使不考虑能源消耗，为军队内部制备足够数量的能舱也不现实，更不可能覆盖全体民众。
   因此该方案的绝望不只来自 `Energy` 消耗，也来自设备制造、部署、维护和数量规模完全跟不上感染扩散。

3. 蓝色药剂
   蓝色药剂是结合本世界 `Energy` 技术与传统生物技术的混合疫苗，对该病症有一定效果。
   它并非万能解药，更适合被理解为少数仍有希望的应急免疫 / 抑制方案。
   在当前主角组中，成安、若琳与艾琳娜都可视为已经处在这一药剂体系的覆盖或延伸作用之下；这会使他们对非均一化环境的承受与恢复能力高于思琳，但仍远不如陈曦岭那种原生改造体质。
   更深层地说，这类药剂之所以能成立，是因为许多关键生物材料根本无法从普通人体中稳定获得，而只能来自曦岭这一类在灾难前就被深度改造过的个体。
   曦岭几乎就是这条线最接近“完美样本”的存在。
   艾琳娜在意识到这一点之后，没有把相关记录交还给开云或仙洲生命司，而是把掌握到的材料与数据收束在本土快速反应集群内部。
   最终能够被真正制成的蓝色药剂，只有三支。
   这也会成为后续一个极痛的反问基础：
   如果三支药剂都已经靠曦岭的材料做出来，并且你们三个人都已经因此活了下来，那么当下一步仍然需要她时，队伍还有没有资格继续说“我们下不了手”。

4. 信息状态
   这些信息不一定对所有基层单位公开。艾琳娜可能比大多数人更早知道内部绝望程度，也因此在 `D Year 4 月 5 日` 选择私下为成安注射蓝色药剂。


十、前史节点：D Year 4 月 5 日

时间定位：

1. `D Year` 暂作为故事开端年份代称，`D` 可先理解为 `Destruction` 的工作缩写。
2. `4 月 5 日` 发生在第一幕大约半个月前，是感染危机正式压到主角组之前的重要前史节点。

军营状态：

1. 近来军营内感冒症状越来越多。
2. 症状包括咳嗽、低热、乏力和轻微头痛，表面上仍像普通流感或训练疲劳。
3. 患病人数增加到影响日常训练，部分训练被迫取消。
4. 不少患者会被送去做短时能舱治疗或 `Energy` 导流矫正，往往能暂时恢复，但过一阵子又会重新出现相似症状。
5. 当时角色们还无法确认这些感冒症状与后来的尸潮、咬伤感染或病毒排异有关。
6. 在制度层面，这一时期更像“麻烦但可管理”的慢性疫情，而不是所有人都已意识到末日将至。

高层认知：

1. 医疗条件良好的政府官员与高等级系统，对这场病程最初并不悲观。
2. 他们会相信只要能舱继续投产、配给继续提高、治疗流程继续标准化，这类异常“昏睡症”最终仍能被纳入治理框架。
3. 但少数与 `开云生物 / Kairon Bio` 以及其它企业有深入接触的官员，实际上知道这些病原体并非普通自然病毒。
4. 更准确地说，企业侧已经能够主动改造某些特化版本，也就是把自然微生物变成更适合干扰 `Energy` 流动的 `微动力生物引擎`。
5. 这也意味着他们一开始未必是为了毁灭世界；更像是在试图控制、试验、利用，最后却撞上了远超预期的环境变化与连锁后果。

办公室事件：

1. 艾琳娜·索尔贝格将青阳成安叫到营地医院办公室。
2. 两人此时是情人关系，这件事本身需要保密或至少不宜公开。
3. 艾琳娜为成安注射了一针蓝色药剂。
4. 该药剂是新兴 `Energy` 技术与传统生物技术结合的混合疫苗，对异常“昏睡症”及其背后的感染病程有一定效果。
5. 但它并不是普通军方量产物。它的关键材料，来自艾琳娜此前在集群内部秘密控制下来的一组样本，而那组样本的源头正是陈曦岭。
6. 更准确地说，艾琳娜曾在一次实习 / 志愿者流程中接触到曦岭，并本能地意识到她是一个近乎不该存在的完美样本。
7. 艾琳娜随后借助自己舅舅，也就是本土快速反应集群生化部总监的权限，将所有记录与样本拦在集群体系内部，没有向 `开云生物 / Kairon Bio` 或 `仙洲生命司` 通报。
8. 最终，那批材料只够做出三支药剂。
9. 艾琳娜叮嘱成安：无论如何不能向任何人提起这件事。

叙事功能：

1. 这段前史可以解释成安与艾琳娜之间存在超出普通战友的信任和秘密。
2. 蓝色药剂的基本性质是 `Energy`-生物混合疫苗，但现在可以明确：它的真正稀缺性不只是审批或工艺问题，而是源头材料几乎不可复制。
3. 药剂与 `Energy` 技术有关，也与曦岭本人这条隐藏生物线直接相连，因此能够把病毒线、角色秘密和世界科技树的不均衡感连成一个结。
4. 成安是否因此拥有特殊抵抗、延迟发病、异常感知或副作用，暂不确定。
5. 艾琳娜的动机应以“保护成安”为核心，但她也同时知道：自己手里拿着的，其实是不能被上报、不能被追问来源、也几乎无法再复制的应急方案。

视觉 / 分镜备忘：

1. 营地医院办公室应冷、窄、带有军用医疗设施和临时档案堆积感。
2. 蓝色药剂可以作为少数非灰度强调色，呈现冷蓝、荧光蓝或低饱和电弧蓝。
3. 成安的表情应是疑惑、信任和不安混合；艾琳娜则应显得疲惫、坚定、带有负罪感。
4. 这一幕可以作为后续回忆插入，不一定放在第一幕之前完整播放。
5. 如果做静态动画，可用针剂特写、办公室门缝、艾琳娜低声警告、成安袖口注射点四个镜头完成。


十一、灾难日节点：D Year 4 月 14 日

时间定位：

1. `4 月 14 日` 暂定为“灾难日”。
2. 该节点发生在 `4 月 5 日` 蓝色药剂事件之后，代表第 16 联合航空营从异常感冒和昏睡症过渡到公开崩溃。

第 16 联合航空营崩溃：

1. 第 16 联合航空营是第二首都神华市外围的精锐部队。
2. 灾难日当天，基地面对一大群丧尸来袭。
3. 这些丧尸并不夸张高速，移动速度只比正常人走路快一点。
4. 真正的问题是大部分士兵已进入感冒、无力或昏睡病程，很多人连枪都拿不稳。
5. 因此精锐部队在短时间内崩溃，不是因为丧尸单体强到违反常识，而是防线人员已经被病程掏空。

成安与艾琳娜撤退：

1. 青阳成安带着艾琳娜·索尔贝格且战且退。
2. 此时成安仍然主要是个人视角和近距离生存状态，不应表现为已经拥有完整无人机支援链路。
3. 艾琳娜的医疗身份让撤退更困难：她可能仍试图带走药品、病例资料、蓝色药剂线索或伤员名单。

李思琳与陈曦岭出现：

1. 一台吉普车向成安和艾琳娜开来。
2. 驾驶者是李思琳。
3. 副驾驶坐着见习空地联络官陈曦岭。
4. 成安看向车后，惊讶于她们准备得相当充分。
5. 李思琳解释：陈曦岭是个末日爱好者，平时就有一套应急装备；好在现在可以提起箱子就走。
6. 这一点让陈曦岭的“菜鸟”身份更有层次：她在正式军职上是见习，但在末日准备、应急包、路线规划和野外生存方面反而提前做足功课。

转向神华工业大学：

1. 吉普车原本向城外开。
2. 行驶途中，李思琳突然脸色大变。
3. 她意识到妹妹李若琳还在神华工业大学相关区域，或至少意识到必须先去确认妹妹状况。
4. 李思琳调头，往神华工业大学方向开去。
5. 这个决定把主角组从“单纯逃离军营”推向“冒险进入更危险城市区域救人”。

神华工业大学校门外：

1. 众人抵达神华工业大学校门外。
2. 神华工业大学在仙洲的地位极高，几乎等同于中国语境中的清华大学，因此它不仅是高校，也是科研、能源、材料和国家级人才节点。
3. 李思琳像变戏法一样掏出一台业余无线电台，快速操作后发出几次 `滴滴滴` 的呼叫。
4. 无线电果然传来回应。李思琳听了几声后，确认李若琳大致还在公寓方向。
5. 李思琳丢下电台，拿好武器和装备，只对成安、艾琳娜、陈曦岭三人说了一句：`拜托了`。
6. 这句话将“姐姐救妹妹”的私人行动变成四名战友共同承担的救援行动。
7. 三人没有长篇表态，只开始收拾武器和装备，准备跟在李思琳身后出发。

校园受袭状态：

1. 神华工业大学是被重点策划攻击的目标。
2. 一些昔日顶尖实验室方向传来爆炸声，暗示外星势力 / 本土生物公司对科研节点、能源技术和实验设施进行了有组织打击。
3. 校园主区域压力较大，但公寓方向压力相对没有那么巨大。
4. 这让小队冲入学生 / 研究生公寓区域仍然有可行性，但行动必须快速。
5. 一行人最终跟着李思琳冲进李若琳的公寓。

李若琳公寓救援：

1. 众人进入公寓楼，越过歪七八扭躺倒在地的人们。
2. 这里不是尸横遍野，而是一道走廊上稀稀拉拉躺着几个人。
3. 由于此时大部分博士生可能还在实验室，公寓走廊里的倒地者数量不多。
4. 这些未来几乎注定成为国家精英的研究生正躺在地上，只有胸口微微起伏，显示他们更接近异常“昏睡症”中段，而不是普通尸体。
5. 众人踹开若琳房门，只见李若琳斜躺在床上，右手手腕的咬痕无比醒目。
6. 艾琳娜迅速处理若琳的伤口，完成临时消毒、压迫、包扎和固定。
7. 艾琳娜判断可以撤离，干脆直接把若琳扛到肩上。
8. 成安、李思琳和陈曦岭迅速将艾琳娜和若琳护到中心，组成移动保护队形撤离。

撤离恶化：

1. 离开公寓的路上，形势进一步恶化。
2. 丧尸开始往各处游荡，校园内的安全路线变得更不稳定。
3. 倒地的人越来越多，异常“昏睡症”患者和伤员开始扩大可见规模。
4. 小队仍然成功回到车上。

无标识冷藏针剂：

1. 回到车上后，艾琳娜从随身箱中取出一支通过 `Energy` 驱动的小型冷藏针剂。
2. 针剂没有任何标识。
3. 艾琳娜没有长时间解释，对着李若琳的颈项直接注射。

撤出神华市：

1. 众人上了吉普车后，由李思琳驾车出发。
2. 此时李思琳的左脚已经有一道丧尸抓出的伤口，但她仍然隐忍不说，继续驾驶。
3. 车辆驶出城市后，高速反而畅通无阻。

目的地分歧：

1. 青阳成安问：接下来去哪里。
2. 李思琳回答：`半岛`，也就是 72 号基地。
3. 72 号基地原本即将交付第 16 联合航空营，作为近海训练基地使用。
4. 成安估算路线后指出：距离约 `800 公里`，当前油量显然不够。
5. 成安建议先去临河郡的 `38e 基地`。
6. 在修筑半岛基地期间，出差路过的航空营官兵大多安排在 38e 基地补给，因此众人对那里的情况都很熟悉。
7. 38e 基地可以作为中途补给、换车、获取油料、药品、弹药或情报的现实选择。

38e 基地夜间：

1. 当日夜里，众人抵达临河郡 `38e 基地`。
2. 众人惊讶发现这里竟然有激烈交火痕迹，说明该基地也曾遭到严重攻击。
3. 基地内载具大多被毁。
4. 好在大部分丧尸已经散去，现场没有形成持续围攻。
5. 众人忙活半天，只能把剩余燃油抽到一台幸存的跨斗三轮 / 侧斗摩托中。
6. 估算燃油后，认为这台车应该足够走完剩下去往 72 号半岛基地的旅程。
7. 随后众人排好哨，在基地内找好房间休息。

38e 基地清晨：

1. 第二天一早，成安醒来，发现李思琳在屋顶上操作电台。
2. 思琳面色凝重，显然已经通过无线电获知了更坏的战场信息。
3. 她望着成安，说：`巨人，疾跑者，粘液投掷者，就连一般的丧尸都可以抗住几发 7.62mm...这个世界疯了。`
4. 这句话是第一次明确提示：尸潮中存在多种生物兵器 / 变异单位，且普通丧尸的耐受性也在上升。
5. 成安没有展开讨论，只摇摇头，招呼众人起床。
6. 成安和艾琳娜一起将若琳扶上跨斗三轮 / 侧斗摩托，继续出发。

继续向半岛移动：

1. 从 38e 基地离开后，众人的行进速度明显变慢。
2. 李思琳开始不断咳嗽，脚步也出现踉跄。
3. 她左脚的抓伤和早期病程开始影响状态。
4. 因此后续越来越多由李思琳驾驶跨斗三轮 / 侧斗摩托，让她减少步行负担。
5. 侧斗摩托按临时塞满三人的灾难撤离状态处理：李思琳驾驶，李若琳坐侧斗，陈曦岭可挤在后方或行李位；青阳成安与艾琳娜通常步行警戒或先行检查。
6. 艾琳娜对病毒有所了解，知道这更像早期病程或排异反应，因此众人没有立刻惊慌。
7. 但艾琳娜不理解陈曦岭为什么毫无症状，甚至越来越生龙活虎。
8. 她可以用半开玩笑、半困惑的语气说：`不能是因为年轻人身体好吧？`
9. 陈曦岭的异常健康状态应作为后续悬念：表层上可以先被理解为体质、接触剂量、免疫差异或未暴露；更深层真相则是她早已被做过基因层面的免疫处理。

分镜 / 节奏备忘：

1. 可以先用基地崩溃镜头表现士兵无力、咳嗽、枪支掉落、丧尸缓慢但稳定压近。
2. 成安和艾琳娜撤退镜头应是仓促、低弹药、局部火光或灰白烟尘，而不是大规模英雄反击。
3. 吉普车出现时可以用远光、刹车声和急停打断撤退节奏。
4. 车后装备箱、燃料、医疗包、工具、食物和地图可用一个快速特写表现“准备充足”。
5. 李思琳提到曦岭是末日爱好者时，可以有短促的黑色幽默，但整体仍应压抑。
6. 李思琳脸色大变和调头应作为该节点的情绪转折，直接引向李若琳和神华工业大学线。
7. 校门外无线电段应短而紧。重点是李思琳确认目标、放下电台、说出 `拜托了`，随后四人立即行动。
8. 实验室爆炸可以放在远处背景，不必直接展示大量战斗；公寓方向相对安静，能形成“重点目标被炸，个人救援仍有窗口”的对比。
9. 公寓走廊不要做成屠杀现场。重点是少量倒地研究生的安静呼吸，让观众意识到这是国家未来精英被病程批量按倒。
10. 若琳手腕咬痕应作为房间内第一眼视觉焦点，随后才切到艾琳娜的医疗动作。
11. 车上无标识冷藏针剂应突出 `Energy` 驱动冷藏、小体积、无标签和艾琳娜的果断。
12. 离城高速段应表现为诡异畅通：宽阔车道、零散弃车、远处城市烟柱，而不是典型拥堵逃亡。
13. 思琳左脚伤口可先作为观众注意到、队友未必立刻发现的细节，为她后续咳嗽和状态下降埋伏笔。
14. `半岛`、`72 号基地` 和 `38e 基地` 的对话可以作为把剧情引向当前游戏默认半岛地图的关键桥段。
15. 38e 基地夜间场景应突出交火后的空荡：毁坏载具、弹壳、烧焦痕迹、散去的尸潮和被抽油的幸存侧斗摩托。
16. 思琳清晨屋顶电台段应作为敌人种类升级提示，但不要直接变成怪物图鉴说明。
17. 思琳病程恶化与曦岭异常健康应并列呈现，制造“同队暴露后反应完全不同”的悬念。


十二、第一幕剧情草案

第一幕发生在 `D Year 4 月 18日`。当前游戏开局只需要从众人抵达半岛基地开始。前面的 `4 月 5 日` 蓝色药剂、`4 月 14 日` 灾难日、神华工业大学救援和 `38e 基地` 中转，可统一视为 `Stage 0`；它们不在当前开局中完整播放，后续可作为成安昏迷、梦境或间幕回忆插入。

场景核心：

1. 一台跨斗三轮摩托缓慢前进。
   车辆可按俗称“八嘎车”理解，但正式文档中建议称为跨斗三轮、军用跨斗摩托或侧斗摩托，避免调性被现实俗称带偏。

2. 李思琳负责驾驶。
   她一边低速驾驶跨斗三轮，一边担心妹妹手腕处的咬痕。她自己的状态也并不好，会不时咳嗽两声，但仍然强撑着保持路线和速度。

3. 李若琳坐在旁边，面色苍白。
   她刚经历逃难和受伤，身体状态明显不稳。她手腕处有咬痕，伤口已经被军医尽力包扎，手臂被固定或束紧。

4. 陈曦岭挤坐在车后方或行李位。
   她状态最好，可以随时跳下车处理障碍、警戒道路两侧。这个状态与李思琳的硬撑、李若琳的虚弱形成对比。

5. 青阳成安和艾琳娜·索尔贝格也跟在后面前进。
   青阳成安此时还没有无人机，开场可先以他的个人第一视角展开；他承担观察、通讯和跟随队伍的功能。艾琳娜则刚完成包扎，仍在观察李若琳的意识、脉搏和感染迹象。

6. 咬痕信息
   李若琳的手腕咬痕是第一幕的核心悬念。它不必立刻解释感染机制，但应让玩家意识到：这趟撤离不是普通逃难，而是带着随时可能恶化的倒计时。
   由于病毒早期症状接近轻感冒，李若琳此时可以表现为苍白、低热、乏力和轻微发冷，而不是明显狂暴或变异。

半岛在望：

1. 众人继续前进，半岛已然在望。
2. 大地传来隐隐震动。
3. 极远处飘起不详的沙尘，暗示大规模尸潮、生物兵器或重型变异单位正在逼近。
4. 这个阶段不需要立刻展示完整敌群，只要让玩家感到远方有什么巨大的东西正在移动。

基地门口：

1. 众人终于抵达 `72 号半岛基地` 门口。
2. 基地门口只躺着两个哨兵，身体微微抽搐。
3. 跨斗三轮停在闸口后方，李思琳、李若琳和陈曦岭仍在车上；青阳成安与艾琳娜先靠近哨兵。
4. 艾琳娜检查哨兵后摇头，说明两人已经接近弥留，常规处理意义不大。
5. 这个画面表明基地并非被完整占领，而是守备人员被病程和突袭打到近乎失能。

能舱与军火库：

1. 艾琳娜指挥众人迅速把李若琳抬到军火库。
2. 军火库内果然有一台到货但尚未部署的能舱。
3. `Energy` 能源装置布设完好，说明半岛基地本身足够先进，且已经接近正式交付状态。
4. 远方此时已经传来若隐若现的吼声，留给众人的准备时间非常短。
5. 众人将李若琳放入能舱，启动长时间能量冲刷 / 维持流程。

指挥权限接入：

1. 李思琳将令牌交给青阳成安。
2. 成安带着令牌奔往指挥部。
3. 他成功获取基地指挥权限。
4. 这一刻是玩家从个人第一视角过渡到基地指挥 / 无人系统视角的关键节点。
5. 72 号半岛基地是一座先进且高度无人化的基地；获得权限后，沉寂的基地系统开始运作。

无人化基地启动：

1. 陈曦岭拆开军火库中的一个包装，一个无人器械被释放出来。
2. 这可以作为“无人作战平台成熟”的第一次明确演示，不必解释太多，只要让玩家看到自动化设备开始执行任务。
3. 成安一面派人去门口接回接近弥留的哨兵，一面迅速激活并确认现有建筑。
4. 需要重点确认的建筑包括军火库、能源设施、材料设施、指挥部、防御设施和南段机库。
5. 基地南段机库内的 AC-130 状态良好。
6. 经过紧锣密鼓的战前准备后，AC-130 即可使用。
7. 这条线直接接入当前游戏中的半岛基地默认建筑、资源建筑、军火库、机库和无人机 / 战术支援玩法。

第一关进入：

1. 须臾之后，陈曦岭与李思琳都来到指挥部。
2. 陈曦岭虽然有些手忙脚乱，但仍成功部署了两台 `7.62mm` 机枪阵地。
3. 远处沙尘越来越大，说明敌群正在接近，准备时间即将耗尽。
4. 成安搀扶状态不佳的李思琳上飞机。
5. 成安同时嘱咐陈曦岭记得把观测无人机放飞。
6. 李思琳登上 AC-130 后，伴随飞机起飞场景，剧情正式进入防御战 demo，也就是第一关。
7. 起飞后，成安作为玩家视角接过观测无人机控制权。
8. 玩家通过无人机视角引导 AC-130 炮火，开始保卫 72 号半岛基地。

第一关结局：

1. 防御战结束后，AC-130 勉强降落在跑道上。
2. 飞机状态应表现为还能落地但已经接近极限，强化“第一关胜利并不轻松”的感觉。
3. 成安抱着状态恶化的李思琳下飞机。
4. 艾琳娜早已乘坐运兵车前来等候。
5. 众人将李思琳送入军火库。
6. 此时李若琳已经从能舱中被放到行军床上，盖好被子，状况暂时稳定。
7. 这说明能舱和无标识针剂至少暂时起效，但仍不能保证长期安全。
8. 李思琳被投入能舱，开始接受能量冲刷 / 维持流程。
9. 这一镜头形成第一关后的代价感：基地守住了，但驾驶 AC-130 的思琳也被病程拖入治疗队列。

哨兵海葬：

1. 第一关结束后，基地门口两名接近弥留的哨兵最终死亡。
2. 成安指挥无人器械 / 机器人处理遗体，将两名哨兵进行海葬。
3. 这个仪式不应铺张，只需要安静、短促、克制。
4. 此时能站着默哀的只有青阳成安、陈曦岭和艾琳娜·索尔贝格三人。
5. 李若琳在行军床上暂时稳定，李思琳在能舱中治疗，因此都无法参加。
6. 这段能让第一关胜利后的空旷感落到具体的人身上：基地守住了，但守基地的人几乎已经不在。

教学目标：

1. 陈曦岭部署两台 7.62mm 机枪阵地，作为第一关地面自动防御的来源。
2. 成安接入观测无人机，完成从个人视角到当前游戏主视角的转换。
3. 李思琳驾驶 / 指挥 AC-130，解释玩家为何能引导空中炮火。
4. 远处沙尘和吼声作为第一波进攻倒计时。
5. 这一段应直接衔接当前可玩防御战 demo，不再继续拖长过场。
6. 第一关结局应以医疗收束而不是庆祝收束：飞机勉强着陆、成安抱思琳下机、艾琳娜接应、若琳稳定、思琳入舱。
7. 两名哨兵海葬可以作为战后最后一组静态镜头，站立默哀者只有成安、曦岭和艾琳娜，画面应安静到近乎没有胜利感。

静态分镜建议：

1. 远景
   灰白色破损道路或基地外围，跨斗三轮缓慢进入画面，车上三人、步行两人。李思琳驾驶，李若琳坐在侧斗，陈曦岭挤在后方或行李位，青阳成安与艾琳娜步行跟随或警戒，画面气氛压低，不做英雄登场。

2. 中景
   李思琳握住车把驾驶，眼睛盯着前方，但会短促咳嗽；李若琳坐在侧斗或旁座，身体微微蜷缩，脸色苍白；陈曦岭挤坐在后方。艾琳娜可以在车旁观察病程，不应被误读为留在车上的第三名乘员。

3. 特写
   李若琳手腕处的包扎、渗血、咬痕轮廓和临时固定。不要过度血腥，重点是“已经处理过但仍然危险”。

4. 反应镜头
   李思琳在驾驶间隙看向妹妹手腕，担忧压过军官式冷静；她不能停下，只能继续把车往前带。

5. 医疗镜头
   艾琳娜·索尔贝格观察包扎处或查看简易医疗终端，表情克制但不轻松。

6. 通讯 / 战术镜头
   青阳成安检查手持终端、无线电或周围环境。此时不表现无人机链路，玩家先通过他的个人视角进入队伍处境。

7. 陆军警戒镜头
   陈曦岭在车辆后方轻快跟进，保持警戒，观察道路两侧和前方拐角，显示她当前体能状态明显好于车上两姐妹。

8. 收束镜头
   远处传来尸群或战斗声，车辆继续缓行。画面先保持青阳成安的个人视角；抵达半岛基地并取得指挥权限后，无人系统和战术监视器 UI 才正式接入。

角色状态：

1. 李思琳：驾驶、担忧妹妹、自己也在咳嗽但强撑。
2. 李若琳：受伤、虚弱、感染风险悬念。
3. 陈曦岭：在后方精神和体力状态较好，负责警戒、观察道路和辅助控制路线。
4. 青阳成安：开场个人第一视角、通讯、观察、警戒；此时尚未拥有无人机。
5. 艾琳娜·索尔贝格：包扎后监测伤情，承担医疗判断压力。

视觉口径：

1. 开场应是低速、压抑、疲惫的撤离，不是高速追车。
2. 色彩可延续灰黑白监视器风格，只有伤口、警示灯或 UI 标记保留极低饱和强调。
3. 车辆、衣物和装备要有尘土、擦痕、血迹和临时绑扎感。
4. 李若琳的咬痕不要处理成夸张怪物化，第一幕只需要危险和不确定。
5. 这组分镜可以作为新手教程前的剧情引子，先以青阳成安的个人视角建立队伍和危机；无人机视角应作为后续剧情节点或教程步骤被正式接入。
6. 4 月 18 日半岛基地段应作为教程正式开始点：能舱救人、令牌授权、无人化基地启动、建筑确认和 AC-130 准备共同构成第一组教学目标。
7. 第一关开始前的最后一组镜头应是：曦岭部署两台 7.62mm 机枪阵地，成安搀扶思琳登机，观测无人机放飞，AC-130 起飞，画面切入无人机火控 UI。
8. 第一关结束后的镜头应压低胜利感，把重点放在思琳入能舱和若琳暂时稳定上，为后续基地经营和防御留下情绪压力。
9. 如果开局剧情较长，应把 `4 月 5 日`、`4 月 14 日`、神华大学、38e 基地、4 月 18 日半岛基地分成数个短章节式静态动画，每段只保留 3-6 个关键镜头，避免变成连续长篇说明。


十三、后续待定

1. 是否需要正式国徽。
2. `Siano` 的中文全称是否只是“仙洲”，还是需要“仙洲共和国 / 仙洲联邦 / 仙洲防卫区”等正式称呼。
3. 旗帜比例暂未定，后续可按 `3:2` 或 `16:10` 做两个版本。
4. 是否为黑白监视器 UI 单独制作一版简化旗帜。
