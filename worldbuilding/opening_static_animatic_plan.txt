一、制作目标

形式：

1. 静态分镜动画，不做完整 CG。
2. 每个镜头是一张 16:9 横图，可叠加轻微推拉、平移、抖动、闪白、扫描线和字幕。
3. 图片内不生成任何文字，所有日期、地点、字幕、系统提示都由 Godot UI 绘制。
4. 配置音效、环境声和少量关键台词。没有正式配音时，先使用字幕 + 电台噪声 + UI 提示音。
5. 开局可以稍长，但必须分成短章节，避免像连续长篇说明。

建议时长：

1. 当前开局版：只播放 `CH05-CH07`，约 3-5 分钟。
2. `CH01-CH04` 可统一视为 `Stage 0`，不作为当前开局必播内容，改为后续成安昏迷、梦境或间幕回忆使用。
3. 完整编年版：7 个章节，约 7-10 分钟，仅作为制作资料和后续回忆素材池。
4. 首轮 MVP：保留 `CH05-CH07` 中标记为 `MVP` 的镜头，先打通“半岛抵达 -> 第一关 -> 战后收束”。
5. 每个镜头默认 4-7 秒，动作镜头 2-4 秒，情绪镜头 6-9 秒。

视觉统一口径：

1. 写实军事静态分镜，灰黑白 / 暖白军用监视器风格。
2. 只允许少量强调色：蓝色针剂 / Energy 冷光、红色极低饱和警示灯、火光压暗。
3. 角色和装备有尘土、汗渍、血迹、临时包扎、疲惫感。
4. 不做英雄海报构图，不做动漫夸张表情。
5. 画面优先表达冷、紧、疲惫和不确定。

角色视觉锚点：

1. 青阳成安：28 岁亚裔男性，空军上尉，战术支援中队，无人机引导操作员；开局前半段还没有无人机。
2. 李思琳：31 岁女性，中国和俄罗斯混血面孔，空军少校，AC-130 机长；状态不断恶化，有左脚抓伤和咳嗽。形象更锐利、成熟、高压、飞行员化。
3. 李若琳 / Rosaline：26 岁女性，中国和俄罗斯混血面孔，应用材料与能源博士生；手腕咬伤，虚弱苍白。与思琳有姐妹相似，但更柔和、学术化、病弱。
4. 陈曦岭：25 岁女性，亚裔中国面孔，陆军中尉，见习空地联络官；菜鸟但体力好、末日准备充分。形象应明显不同于李家姐妹，短发或齐耳短发、健康、五官紧凑、清爽年轻，不复刻现实人物脸。
5. 艾琳娜·索尔贝格 / Elina Solberg：29 岁女性，北欧风格面孔，陆军中尉，军医；冷静、疲惫、果断。

推荐文件结构：

1. `assets/generated/story/opening/images/`：开局静态分镜图片。
2. `assets/generated/story/opening/audio/sfx/`：关键音效。
3. `assets/generated/story/opening/audio/ambience/`：环境底噪。
4. `assets/generated/story/opening/audio/voice/`：后续若有配音，放关键台词。
5. `data/opening_animatic.csv`：当前已接入的数据驱动分镜表。
6. `scripts/StoryAnimaticPlayer.gd`：当前已接入的静态动画播放器。
7. `assets/sounds/story/`：当前第一批程序化临时音效目录，cue 名可直接由 CSV 引用。


二、音效总表

优先级 A，第一版必须有：

1. `sfx_radio_morse_short_01.wav`：业余电台滴滴短呼。
2. `sfx_radio_static_loop_01.wav`：电台底噪。
3. `sfx_door_kick_01.wav`：踹开公寓门。
4. `sfx_injection_01.wav`：针剂注射。
5. `sfx_cooler_open_01.wav`：冷藏针剂箱开启。
6. `sfx_energy_chamber_start_01.wav`：能舱启动低鸣。
7. `sfx_command_auth_01.wav`：指挥权限确认音。
8. `sfx_drone_launch_01.wav`：观测无人机放飞。
9. `sfx_ac130_takeoff_01.wav`：AC-130 起飞。
10. `sfx_ac130_hard_landing_01.wav`：AC-130 勉强降落。
11. `sfx_ocean_wind_01.wav`：海葬段海风 / 海浪。

优先级 B，有则增强：

1. `amb_hospital_room_01.wav`：医院办公室低频灯噪。
2. `amb_camp_collapse_01.wav`：远处枪声、警报、咳嗽、人群混乱。
3. `amb_campus_distant_explosion_01.wav`：远处实验室爆炸和城市火声。
4. `amb_empty_base_night_01.wav`：38e 基地夜风、金属轻响。
5. `amb_peninsula_distant_horde_01.wav`：远处低吼、震动、沙尘。
6. `sfx_jeep_brake_01.wav`：吉普急刹。
7. `sfx_fuel_siphon_01.wav`：抽油声。
8. `sfx_machinegun_mount_deploy_01.wav`：7.62mm 机枪阵地部署。
9. `sfx_robot_servo_01.wav`：无人器械伺服电机。
10. `sfx_body_bag_or_blanket_01.wav`：行军床 / 被褥轻响。

对白处理：

1. 第一版可以只做字幕，不做真人配音。
2. 关键台词可后续做低保真电台配音，降低配音质量要求。
3. 系统音用英语更贴近当前 UI：`COMMAND AUTHORITY CONFIRMED`、`DRONE LINK ONLINE`。

六、Godot 实现建议

播放器功能：

1. 黑屏 / 占位章节卡。已接入。
2. 显示一张主图；真实图片缺失时自动回退到程序化占位画面。已接入。
3. 支持 Ken Burns 式推拉和平移，参数来自 `camera_from` / `camera_to`。已接入。
4. 支持字幕条。已接入。
5. 支持环境声循环、一次性音效和可选台词音频；同一镜头可按多个时间点触发 cue。已接入基础版。
6. 支持点击 / 空格提前进入下一镜头。已接入。
7. 支持上一镜头 / 下一镜头跳转，方便调试和回看。已接入。
8. 支持上一章节 / 下一章节跳转，避免每次调试都从头播放。已接入。
9. 支持长按 Esc 跳过整段，F3 切换调试显示；第一次播放 / 重看状态下一步接入。

调试快捷键建议：

1. `Space` / 鼠标左键：进入下一镜头。
2. `Backspace` / 鼠标右键：返回上一镜头。
3. `PageDown`：进入下一章节。
4. `PageUp`：返回上一章节。
5. `Home`：回到当前章节第一镜头。
6. `End`：跳到当前章节最后一镜头。
7. 长按 `Esc`：跳过整段开局静态动画。
8. `F3`：显示或隐藏调试信息。
9. 调试模式下显示当前镜头编号，例如 `OP06-08 / CH06 / 06.0s`；正式播放时隐藏。

推荐数据字段：

1. `id`
2. `chapter_id`
3. `group`
4. `duration`
5. `image_path`
6. `camera_from`
7. `camera_to`
8. `chapter_card`
9. `visual`
10. `subtitle_speaker`
11. `subtitle_text`
12. `sfx_cues`
13. `sfx_timing`
14. `music_or_ambience`
15. `transition`
16. `next_action`
17. `skip_group`
18. `debug_note`

当前已经搬到 `data/opening_animatic.csv`。其中 `sfx_cues` 和 `sfx_timing` 用分号分隔，允许同一镜头多个时间点触发音效；未写完整路径的 cue 会解析为 `assets/sounds/story/<cue>.wav`。
