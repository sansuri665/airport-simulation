# 西印度洋架空国家地图

这是以马达加斯加主岛为地理原型制作的架空国家导航底图。当前阶段只确定国家主岛的外部轮廓，不绘制山脉、河流、城市、道路或行政区。

## 最终文件

- `index.html`：交互地图，支持缩放、拖动、地名开关、经纬度读取和轮廓画笔。
- `merged-island-outline.json`：唯一保留的岛屿轮廓数据，使用 WGS84 经纬度。
- `geodata.js`：供地图页面直接加载的东非与主岛显示数据。

阶段性手绘 JSON 已在轮廓定稿后删除。之后若继续使用画笔修改，可先导出临时 JSON，确认后再合并回 `merged-island-outline.json`。

## 与原始马达加斯加的差异

参考底图为 [Natural Earth 1:50m](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/) 的马达加斯加主岛轮廓。现实面积参考值来自 [CIA World Factbook](https://www.cia.gov/the-world-factbook/about/archives/2021/field/area/)。

- 现实马达加斯加总面积参考值：587,041 平方公里。
- 架空主岛估算面积：761,828 平方公里，约 76.2 万平方公里。
- 净增加面积：约 174,787 平方公里，增幅约 29.77%。
- 最终轮廓在原岛以外增加约 177,314 平方公里，同时削减原轮廓约 2,527 平方公里。
- 几何中心相对原岛约向东移动 52.3 公里、向北移动 9.9 公里。

主要形态变化：

1. 西北海岸变得更宽、更圆缓，早期拼接形成的尖刺已被修平。
2. 东海岸整体向印度洋方向外扩，并增加较自然的海湾与岬角变化。
3. 东南海岸保留一块受控的小型扩展，没有采用曾经过于臃肿的大型突出部。
4. 西南和远西海岸最接近原始马达加斯加轮廓，是整个岛形的稳定基底。
5. 南部狭长尖刺已圆化，但岛屿最南端和整体南北长度几乎没有改变。
6. 较长的直线岸段加入了小尺度波动，使海岸更接近天然侵蚀形成的轮廓。

原始岛屿经纬范围约为：

- 西端 43.257129°E
- 东端 50.482715°E
- 北端 12.079590°S
- 南端 25.570508°S

最终架空岛屿经纬范围约为：

- 西端 43.257129°E
- 东端 51.121892°E
- 北端 12.071280°S
- 南端 25.571136°S

因此，岛屿主要是向东扩宽，而南北尺度基本维持原状。

## 面积说明

面积为世界观设定估算值：以现实马达加斯加 587,041 平方公里为基准，再叠加等积投影计算出的轮廓差值。它适合用于设定集、人口密度和行政规划，但不应视为测绘级数据。

直接用浏览器打开 `index.html` 即可查看地图。
